# 背包专题小结

## 先记一句最重要的话

> 外循环决定“顺序要不要去重”，内循环方向决定“当前物品能不能重复使用”。

这是背包题里最容易混的地方。

很多时候代码长得很像，但只要：

- 外循环换了
- 内循环从正序变成倒序

题目的含义就已经变了。

---

## 一、先从两个维度判断题型

拿到一道背包题，先别急着套模板，先问自己两个问题。

### 1. 题目到底在求什么

常见有 4 种：

1. **能不能凑出来**
2. **最少 / 最多是多少**
3. **组合数是多少**
4. **排列数是多少**

这一步决定：

- `dp` 里存的是 `True / False`
- 还是最优值
- 还是方案数

### 2. 每个物品能用几次

常见有 2 种：

1. **每个物品只能用一次**
2. **每个物品可以无限次使用**

这一步决定：

- 一维优化时内层要倒序还是正序

---

## 二、外循环和内循环到底在控制什么

### 外循环在控制什么

外循环控制的是：

```text
你是按“物品种类”组织答案，还是按“目标容量”组织答案
```

所以它决定：

```text
顺序是否会被重复统计
```

#### 外层枚举物品

```python
for coin in coins:
    for total in ...:
```

含义是：

> 先决定当前允许使用哪些物品种类，再去扩展容量。

这样通常会把：

```text
1 + 2
2 + 1
```

看成同一种组合。

所以它适合：

- 组合数
- 标准背包模板写法

#### 外层枚举容量

```python
for total in range(...):
    for coin in coins:
```

含义是：

> 对每个目标值，去枚举“最后一步选了哪个物品”。

这样通常会天然地区分不同顺序。

所以它适合：

- 最值类里“枚举最后一步”
- 排列数

---

### 内循环方向在控制什么

内循环方向控制的是：

```text
当前这一轮里，能不能继续使用当前物品
```

#### 倒序

```python
for total in range(target, num - 1, -1):
```

含义是：

> 当前物品这一轮只能用一次。

因为更新 `dp[total]` 时，用到的 `dp[total - num]` 还是上一轮的值。

所以它适合：

- 0-1 背包

#### 正序

```python
for total in range(num, target + 1):
```

含义是：

> 当前物品这一轮可以继续重复使用。

因为更新 `dp[total]` 时，用到的 `dp[total - num]` 可能已经被当前这一轮更新过。

所以它适合：

- 完全背包

---

## 三、四种最常见情况

---

### 1. 0-1 背包：能不能凑出来

代表题：

- 416 Partition Equal Subset Sum

写法：

```python
for num in nums:
    for total in range(target, num - 1, -1):
        dp[total] = dp[total] or dp[total - num]
```

对应代码：

- [01_q416/solution_4_optimized_dp.py](01_q416/solution_4_optimized_dp.py)

这里：

- 外层是物品
- 内层倒序
- 因为每个数只能用一次
- `dp[total]` 存的是能不能凑出来

一句话记忆：

> 0-1 背包一维优化，外物品，内容量倒序。

---

### 2. 0-1 背包：方案数

代表题：

- 494 Target Sum（一维优化之后）

写法：

```python
for num in nums:
    for total in range(positive, num - 1, -1):
        dp[total] += dp[total - num]
```

对应代码：

- [02_q494/solution_4_optimized_dp.py](02_q494/solution_4_optimized_dp.py)

这里虽然是计数，但因为每个数只能选一次，所以本质仍然是：

- 外层物品
- 内层倒序

和 416 的区别只在于：

- 416 存的是布尔值
- 494 存的是方案数

一句话记忆：

> 0-1 背包里，不管你求布尔、最值还是计数，只要一维优化，内层基本都先记倒序。

---

### 3. 完全背包：最值

代表题：

- 279 Perfect Squares
- 322 Coin Change

#### 写法 A：外容量，内物品

```python
for total in range(1, amount + 1):
    for coin in coins:
        dp[total] = min(dp[total], dp[total - coin] + 1)
```

对应代码：

- [03_q279/279_perfect_squares.md](03_q279/279_perfect_squares.md)
- [04_q322/solution_3_dp.py](04_q322/solution_3_dp.py)

这种写法的思路是：

> 对每个目标值，枚举最后一个使用的物品。

它特别适合最值类，因为最自然。

#### 写法 B：外物品，内容量正序

```python
for coin in coins:
    for total in range(coin, amount + 1):
        dp[total] = min(dp[total], dp[total - coin] + 1)
```

这也是对的。

因为最值类不会因为不同顺序被重复累加。

也就是说：

- `1 + 2`
- `2 + 1`

即使都被你“想到”了，最后也只是取同一个最优值。

一句话记忆：

> 完全背包最值最自由，外容量或外物品通常都能写对；面试里更推荐按“最后一步”去推。

---

### 4. 完全背包：组合数

代表题：

- 518 Coin Change II

标准写法：

```python
for coin in coins:
    for total in range(coin, amount + 1):
        dp[total] += dp[total - coin]
```

对应代码：

- [05_q518/solution_4_optimized_dp.py](05_q518/solution_4_optimized_dp.py)

这里必须这样写。

因为这题问的是：

```text
组合数
```

不区分：

```text
1 + 2
2 + 1
```

所以必须：

- 外层枚举物品
- 内层金额正序

外层枚举物品，是为了去掉顺序重复。

内层正序，是为了允许当前物品重复使用。

一句话记忆：

> 完全背包组合数 = 外物品 + 内容量正序。

---

### 5. 完全背包：排列数

代表题：

- 377 Combination Sum IV

标准思路：

```python
for total in range(1, target + 1):
    for num in nums:
        dp[total] += dp[total - num]
```

这里要区分：

- `1 + 2`
- `2 + 1`

所以要对每个 `total` 去枚举“最后一个放的是谁”。

因此写法通常是：

- 外层容量
- 内层物品

一句话记忆：

> 完全背包排列数 = 外容量 + 内物品。

---

## 四、为什么 322 和 518 看起来不一样

这两个题很适合放在一起记。

### 322

题目问的是：

```text
最少硬币数
```

所以你可以写成：

```python
for total in range(1, amount + 1):
    for coin in coins:
```

因为这是在枚举：

```text
凑出 total 时，最后一枚硬币是谁
```

不同顺序不会导致答案错误，因为最后是取：

```text
min(...)
```

### 518

题目问的是：

```text
组合数
```

所以你必须写成：

```python
for coin in coins:
    for total in range(coin, amount + 1):
```

因为这时顺序不能重复计数。

如果也写成外容量、内硬币，就容易把：

- `1 + 2`
- `2 + 1`

重复算进去。

所以这两题最大的差别不是“一个是完全背包，一个不是”。

而是：

> 两题都是完全背包，真正决定写法差异的是：322 求最值，518 求组合数。

## 五、一张表快速记忆

| 类型 | 外循环 | 内循环 | 方向 |
|---|---|---|---|
| 0-1 背包 | 物品 | 容量 | 倒序 |
| 完全背包最值 | 物品或容量都可 | 另一个维度 | 若物品在外则正序 |
| 完全背包组合数 | 物品 | 容量 | 正序 |
| 完全背包排列数 | 容量 | 物品 | 通常正序 |

---

## 六、面试里怎么说最稳

你可以直接这样说：

> 我会先看题目问的是最值、可行性、组合数还是排列数；再看每个物品是只能用一次还是可以无限使用。顺序是否区分，决定外循环是谁；物品能否重复使用，决定内循环是正序还是倒序。

再压缩一点，就是：

> 外循环看顺序，内循环方向看复用。

这句话基本能把大部分一维背包题的循环顺序解释清楚。
