# 122. Best Time to Buy and Sell Stock II

## 题目理解

给你一个数组 `prices`，`prices[i]` 表示第 `i` 天股票的价格。

和第 121 题不同，这一题允许你：

- 进行 **多次交易**
- 但同一时间 **只能持有一股**
- 也就是说，必须先卖掉，才能再次买入

例如：

- `prices = [7,1,5,3,6,4]`，答案是 `7`
  - 第 2 天买入 `1`，第 3 天卖出 `5`，赚 `4`
  - 第 4 天买入 `3`，第 5 天卖出 `6`，赚 `3`
  - 总利润 `4 + 3 = 7`
- `prices = [1,2,3,4,5]`，答案是 `4`
  - 可以理解成第 1 天买入、第 5 天卖出，赚 `4`
  - 也可以理解成每天都把上涨差价赚到，结果一样
- `prices = [7,6,4,3,1]`，答案是 `0`
  - 一直在跌，不做交易最好

这题最关键的变化是：

> **交易次数不再限制为 1 次，而是可以做很多次。**

因此我们思考的重点也变了：

- 第 121 题：要找“一次交易”的最佳买卖点
- 第 122 题：要决定“每一天到底是继续持有、卖出，还是重新买入”

这题很适合按下面的路径理解：

```text
暴力递归 -> 记忆化递归 -> 二维 DP -> 状态压缩 -> 贪心
```

因为它既能用股票 DP 的方式完整推导，也能在最后落到一个非常漂亮的贪心结论。

## 方法一：暴力递归

### 思路

先不要急着套模板，直接把每天的选择写成递归。

走到第 `day` 天时，我们其实只有两种状态：

1. **手里没有股票**
2. **手里持有股票**

定义：

```text
dfs(day, holding) = 从第 day 天开始，在 holding 这个持股状态下，后面最多能赚多少钱
```

那么每天的选择就很自然了。

#### 情况一：当前没有持股

这时有两种选择：

1. 今天什么都不做，去下一天
2. 今天买入，利润要减去 `prices[day]`

所以：

```text
dfs(day, 0) = max(
    dfs(day + 1, 0),
    -prices[day] + dfs(day + 1, 1)
)
```

#### 情况二：当前持有股票

这时也有两种选择：

1. 今天什么都不做，继续持有
2. 今天卖出，利润加上 `prices[day]`

所以：

```text
dfs(day, 1) = max(
    dfs(day + 1, 1),
    prices[day] + dfs(day + 1, 0)
)
```

### 边界

当 `day == n`，说明天数已经走完了：

- 如果此时手里没有股票，后面当然赚不到钱，返回 `0`
- 如果此时手里还持有股票，说明这条路径最后没卖掉，不应该被选中

所以可以写成：

```text
dfs(n, 0) = 0
dfs(n, 1) = -∞
```

这里的 `-∞` 不是在表示真实利润，而是在表示：

```text
这种状态不合法，不要选它
```

### 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        n = len(prices)

        def dfs(day: int, holding: bool) -> int:
            if day == n:
                return 0 if not holding else float("-inf")

            best = dfs(day + 1, holding)
            if holding:
                best = max(best, prices[day] + dfs(day + 1, False))
            else:
                best = max(best, -prices[day] + dfs(day + 1, True))

            return best

        return dfs(0, False)
```

### 复杂度

- 时间复杂度：指数级
- 空间复杂度：`O(n)`，主要来自递归深度

### 评价

这个方法的价值在于：

- 把“每天只有买 / 卖 / 不动”这个决策过程看清楚
- 把后面 DP 的状态定义先想明白

但它会重复计算很多状态，不能作为最终答案。

## 方法二：记忆化递归

### 思路

暴力递归为什么慢？

因为像下面这种状态会被反复计算：

```text
dfs(day, holding)
```

只要：

- `day` 一样
- `holding` 一样

那么后面的最优利润就一定一样。

所以我们可以把它缓存起来。

状态定义和转移都完全不变，唯一的区别是：

- 算过的状态直接返回
- 没算过的状态再递归

### 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        n = len(prices)
        memo = {}

        def dfs(day: int, holding: bool) -> int:
            if day == n:
                return 0 if not holding else float("-inf")

            key = (day, holding)
            if key in memo:
                return memo[key]

            best = dfs(day + 1, holding)
            if holding:
                best = max(best, prices[day] + dfs(day + 1, False))
            else:
                best = max(best, -prices[day] + dfs(day + 1, True))

            memo[key] = best
            return best

        return dfs(0, False)
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 评价

这个方法已经能通过，而且很适合把暴力递归平滑地升级为 DP。

优点：

- 思路最自然
- 和后面 DP 的状态是一一对应的

缺点：

- 仍然是递归写法
- 面试里不如迭代版稳定

## 方法三：二维 DP

### 为什么要写成 DP

上面的记忆化递归，本质上已经说明了：

```text
状态只有 day 和 holding 两个维度
```

既然状态数只有 `n * 2` 个，那完全可以把它改写成迭代 DP。

### 状态定义

定义：

```text
dp[i][0] = 到第 i 天结束时，手里没有股票时的最大利润
dp[i][1] = 到第 i 天结束时，手里持有股票时的最大利润
```

这里“到第 i 天结束时”这几个字很关键。

它表示：

- 今天可以做操作
- 操作完之后，看你最终是空仓还是持股

### 第一天怎么初始化

第 `0` 天结束时：

- 如果手里没股票，那就是根本没买，利润是 `0`
- 如果手里有股票，那就说明今天买了，利润是 `-prices[0]`

所以：

```text
dp[0][0] = 0
dp[0][1] = -prices[0]
```

### 转移怎么来

#### 1. `dp[i][0]`：第 `i` 天结束时手里没有股票

有两种可能：

1. 昨天就没有股票，今天继续不动
2. 昨天持有股票，今天把它卖掉

所以：

```text
dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] + prices[i])
```

#### 2. `dp[i][1]`：第 `i` 天结束时手里持有股票

也有两种可能：

1. 昨天就持有股票，今天继续拿着
2. 昨天没有股票，今天买入

所以：

```text
dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - prices[i])
```

这两条转移，就是股票题里最核心的二维状态机。

### 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices:
            return 0

        n = len(prices)
        dp = [[0, 0] for _ in range(n)]

        dp[0][0] = 0
        dp[0][1] = -prices[0]

        for i in range(1, n):
            dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] + prices[i])
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - prices[i])

        return dp[n - 1][0]
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 评价

这是股票系列里非常重要的一版写法。

优点：

- 状态定义标准
- 很容易推广到 `309 / 123 / 188 / 714`
- 面试里如果面试官在考“股票系列套路”，这版很有价值

缺点：

- 对这一题本身来说，空间还可以继续压缩

## 方法四：状态压缩 DP

### 思路

观察方法三会发现：

第 `i` 天只依赖第 `i - 1` 天。

也就是说，我们并不需要整张 `dp` 表，只需要保留前一天的两个状态：

- `cash`：当天结束时手里没股票的最大利润
- `hold`：当天结束时手里有股票的最大利润

初始时：

```text
cash = 0
hold = -prices[0]
```

每天更新：

```text
new_cash = max(cash, hold + price)
new_hold = max(hold, cash - price)
```

注意这里一定要先算出 `new_cash` 和 `new_hold`，
因为它们都应该基于“上一天”的状态来转移。

### 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices:
            return 0

        cash = 0
        hold = -prices[0]

        for price in prices[1:]:
            prev_cash = cash
            prev_hold = hold
            cash = max(prev_cash, prev_hold + price)
            hold = max(prev_hold, prev_cash - price)

        return cash
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 评价

这是股票状态机的标准压缩版。

优点：

- 保留了完整的 DP 含义
- 空间已经是最优
- 非常适合为后面的股票系列题打基础

缺点：

- 对于 `122` 这一题来说，它还不是最容易一眼想到的结论

因为这题还可以继续化简成一个更短的贪心写法。

## 方法五：贪心（最优解）

### 先说结论

这题的最优策略是：

> **把所有相邻两天之间的正利润全部加起来。**

也就是：

```text
如果 prices[i] > prices[i - 1]
就把 prices[i] - prices[i - 1] 加进答案
```

### 为什么这件事是对的

这是这题最值得真正理解的地方。

假设有一段连续上涨：

```text
1, 2, 3, 4, 5
```

如果你选择：

- 第一天买入
- 第五天卖出

利润是：

```text
5 - 1 = 4
```

如果你改成每天都把上涨差价赚到：

- `2 - 1 = 1`
- `3 - 2 = 1`
- `4 - 3 = 1`
- `5 - 4 = 1`

加起来也是：

```text
1 + 1 + 1 + 1 = 4
```

也就是说：

```text
5 - 1 = (2 - 1) + (3 - 2) + (4 - 3) + (5 - 4)
```

这说明一整段上涨区间的总利润，等于里面所有正的相邻差值之和。

所以：

- 遇到上涨，就把这段上涨赚下来
- 遇到下跌，就不要把这段亏损带进利润里

最终把所有正差值相加，就是全局最优。

### 为什么这题可以贪心，但别的股票题不一定行

因为这题刚好满足这几个条件：

- 可以交易很多次
- 没有手续费
- 没有冷冻期
- 没有交易次数上限

所以一次长上涨，可以自由拆成很多段小上涨，利润完全不变。

但如果加入：

- 冷冻期
- 手续费
- 最多只能交易两次 / `k` 次

那这个贪心就不一定成立了，必须回到 DP。

这也是为什么：

- `122` 可以贪心
- `309 / 714 / 123 / 188` 通常要靠状态机 DP

### 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        profit = 0

        for i in range(1, len(prices)):
            if prices[i] > prices[i - 1]:
                profit += prices[i] - prices[i - 1]

        return profit
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 评价

这是这道题最短、最漂亮、也最常见的最优写法。

优点：

- 代码最短
- 复杂度最优
- 正确性不难解释

缺点：

- 如果你只背结论，不理解为什么能拆成所有正差值
- 那面试官一追问，容易说不清

## 哪个方法最适合面试

### 结论

**如果只看这道题本身，最适合面试的是：方法五，贪心。**

### 原因

#### 方法一：暴力递归

- 适合起步
- 但会超时
- 不能作为最终答案

#### 方法二：记忆化递归

- 能通过
- 但递归写法不够利落

#### 方法三：二维 DP

- 很标准
- 很适合讲股票状态机
- 对后续股票系列非常重要

#### 方法四：状态压缩 DP

- 很稳
- 很通用
- 如果面试官想顺着追问 `309/123/188`，这一版非常有价值

#### 方法五：贪心

- 对本题最短、最优
- 证明不复杂
- 面试现场最好写

所以对 `122` 这题本身来说：

> **方法五最适合面试，方法四最适合迁移到股票系列。**

---

## 最适合面试的方法：详细讲解

### 1. 先把题目本质说清楚

这题和第 121 题最大的区别是：

- 第 121 题只能交易一次
- 这题可以交易很多次

所以这题不再是“找一次最优买卖”，而是：

> 只要某一段上涨能赚钱，就应该把这段利润拿到。

### 2. 为什么可以把长上涨拆开

假设价格是：

```text
1, 3, 5
```

你可以：

- 第一天买，第 3 天卖，赚 `5 - 1 = 4`

也可以：

- 第一天买，第 2 天卖，赚 `2`
- 第 2 天买，第 3 天卖，赚 `2`

总利润仍然是：

```text
4
```

本质原因是：

```text
5 - 1 = (3 - 1) + (5 - 3)
```

只要没有手续费、冷冻期、次数限制，这种拆分就不会损失利润。

### 3. 为什么只加正差值就够了

如果：

```text
prices[i] > prices[i - 1]
```

说明昨天买、今天卖是赚钱的，
那么这段差值就应该贡献到最终利润里。

如果：

```text
prices[i] <= prices[i - 1]
```

说明这一段没有正收益，
把它加进去只会让利润不变或者变差，所以直接跳过。

因此：

- 所有应该赚到的钱，都体现在正差值里
- 所有不该拿的下跌或持平，都被自动忽略

### 4. 为什么这样不会漏掉更优方案

因为任何合法交易序列，本质上都只是在若干个上涨区间里获利。

而每个上涨区间的利润，都可以拆成相邻正差值之和。

所以无论你是：

- 整段买卖
- 还是拆成多段买卖

最终最多也就是把所有正差值都赚到。

而贪心算法恰好把这些正差值全部拿到了，因此就是最优解。

### 5. 面试时推荐怎么讲

你可以这样说：

> 这题允许无限次交易，而且没有手续费、冷冻期和交易次数限制。所以一整段上涨区间的利润，可以等价拆成每天的上涨差价之和。于是我只需要遍历数组，把所有 `prices[i] - prices[i - 1] > 0` 的部分累加起来，就得到了最大利润。

这套讲法很短，但逻辑是完整的。

### 面试最推荐代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        profit = 0

        for i in range(1, len(prices)):
            if prices[i] > prices[i - 1]:
                profit += prices[i] - prices[i - 1]

        return profit
```

## 总结

### 递进关系

1. **暴力递归**
   - 把每天的买 / 卖 / 不动状态想清楚
   - 是所有后续方法的起点

2. **记忆化递归**
   - 去掉重复状态
   - 自然过渡到股票 DP

3. **二维 DP**
   - 标准状态机写法
   - 最适合和股票系列其他题一起记

4. **状态压缩 DP**
   - 保留核心状态
   - 把空间降到 `O(1)`

5. **贪心**
   - 抓住本题没有额外限制的特殊性质
   - 直接把所有正差值累加
   - 是本题最优、最简洁的解法

### 一句话记忆

> **第 122 题的本质，是把所有上涨的那部分利润都赚到。**
