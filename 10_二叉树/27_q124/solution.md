# LeetCode 124 - 二叉树中的最大路径和（Binary Tree Maximum Path Sum）

## 题目

给你一棵二叉树的根节点 `root`，返回这棵树中的最大路径和。

路径的定义：

```text
从树中任意一个节点出发，沿着父子边走到任意另一个节点。
路径中每个节点最多出现一次。
路径至少包含一个节点。
路径不一定经过根节点。
路径也不要求从叶子到叶子。
```

例如：

```text
      -10
      /  \
     9   20
        /  \
       15   7
```

最大路径是：

```text
15 -> 20 -> 7
```

路径和是：

```text
15 + 20 + 7 = 42
```

所以答案是：

```text
42
```

---

## 先说结论

第 124 题是二叉树里非常经典的“路径贡献”问题。

从简单到最优，可以这样理解：

1. 图上暴力枚举所有路径：最直观，帮助理解“路径可以从任意节点到任意节点”
2. 枚举每个节点作为路径最高点：开始接近树形思路，但会重复计算
3. 一次 DFS 计算贡献值：`O(n)`，**最适合面试**

最适合面试的方法是：

```text
DFS 后序遍历 + 全局最大路径和
```

这题最关键的区别是：

```text
经过当前节点的最大路径和
```

和：

```text
当前节点能向父节点提供的最大贡献值
```

不是同一个东西。

这个区别吃透了，第 124 题就通了。

---

## 这题本质是什么

这题问的是：

```text
树中任意一条路径的最大节点和
```

路径可以长这样：

```text
左子树某个节点 -> ... -> 当前节点 -> ... -> 右子树某个节点
```

比如：

```text
      20
     /  \
    15   7
```

最大路径可以是：

```text
15 -> 20 -> 7
```

这条路径在节点 `20` 这里发生了“拐弯”：

```text
从左边上来，经过 20，再往右边下去
```

所以对于每个节点，我们都要考虑：

```text
如果路径经过我，并且可以同时连接我的左边和右边，最大是多少？
```

但是当这个节点要继续向父节点连接时，就不能同时带上左右两边。

因为路径不能分叉。

比如：

```text
        父节点
          |
         20
        /  \
       15   7
```

如果 `20` 要向父节点返回一条路径，那么只能返回：

```text
20 -> 15
```

或者：

```text
20 -> 7
```

不能返回：

```text
15 -> 20 -> 7
```

再接父节点。

因为那样路径会在 `20` 分叉。

这就是本题最核心的点。

---

## 最容易错的地方

### 1. 以为路径必须从根节点开始

这题路径可以从任意节点开始。

比如：

```text
      -10
      /  \
     9   20
        /  \
       15   7
```

最大路径是：

```text
15 -> 20 -> 7
```

它不经过根节点 `-10`。

### 2. 负数贡献不能强行带上

如果某个子树能提供的最大贡献是负数，那带上它只会让路径和变小。

所以最优解里会写：

```python
left_gain = max(dfs(node.left), 0)
right_gain = max(dfs(node.right), 0)
```

含义是：

```text
如果左子树贡献为负，就当作不要左子树。
如果右子树贡献为负，就当作不要右子树。
```

### 3. 返回值不能同时带左右子树

更新全局答案时，可以同时用左右子树：

```python
current_path = node.val + left_gain + right_gain
```

但是返回给父节点时，只能选一边：

```python
return node.val + max(left_gain, right_gain)
```

因为返回给父节点的路径必须是一条单链，不能分叉。

## 解法一：图上暴力枚举所有路径

对应文件：

```text
10_二叉树/27_q124/solution_1_bruteforce_graph.py
```

### 思路

这题的路径可以从任意节点到任意节点。

最直观但最暴力的想法是：

```text
把二叉树看成一张无向图。
从每个节点出发，DFS 到所有能到达的节点。
每走出一条路径，就计算路径和。
```

因为树中任意两个节点之间只有一条简单路径。

所以从每个起点 DFS 一遍，就可以枚举所有路径。

例如：

```text
      -10
      /  \
     9   20
        /  \
       15   7
```

把它看成无向图：

```text
-10 -- 9
-10 -- 20
20 -- 15
20 -- 7
```

从 `15` 出发，可以走到：

```text
15
15 -> 20
15 -> 20 -> 7
15 -> 20 -> -10
15 -> 20 -> -10 -> 9
```

其中：

```text
15 -> 20 -> 7
```

路径和是：

```text
42
```

### 对应代码思路

先收集所有节点，并建立无向邻接表：

```python
graph[node].append(child)
graph[child].append(node)
```

然后从每个节点出发 DFS：

```python
for start in nodes:
    dfs(start, None, 0)
```

DFS 时维护当前路径和：

```python
current_sum += node.val
ans = max(ans, current_sum)
```

### 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(n)`

为什么是 `O(n^2)`？

因为有 `n` 个起点。

从每个起点 DFS 最多访问 `n` 个节点。

这个方法非常直观，但面试不推荐作为最终答案。

它的价值是帮助你理解：

```text
124 的路径真的可以是任意节点到任意节点。
```

## 解法二：枚举每个节点作为路径最高点

对应文件：

```text
10_二叉树/27_q124/solution_2_enumerate_peak.py
```

### 思路

在一棵二叉树里，任意一条路径都有一个“最高点”。

这里的“最高点”不是值最大，而是离根更近的那个拐点。

比如路径：

```text
15 -> 20 -> 7
```

它的最高点是：

```text
20
```

因为路径从 `20` 的左子树上来，又往 `20` 的右子树下去。

所以我们可以枚举每个节点 `node`，假设它是这条最大路径的最高点。

那么经过 `node` 的最大路径和是：

```text
node.val + 左边向下最大贡献 + 右边向下最大贡献
```

如果某边贡献是负数，就不要那一边。

写成公式：

```python
left_gain = max(max_down(node.left), 0)
right_gain = max(max_down(node.right), 0)
path_sum = node.val + left_gain + right_gain
```

然后枚举所有节点，取最大值。

### 什么是 max_down

`max_down(node)` 表示：

```text
从 node 出发，只能一路往下走，能得到的最大路径和。
```

它不能同时走左边和右边。

因为它是一条往下延伸的单链。

所以：

```python
max_down(node) = node.val + max(
    max_down(node.left),
    max_down(node.right),
    0,
)
```

### 用例子看

```text
      20
     /  \
    15   7
```

对于节点 `20`：

```text
left_gain = 15
right_gain = 7
path_sum = 20 + 15 + 7 = 42
```

所以答案可以更新为 `42`。

### 为什么它还不是最优

这个方法已经非常接近最优解了。

但问题是：

```text
每枚举一个节点，都要重新计算它左右子树的 max_down。
```

很多子树会被重复计算。

所以最坏时间复杂度仍然可能是：

```text
O(n^2)
```

优化方向也很自然：

```text
能不能在一次 DFS 里，同时完成 max_down 和全局答案更新？
```

这就来到解法三。

## 解法三：DFS 计算最大贡献值

对应文件：

```text
10_二叉树/27_q124/solution_3_dfs.py
```

## 这是最适合面试的方法

如果面试里写第 124 题，最推荐这一版。

原因是：

1. 时间复杂度 `O(n)`，每个节点只处理一次
2. 不需要把树转成图
3. 不需要重复计算子树贡献
4. 思路正好对应树形 DP 的核心：返回贡献值，更新全局答案

---

### 先明确 dfs(node) 的含义

最优解里的 `dfs(node)` 不是返回“node 子树里的最大路径和”。

它返回的是：

```text
从 node 出发，向下走到某个节点，能给父节点提供的最大贡献值。
```

也就是：

```text
node -> 左边某条链
```

或者：

```text
node -> 右边某条链
```

只能选一边。

因为它要继续接到父节点上，不能分叉。

---

### 当前节点能形成的完整路径

虽然 `dfs(node)` 返回时只能选一边，但在当前节点这里更新答案时，可以同时使用左右两边。

原因是：

```text
一条完整路径可以在当前节点这里拐弯。
```

所以当前节点作为最高点时，路径是：

```text
左边最大贡献 -> node -> 右边最大贡献
```

路径和是：

```python
current_path = node.val + left_gain + right_gain
```

用它更新全局答案：

```python
ans = max(ans, current_path)
```

---

### 返回给父节点的贡献值

但是返回给父节点时，只能返回一条单链。

所以只能选左右贡献较大的一边：

```python
return node.val + max(left_gain, right_gain)
```

不能返回：

```python
node.val + left_gain + right_gain
```

因为这样就把左右两边都带给父节点了，路径会分叉。

### 用例子彻底区分

看这棵树：

```text
        -10
        /  \
       9   20
          /  \
         15   7
```

对于节点 `20`：

左贡献：

```text
left_gain = 15
```

右贡献：

```text
right_gain = 7
```

经过 `20` 的完整路径可以是：

```text
15 -> 20 -> 7
```

路径和：

```text
15 + 20 + 7 = 42
```

所以全局答案可以更新为：

```python
ans = max(ans, 42)
```

但是 `20` 返回给父节点 `-10` 的贡献不能是 `42`。

因为如果 `20` 把 `15 -> 20 -> 7` 整条路径都交给 `-10`，再接上 `-10`，路径会变成：

```text
15 -> 20 -> 7
          |
         -10
```

这不是一条合法的简单路径，而是分叉了。

所以 `20` 只能返回：

```text
20 -> 15
```

或者：

```text
20 -> 7
```

取更大的：

```python
return 20 + max(15, 7)
```

也就是：

```text
35
```

---

### 负数为什么要丢掉

看这个例子：

```text
    2
   /
 -1
```

如果把左子树带上：

```text
2 + (-1) = 1
```

不带左子树：

```text
2
```

显然不带更好。

所以代码里会写：

```python
left_gain = max(dfs(node.left), 0)
right_gain = max(dfs(node.right), 0)
```

意思是：

```text
负贡献直接舍弃，当作 0。
```

这也保证了全是负数的树不会错误返回 0。

因为全局答案 `ans` 初始化为：

```python
ans = -inf
```

每个节点都会用：

```python
node.val + left_gain + right_gain
```

更新答案。

如果树只有一个节点 `-3`，那么：

```text
current_path = -3
```

答案就是 `-3`。

---

### 对应代码

核心代码是：

```python
ans = float("-inf")

def dfs(node):
    nonlocal ans

    if not node:
        return 0

    left_gain = max(dfs(node.left), 0)
    right_gain = max(dfs(node.right), 0)

    ans = max(ans, node.val + left_gain + right_gain)

    return node.val + max(left_gain, right_gain)
```

最后：

```python
dfs(root)
return ans
```

### 复杂度

- 时间复杂度：`O(n)`，每个节点只访问一次
- 空间复杂度：`O(h)`，递归栈

其中：

```text
n 是节点数量
h 是树高
```

平衡树时：

```text
h = O(log n)
```

链状树时：

```text
h = O(n)
```

## 面试推荐

第 124 题最适合面试的方法是：

```text
DFS 后序遍历 + 最大贡献值
```

面试时可以这样讲：

```text
这题的路径可以从任意节点开始、到任意节点结束，不一定经过根。
我用 DFS 计算每个节点能向父节点提供的最大贡献值。
对于一个节点 node，左子树和右子树如果贡献为负，就不选，按 0 处理。
经过 node 的最大路径可以同时连接左贡献、node 自身、右贡献，
所以用 node.val + left_gain + right_gain 更新全局答案。
但是返回给父节点时，路径不能分叉，只能选择左边或右边贡献较大的一条，
所以返回 node.val + max(left_gain, right_gain)。
每个节点只处理一次，所以时间复杂度 O(n)。
```

## 推荐记忆顺序

1. 先记住路径可以在哪里：

```text
任意节点 -> 任意节点
```

2. 再记住当前节点更新答案：

```python
ans = max(ans, node.val + left_gain + right_gain)
```

3. 最后记住返回给父节点：

```python
return node.val + max(left_gain, right_gain)
```

一句话：

```text
更新答案可以左右都要，返回父节点只能选一边。
```
