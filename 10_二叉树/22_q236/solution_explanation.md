# LeetCode 236 - 二叉树的最近公共祖先（Lowest Common Ancestor of a Binary Tree）

## 题目

给定一棵二叉树，以及树中的两个节点 `p`、`q`，返回它们的最近公共祖先。

祖先节点可以是节点自己。也就是说，如果 `p` 是 `q` 的祖先，答案就是 `p`。

例如：

```text
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

当 `p`、`q` 分别指向值为 `5`、`1` 的节点时，答案是值为 `3` 的节点；当它们分别指向值为 `5`、`4` 的节点时，答案是值为 `5` 的节点。

题目保证 `p` 和 `q` 都在树中，节点值唯一。

## 先说结论

从直观到适合面试的写法，可以掌握两种：

1. 分别找出根到 `p`、根到 `q` 的路径，再找路径最后一个相同节点：思路直观，适合理解。
2. 后序递归：让左右子树报告是否找到 `p` 或 `q`，在分叉处确定答案，**最适合面试**。

两种方法时间复杂度都是 `O(n)`。路径法保存两条路径；递归法只使用递归栈，空间复杂度都是 `O(h)`，其中 `h` 是树高。

## 这题本质是什么

从根节点往下看，`p` 和 `q` 的路径会有一段相同的前缀：

```text
根 -> ... -> 最近公共祖先
```

最近公共祖先就是这两条根路径上**最后一个相同的节点**。

递归解法不显式保存路径，而是从叶子往上返回信息：

```text
左子树找到一个目标，右子树找到另一个目标：当前节点就是最近公共祖先
只有一侧找到目标：把那一侧的结果继续向上传
```

## 解法一：分别找路径

对应文件：[solution_1_root_paths.py](solution_1_root_paths.py)

### 思路

先用 DFS 找到从根节点到 `p` 的路径，再找根节点到 `q` 的路径。比较两条路径：

```text
p 的路径：3 -> 5
q 的路径：3 -> 5 -> 2 -> 4
```

从头开始相同的是值分别为 `3`、`5` 的节点，最后一个相同节点，也就是值为 `5` 的节点，就是最近公共祖先。

找路径时，进入节点就先把它放进 `path`。如果左右子树都没找到目标，就把该节点移出路径；找到目标时则保留路径并返回。

### 复杂度

- 时间复杂度：`O(n)`，最多遍历整棵树两次。
- 空间复杂度：`O(h)`，递归栈和两条路径最多各保存树高数量的节点。

## 解法二：后序递归（面试推荐）

对应文件：[solution_2_recursive.py](solution_2_recursive.py)

### 思路怎么来

先不要考虑整棵树，只看当前节点能从左右两边收到什么结果。

假设 `p` 指向值为 `6` 的节点，`q` 指向值为 `4` 的节点：

```text
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

下文中的“值为 `2` 的节点”表示节点值是 `2`，不是遍历到的第二个节点。其他数字同理。

先看值为 `2` 的节点：

```text
值为 2 的节点：左子树没有 p、q，返回 None
值为 2 的节点：右子树找到了 q，返回值为 4 的节点
```

值为 `2` 的节点只收到一个有效结果，也就是值为 `4` 的节点。这只能说明目标 `q` 在它下面，还不能说明它是公共祖先，所以它把这个结果原样返回给值为 `5` 的父节点。

再看值为 `5` 的节点：

```text
值为 5 的节点：左子树找到了 p，返回值为 6 的节点
值为 5 的节点：右子树返回值为 4 的节点
```

值为 `5` 的节点同时从左边收到值为 `6` 的节点、从右边收到值为 `4` 的节点，说明两个目标分别在它的左右两边。因此，值为 `5` 的节点就是它们第一次分开的地方，也就是最近公共祖先，于是返回这个节点。

最后看值为 `3` 的根节点：

```text
值为 3 的节点：左子树返回值为 5 的节点
值为 3 的节点：右子树返回 None
```

值为 `3` 的节点只有左边有结果，所以不能把答案改成它，只需要继续返回左边传来的、值为 `5` 的节点。最终返回的这个节点就是答案。

整个返回过程可以压缩成：

```text
当前节点值为 2：左边 None，右边是值为 4 的节点 -> 返回值为 4 的节点
当前节点值为 5：左边是值为 6 的节点，右边是值为 4 的节点 -> 返回当前这个值为 5 的节点
当前节点值为 3：左边是值为 5 的节点，右边 None -> 返回值为 5 的节点
```

因此，每个节点只需要做下面的判断：

```text
左右都有结果：两个目标从这里分开，返回当前节点
只有一边有结果：当前节点还不是分叉点，把这个结果继续向上返回
左右都没有结果：返回 None
```

### 代码

```python
if root is None:
    return None
if root is p or root is q:
    return root

left_result = self.lowestCommonAncestor(root.left, p, q)
right_result = self.lowestCommonAncestor(root.right, p, q)

if left_result is not None and right_result is not None:
    return root
if left_result is not None:
    return left_result
return right_result
```

这段代码按三步执行：

1. 空节点里肯定没有目标，所以返回 `None`。
2. 当前节点就是 `p` 或 `q`，说明已经找到一个目标，直接返回当前节点。
3. 否则分别搜索左右子树，根据左右结果决定返回什么。

`root is p` 比较的是节点对象是不是同一个，不是比较节点值。LeetCode 传入的 `p`、`q` 本身就是树中的节点对象。

### 为什么遇到 p 或 q 就直接返回

以 `p` 指向值为 `5` 的节点、`q` 指向值为 `4` 的节点为例。递归来到值为 `5` 的节点时，发现当前节点就是 `p`，于是直接返回这个节点。

这时不需要再向下寻找 `4`，因为题目允许节点是自己的祖先，而 `4` 确实在 `5` 的子树里，所以答案就是 `5`。

如果另一个目标不在值为 `5` 的节点下面，也没有问题。这个节点会先被返回到上层；当某个祖先从另一边找到另一个目标时，那个祖先就会成为新的分叉点。

### 正确性要点

递归先处理左右子树，再处理当前节点，所以它会先在更低的位置判断。最下面第一个同时收到左右结果的节点，就是离 `p`、`q` 最近的公共祖先。这个答案向上传递时，上面的节点只会从一侧收到它，因此不会把答案替换成更高的祖先。

### 复杂度

- 时间复杂度：`O(n)`，每个节点最多访问一次。
- 空间复杂度：`O(h)`，空间来自递归调用栈；平衡树为 `O(log n)`，最坏退化树为 `O(n)`。

## 为什么递归法最适合面试

它直接利用二叉树的递归结构，不需要额外保存两条路径，也不需要父指针或哈希表。面试时解释清楚一件事就够了：**每棵子树返回它找到的目标；左右两边都找到时，当前节点就是分叉点。**

要特别说明 `root is p or root is q` 这个基础情况。它既能找到目标，也能处理一个目标是另一个目标祖先的情况。

## 和二叉搜索树版本的区别

第 235 题是二叉搜索树，可以根据节点值大小决定往左还是往右；第 236 题是普通二叉树，没有大小顺序，必须搜索左右子树，再根据返回结果判断分叉位置。
