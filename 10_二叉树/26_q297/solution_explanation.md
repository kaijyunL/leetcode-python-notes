# LeetCode 297 - 二叉树的序列化与反序列化（Serialize and Deserialize Binary Tree）

## 题目

实现两个操作：

```text
serialize：把二叉树变成字符串
deserialize：把字符串还原成原来的二叉树
```

要求反序列化后恢复原树的结构和节点值。字符串格式由我们自己设计，只要 `serialize` 和 `deserialize` 使用同一种格式即可。

## 先说结论

这题最重要的不是选前序还是层序，而是：**序列化时必须记录空节点**。否则，只记录节点值会丢失左右孩子的位置，反序列化无法确定树的结构。

这里给出两种方法：

1. BFS 层序遍历 + 空节点标记：执行过程直观，不依赖递归，**更适合作为 Python 面试实现**。
2. DFS 前序遍历 + 空节点标记：代码更短，是经典写法，但递归深度可能受 Python 调用栈限制。

两种方法的时间复杂度都是 `O(n)`。它们使用不同的编码顺序，因此每种方法的 `serialize` 和 `deserialize` 必须配套使用。

## 为什么必须记录空节点

只按层序记录非空节点值，下面两棵树都会得到 `[1, 2]`：

```text
    1       1
   /         \
  2           2
```

所以序列里需要用特殊标记表示空孩子。本文用 `#` 表示空节点，逗号分隔每个 token。

例如这棵树：

```text
      1
     / \
    2   3
       / \
      4   5
```

BFS 层序编码为：

```text
1,2,3,#,#,4,5,#,#,#,#
```

其中 `2` 后面的两个 `#` 表示值为 `2` 的节点没有左右孩子。其他 `#` 也分别表示对应位置为空。

## 解法一：BFS 层序遍历（面试推荐）

对应文件：[solution_1_bfs.py](solution_1_bfs.py)

### 序列化

用队列按层处理节点：

- 弹出空节点：写入 `#`，不再为它添加孩子。
- 弹出非空节点：写入节点值，并把它的左、右孩子都加入队列；孩子为空时也加入队列。

把上面的树按队列顺序处理：

```text
弹出 1：写入 1，加入 2、3
弹出 2：写入 2，加入 None、None
弹出 3：写入 3，加入 4、5
弹出两个 None：写入 #、#
弹出 4、5：写入 4、5，各自再加入两个 None
弹出四个 None：写入 #、#、#、#
```

因此得到：

```text
1,2,3,#,#,4,5,#,#,#,#
```

队列里的 `None` 只用来输出空位标记，不会继续产生新的孩子，所以遍历会结束。

### 反序列化

先读取第一个 token，创建根节点。之后每从队列取出一个非空节点，就从 token 序列中依次读取两个值，分别作为它的左孩子和右孩子：

```text
读取 1：创建根节点 1，接下来的 2、3 是它的左右孩子
读取 2：接下来的 #、# 表示它没有左右孩子
读取 3：接下来的 4、5 创建为它的左右孩子
读取 4：接下来的 #、# 表示它没有左右孩子
读取 5：接下来的 #、# 表示它没有左右孩子
```

反序列化队列里只放真实节点。读到 `#` 时，对应孩子保持 `None`，不加入队列。

### 关键点

序列化时，每个非空节点都输出两个孩子位置；反序列化时，每个非空节点也消费两个孩子 token。空节点标记让两边对树的结构有相同、完整的记录。

### 复杂度

- 时间复杂度：序列化和反序列化都是 `O(n)`，每个节点及其空孩子位置处理常数次。
- 空间复杂度：队列最坏为 `O(n)`；编码字符串本身也需要 `O(n)` 空间。

## 解法二：DFS 前序遍历

对应文件：[solution_2_recursive_dfs.py](solution_2_recursive_dfs.py)

### 序列化

前序顺序是：

```text
根 -> 左 -> 右
```

遇到空节点也写入 `#`。上面的树会编码为：

```text
1,2,#,#,3,4,#,#,5,#,#
```

### 反序列化

按相同的前序顺序读取 token：

1. 读到 `#`，当前子树为空，返回 `None`。
2. 读到数字，创建当前节点。
3. 接下来的 token 先递归构造左子树，再递归构造右子树。

因为序列化和反序列化使用同一个“根、左、右”的顺序，并且空孩子也占一个 token，所以树的结构可以唯一还原。

### 复杂度与限制

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`，包括编码数据；递归调用栈额外为 `O(h)`，`h` 是树高。
- 如果树退化成很深的单链，递归深度可能超过 Python 的默认限制并触发 `RecursionError`。本题节点数上限较大，所以 Python 面试实现更推荐前面的 BFS 版本。

## 面试时怎么讲

可以先说明：只保存非空节点会丢失左右孩子的位置，因此我要给空孩子也加特殊标记。然后选择 BFS：序列化时按层写节点值和 `#`；反序列化时按同一层序顺序，每个真实节点读取两个孩子 token。这样既说明了格式为何足以还原结构，也说明了编码与解码如何一一对应。
