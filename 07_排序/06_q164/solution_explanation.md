# LeetCode 164. 最大间距

## 题目理解

给定无序数组 `nums`，将它排序后，求相邻元素差值的最大值。

```text
nums = [3, 6, 9, 1]
排序后 = [1, 3, 6, 9]
相邻差值 = 2, 3, 3
答案 = 3
```

若元素个数小于 2，根本不存在相邻元素，返回 `0`。

题目的进阶要求是：

```text
时间 O(n)
空间 O(n)
```

因此普通比较排序的 `O(n log n)` 还不够。关键问题变成：**不真正排出所有元素，能不能直接找到最大相邻间距？**

---

## 方法一：排序后扫描

文件：`solution_1_sort_scan.py`

### 思路

先排序，再顺序比较每两个相邻元素的差：

```python
nums.sort()

for i in range(1, len(nums)):
    max_gap = max(max_gap, nums[i] - nums[i - 1])
```

排序后，题目要找的“相邻元素”就在数组的相邻下标处，因此扫描一次即可。

### 复杂度

- 时间复杂度：`O(n log n)`，排序占主导。
- 空间复杂度：取决于排序实现。当前 Python `list.sort()` 使用 Timsort，最坏可能使用 `O(n)` 辅助空间。

### 面试定位

这是自然的基线解法，也能通过没有线性时间限制的版本。但它不满足本题的进阶要求，接下来需要绕开完整排序。

---

## 方法二：桶 + 鸽笼原理（面试主推）

文件：`solution_2_bucket.py`

这是满足 `O(n)` 时间要求的解法。

### 第一步：最大间距至少有多大

设：

```text
n = 元素个数
min_value = 最小值
max_value = 最大值
range = max_value - min_value
```

排序后有 `n - 1` 个相邻间距，它们加起来正好是：

```text
range
```

因此平均间距为：

```text
range / (n - 1)
```

最大间距不可能小于平均间距。因为元素和桶宽度都是整数，定义：

```python
bucket_size = ceil(range / (n - 1))
```

那么一定有：

```text
最大间距 >= bucket_size
```

代码用整数计算向上取整：

```python
bucket_size = (range + n - 2) // (n - 1)
```

例如：

```text
nums = [3, 6, 9, 1]
min_value = 1
max_value = 9
range = 8
n - 1 = 3

bucket_size = ceil(8 / 3) = 3
```

### 第二步：为什么桶内不可能有答案

用宽度 `bucket_size` 将 `[min_value, max_value]` 分桶。桶下标为：

```python
bucket_index = (num - min_value) // bucket_size
```

同一个桶内任意两个整数的差值最多为：

```text
bucket_size - 1
```

而我们刚刚证明最大间距至少是：

```text
bucket_size
```

所以真正的最大相邻间距不可能发生在同一个桶内，只可能出现在两个相邻的非空桶之间。

这就是本题的关键。我们不需要保存桶内所有元素，也不需要对桶内排序；每个桶只保存：

```text
bucket_min：该桶最小值
bucket_max：该桶最大值
```

### 第三步：为什么比较 `当前桶最小值 - 前一非空桶最大值`

从左到右扫描桶。设前一个非空桶的最大值为 `previous_max`，当前非空桶的最小值为 `bucket_min[i]`。

这两个值在排序后必然相邻跨越了两个非空桶的边界，因此候选间距是：

```python
bucket_min[i] - previous_max
```

空桶必须跳过。空桶越多，说明两个非空桶之间的数值范围越大，最大间距反而越可能出现在这里。

### 过程举例

```text
nums = [3, 6, 9, 1]
min_value = 1
max_value = 9
n = 4
bucket_size = 3
```

桶下标与范围：

```text
桶 0： [1, 3]  -> 放入 1、3，min = 1，max = 3
桶 1： [4, 6]  -> 放入 6，  min = 6，max = 6
桶 2： [7, 9]  -> 放入 9，  min = 9，max = 9
```

扫描非空桶：

```text
桶 0：previous_max = 3
桶 1：6 - 3 = 3，previous_max 更新为 6
桶 2：9 - 6 = 3，previous_max 更新为 9
```

答案为 `3`。

再看空桶的价值：

```text
nums = [1, 3, 100]
n = 3
range = 99
bucket_size = ceil(99 / 2) = 50

桶 0：[1, 50]   -> 1、3，max = 3
桶 1：[51, 100] -> 100，min = 100

跨桶间距：100 - 3 = 97
```

桶内的 `1` 与 `3` 差值只有 `2`；最大间距自然出现在跨桶位置。

### 为什么桶的数量是 `O(n)`

桶数计算为：

```python
bucket_count = range // bucket_size + 1
```

因为：

```text
bucket_size >= range / (n - 1)
```

所以：

```text
range / bucket_size <= n - 1
```

即桶数最多为 `n`。因此：

```text
找最值：O(n)
元素入桶：O(n)
扫描桶：O(n)
```

总时间为 `O(n)`，桶数组空间为 `O(n)`。

### 边界处理

```text
len(nums) < 2：没有相邻元素，返回 0
min_value == max_value：所有数相同，返回 0
```

第二种情况必须提前返回，否则 `range = 0`，计算桶宽度时会出现除零问题。

### 面试中怎么解释

可以直接说：

```text
排序后 n 个数有 n-1 个间距，最大间距至少是整体范围除以 n-1 的向上取整。
我用这个值做桶宽度。这样同一桶内任意差值都小于这个下界，
不可能是答案；答案只会出现在相邻非空桶之间。
所以每个桶只记录最小值和最大值，扫描桶边界即可得到最大间距。
```

## 方法对比与选择

| 方法 | 时间复杂度 | 空间复杂度 | 是否满足进阶要求 | 面试定位 |
|---|---|---|---|---|
| 排序后扫描 | `O(n log n)` | 依排序实现而定 | 否 | 基线思路 |
| 桶 + 鸽笼原理 | `O(n)` | `O(n)` | 是 | 面试主推 |

本题最值得记住的结论是：

```text
最大相邻间距一定发生在桶之间，不会发生在同一个桶内。
```

这个结论来自“最大间距至少等于平均间距的向上取整”，不是来自桶排序模板本身。
