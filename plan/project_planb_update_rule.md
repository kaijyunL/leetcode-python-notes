# planB 更新规则

## 原则

- 统一按“仓库覆盖”口径更新，不按正文历史勾选手工累计。
- 某题若仓库已有对应题目目录且目录内有文件，则标 `✅`，否则标 `⬜`。
- 主表和所有“推荐刷题顺序”表一起同步。
- 统计面板按专题汇总，总计按唯一题号去重。
- 章节标题只保留总题数，不再维护 `+✅` 这类手写计数。

## 更新步骤

1. 先扫描仓库题目目录，得到“已覆盖题号集合”。
   - 目录模式：`XX_专题名/YY_q题号`
   - 判定规则：题目目录存在，且目录内至少有一个文件

2. 更新 `plan/leetcode_study_planB.md` 里的主表状态列。
   - 主表表头：`| # | 题目 | 难度 | 关键点 | 状态 |`
   - 题号在已覆盖集合中则写 `✅`，否则写 `⬜`

3. 同步更新所有“推荐刷题顺序”表。
   - 表头补 `状态` 列
   - 推荐表里的状态按同题号与主表保持一致

4. 更新统计面板。
   - 各专题：`题数 = 该专题主表行数`
   - 各专题：`已覆盖 = 该专题主表中 ✅ 数量`
   - 各专题：`覆盖率 = 已覆盖 / 题数`
   - 总计：按唯一题号去重后统计，不按专题直接相加

5. 清理手写旧数据。
   - 顶部摘要改为“仓库覆盖：X / 246”这类口径
   - 章节标题里的 `+1✅`、`+3✅` 这类手写计数去掉，只保留总题数

## 快速检查

- 主表、推荐表、统计面板三处口径一致
- 统计面板总计按唯一题号去重
- 推荐表全部都有 `状态` 列
