# LeetCode 108 - 将有序数组转换为二叉搜索树（Convert Sorted Array to Binary Search Tree）

## 题目

给你一个整数数组 `nums`，其中元素已经按升序排列。

请你把它转换成一棵高度平衡的二叉搜索树。

高度平衡的意思是：

```text
每个节点的左右子树高度差不超过 1
```

例如：

```text
nums = [-10, -3, 0, 5, 9]
```

一种合法答案是：

```text
      0
     / \
   -10  5
     \   \
     -3   9
```

也可以是：

```text
      0
     / \
   -3   9
   /   /
-10   5
```

这题答案不唯一。

只要满足：

```text
1. 是二叉搜索树
2. 高度平衡
3. 中序遍历结果仍然是 nums
```

就可以。

---

## 先说结论

第 108 题是 BST 构造题的入门题。

核心只有一句话：

```text
有序数组的中点做根，左半边递归建左子树，右半边递归建右子树。
```

从简单到最优，推荐掌握两种写法：

1. 递归 + 数组切片：最直观，适合理解
2. 递归 + 下标边界：避免创建新数组，**最适合面试**

这题不需要复杂技巧。

它真正考的是：

```text
能不能把 BST 的中序有序性质，和二分分治联系起来。
```

---

## 这题本质是什么

二叉搜索树有一个核心性质：

```text
左子树所有值 < 根节点 < 右子树所有值
```

如果对 BST 做中序遍历，顺序一定是：

```text
左 -> 根 -> 右
```

所以 BST 的中序遍历结果一定是升序。

题目直接给了一个升序数组：

```text
[-10, -3, 0, 5, 9]
```

这就相当于告诉我们：

```text
这棵 BST 的中序遍历结果就是这个数组。
```

现在问题变成：

```text
怎么从一个有序数组里选根节点，才能让树尽量平衡？
```

答案是：

```text
选中间元素做根。
```

因为中间元素左边数量和右边数量最接近。

这样递归下去，每一层都尽量把节点分成左右两半，树就会高度平衡。

---

## 为什么一定选中点

如果选最左边元素做根：

```text
nums = [-10, -3, 0, 5, 9]
root = -10
```

左边没有元素，右边还有 4 个元素。

树会变成偏右链：

```text
-10
  \
  -3
    \
     0
      \
       5
        \
         9
```

这不是高度平衡。

如果选最右边元素做根，也会变成偏左链。

所以应该选中点：

```text
nums = [-10, -3, 0, 5, 9]
                 ^
               root = 0
```

左边有：

```text
[-10, -3]
```

右边有：

```text
[5, 9]
```

左右数量一样，最平衡。

---

## 解法一：递归 + 数组切片

对应文件：

```text
11_二叉搜索树/01_q108/solution_1_slice.py
```

### 思路

最直观的方法是直接把数组切开。

当前数组：

```text
nums = [-10, -3, 0, 5, 9]
```

取中点：

```python
mid = len(nums) // 2
```

中点元素作为根：

```python
root = TreeNode(nums[mid])
```

左半边构造左子树：

```python
root.left = sortedArrayToBST(nums[:mid])
```

右半边构造右子树：

```python
root.right = sortedArrayToBST(nums[mid + 1:])
```

递归终止条件：

```python
if not nums:
    return None
```

### 用例子走一遍

```text
nums = [-10, -3, 0, 5, 9]
```

第一次：

```text
mid = 2
root = nums[2] = 0
```

拆成：

```text
左数组：[-10, -3]
右数组：[5, 9]
```

递归构造左数组：

```text
nums = [-10, -3]
mid = 1
root = -3
左数组：[-10]
右数组：[]
```

递归构造右数组：

```text
nums = [5, 9]
mid = 1
root = 9
左数组：[5]
右数组：[]
```

得到的树可以是：

```text
      0
     / \
   -3   9
   /   /
-10   5
```

这是合法答案。

### 为什么它不是面试最优

这个方法非常适合理解。

但它每次递归都创建新数组：

```python
nums[:mid]
nums[mid + 1:]
```

切片会带来额外空间开销。

面试时可以先讲这个思路，但最终建议写解法二。

### 复杂度

- 时间复杂度：`O(n)`，每个节点创建一次
- 空间复杂度：`O(n)`，切片创建新数组，递归栈也会占空间

## 解法二：递归 + 下标边界

对应文件：

```text
11_二叉搜索树/01_q108/solution_2_index.py
```

## 这是最适合面试的方法

如果面试里写第 108 题，最推荐这一版。

原因是：

1. 思路仍然是最自然的分治
2. 不创建新数组
3. 每个节点只处理一次
4. 代码短，边界也不复杂

一句话总结：

```text
用 nums[left ... right] 构造当前子树；
取中点 mid 做根；
left ... mid - 1 构造左子树；
mid + 1 ... right 构造右子树。
```

---

### 先把两个下标翻译成人话

定义递归函数：

```python
def build(left, right):
```

含义是：

```text
用 nums[left ... right] 这一段有序数组，构造一棵高度平衡 BST。
```

注意这里是左闭右闭区间。

如果换成 Python 真切片，就是：

```text
nums[left : right + 1]
```

比如：

```text
nums[0 ... 4] 等价于 nums[0:5]
nums[0 ... 1] 等价于 nums[0:2]
nums[3 ... 4] 等价于 nums[3:5]
```

---

### 用例子走一遍

```text
nums = [-10, -3, 0, 5, 9]
index =   0   1  2  3  4
```

第一次调用：

```python
build(0, 4)
```

意思是：

```text
用 nums[0 ... 4] = [-10, -3, 0, 5, 9] 构造整棵树
```

取中点：

```python
mid = (0 + 4) // 2
    = 2
```

根节点是：

```python
root = TreeNode(nums[2])  # 0
```

左子树用左半段：

```python
root.left = build(0, 1)
```

右子树用右半段：

```python
root.right = build(3, 4)
```

翻译成人话：

```text
用 nums[0 ... 1] = [-10, -3] 构造左子树
用 nums[3 ... 4] = [5, 9] 构造右子树
```

---

### 继续看左子树

左子树调用：

```python
build(0, 1)
```

当前数组段是：

```text
nums[0 ... 1] = [-10, -3]
```

取中点：

```python
mid = (0 + 1) // 2
    = 0
```

根节点是：

```python
root = TreeNode(nums[0])  # -10
```

左子树：

```python
build(0, -1)
```

这是空区间，返回 `None`。

右子树：

```python
build(1, 1)
```

就是：

```text
nums[1 ... 1] = [-3]
```

所以左半边最后会变成：

```text
-10
  \
  -3
```

这也是合法的。

如果你想让偶数长度数组时树形更偏另一边，也可以用右中点。

本题答案不唯一。

---

### 递归停止条件为什么是 left > right

代码里会写：

```python
if left > right:
    return None
```

意思是：

```text
当前数组段已经没有元素了。
```

比如上面的左子树：

```python
build(0, 1)
```

取 `mid = 0` 后，左边继续递归：

```python
build(0, -1)
```

这里：

```text
left = 0
right = -1
```

也就是：

```text
nums[0 ... -1]
```

左边界已经超过右边界，说明没有节点，返回 `None`。

---

### 对应代码

核心代码是：

```python
def build(left, right):
    if left > right:
        return None

    mid = (left + right) // 2
    root = TreeNode(nums[mid])

    root.left = build(left, mid - 1)
    root.right = build(mid + 1, right)

    return root

return build(0, len(nums) - 1)
```

### 为什么它满足 BST

因为 `nums` 是升序数组。

当 `nums[mid]` 做根时：

```text
nums[left ... mid - 1] 里的所有值都小于 nums[mid]
nums[mid + 1 ... right] 里的所有值都大于 nums[mid]
```

所以：

```text
左子树所有值 < 根节点 < 右子树所有值
```

这正好满足 BST 性质。

### 为什么它高度平衡

每次都取中点。

所以左右两边元素数量最多差 1。

递归到每一层都是这样。

因此最终整棵树高度平衡。

### 复杂度

- 时间复杂度：`O(n)`，每个数组元素创建一个节点
- 空间复杂度：`O(log n)`，平衡树递归栈高度是 `log n`

如果不把返回的树本身算作额外空间，这就是本题最优解。

## 面试推荐

第 108 题最适合面试的方法是：

```text
递归 + 下标边界
```

面试时可以这样讲：

```text
因为数组是升序的，而 BST 的中序遍历也是升序的，
所以这个数组可以看作目标 BST 的中序遍历结果。
为了让树高度平衡，我每次取当前数组区间的中点作为根。
中点左边的元素都小于根，用来递归构造左子树。
中点右边的元素都大于根，用来递归构造右子树。
递归函数 build(left, right) 表示用 nums[left ... right] 构造一棵平衡 BST。
当 left > right 时，说明区间为空，返回 None。
每个元素只会成为一次根节点，所以时间复杂度 O(n)。
因为每次二分，递归深度是 O(log n)。
```
