# LeetCode 96 - 不同的二叉搜索树

## 题目

给你一个整数 `n` ，求恰好由 `n` 个节点组成，且节点值从 `1` 到 `n` 互不相同的二叉搜索树有多少种。

例如：

```text
输入：n = 3
输出：5
```

---

## 这题本质在考什么

这题看起来是在数树，其实本质是在数：

```text
当我们固定某个数字做根节点时，
左边能组成多少种 BST，
右边能组成多少种 BST。
```

因为 BST 满足：

```text
左子树所有值 < 根节点 < 右子树所有值
```

所以一旦根节点确定，左右两边能放哪些数字也就确定了。

如果根节点选 `i`：

```text
左子树只能用 1 ~ i-1，共 i-1 个节点
右子树只能用 i+1 ~ n，共 n-i 个节点
```

注意这里有个关键点：

```text
真正影响方案数的不是“具体值”，而是“节点个数”。
```

也就是说：

```text
由 {1,2,3} 组成 BST 的方案数
和由 {8,9,10} 组成 BST 的方案数
其实一样，因为它们都只有 3 个节点。
```

所以我们可以把问题抽象成：

```text
f(n) = 由 n 个节点组成 BST 的方案数
```

---

## 递推关系怎么来的

设 `f(n)` 表示 `n` 个节点能组成多少种 BST。

如果根节点选第 `i` 小的数，那么：

```text
左子树节点数 = i - 1
右子树节点数 = n - i
```

左子树有 `f(i - 1)` 种构造方式，
右子树有 `f(n - i)` 种构造方式。

左右子树彼此独立，所以：

```text
以 i 为根的方案数 = f(i - 1) * f(n - i)
```

把所有根节点情况加起来：

```text
f(n) = Σ f(i - 1) * f(n - i)   ，其中 i 从 1 到 n
```

也可以写成：

```text
f(n) = f(0)*f(n-1) + f(1)*f(n-2) + ... + f(n-1)*f(0)
```

这就是本题的核心递推式。

---

## 为什么 `f(0) = 1`

这点面试很常问。

空树看起来“没有树”，为什么不是 `0`？

因为这里我们数的是：

```text
构造方式的数量
```

当某一边没有节点时，空树也算一种合法情况，否则乘法就没法成立。

例如根节点选最小值时：

```text
左子树没有节点
右子树有 n-1 个节点
```

如果把空树记成 `0`，那这一整种情况都会被乘成 `0`，显然不对。

所以必须定义：

```text
f(0) = 1
f(1) = 1
```

---

## 解法总览

我们按“从简单暴力到最优”的顺序来理解：

1. 暴力递归：直接套递推式，重复计算很多子问题
2. 记忆化搜索：在递归基础上缓存结果
3. 动态规划：自底向上填表，**最适合面试**
4. 卡特兰数公式：数学最优解，时间更好

注意：

```text
如果问“最适合面试”，优先讲动态规划。
如果问“复杂度最优”，卡特兰数公式更优。
```

---

## 解法一：暴力递归

对应文件：

```text
11_二叉搜索树/08_q96/solution_1_bruteforce_recursive.py
```

### 思路

直接按照递推式写递归：

```text
f(n) = Σ f(i - 1) * f(n - i)
```

每次枚举根节点 `i`，递归计算左边和右边的方案数。

### 代码

```python
class Solution:
    def numTrees(self, n: int) -> int:
        def count(nodes: int) -> int:
            if nodes <= 1:
                return 1

            total = 0
            for root in range(1, nodes + 1):
                left_count = count(root - 1)
                right_count = count(nodes - root)
                total += left_count * right_count
            return total

        return count(n)
```

### 复杂度

```text
时间复杂度：指数级
空间复杂度：O(n)   （递归栈深度）
```

### 问题在哪

比如算 `f(5)` 时，会反复去算：

```text
f(3)、f(2)、f(1) ...
```

重复子问题非常多，所以会越来越慢。

这个方法适合拿来“看懂递推来源”，不适合作为面试主答案。

## 解法二：记忆化搜索

对应文件：

```text
11_二叉搜索树/08_q96/solution_2_memoization.py
```

### 思路

既然暴力递归的问题是重复计算，那就把算过的结果存起来。

第一次算出 `f(4)` 后，后面再遇到 `f(4)`，直接取缓存即可。

### 代码

```python
class Solution:
    def numTrees(self, n: int) -> int:
        memo = {0: 1, 1: 1}

        def count(nodes: int) -> int:
            if nodes in memo:
                return memo[nodes]

            total = 0
            for root in range(1, nodes + 1):
                total += count(root - 1) * count(nodes - root)

            memo[nodes] = total
            return total

        return count(n)
```

### 复杂度

```text
时间复杂度：O(n^2)
空间复杂度：O(n)
```

### 为什么降成 `O(n^2)`

因为 `count(0)` 到 `count(n)` 每个状态只会真正计算一次。

而每个状态内部要枚举一次根节点，最多枚举 `n` 次，所以总复杂度是：

```text
1 + 2 + 3 + ... + n = O(n^2)
```

## 解法三：动态规划

对应文件：

```text
11_二叉搜索树/08_q96/solution_3_dp.py
```

## 最适合面试的方法

这是这题最推荐作为面试主答案的方法。

原因很简单：

```text
1. 递推关系清晰
2. 不依赖递归栈
3. 推导过程很能体现你是否真正理解 BST 计数
4. 写法稳定，不容易错
```

### 第一步：定义状态

令：

```text
dp[i] = 由 i 个节点组成 BST 的方案数
```

这里 `i` 不是值范围，而是节点数量。

因为我们刚才已经分析过：

```text
方案数只和节点个数有关，和具体值无关
```

### 第二步：确定初始值

```text
dp[0] = 1
dp[1] = 1
```

解释：

```text
0 个节点时，空树算 1 种
1 个节点时，只有 1 种
```

### 第三步：写状态转移

现在求 `dp[i]`。

我们枚举每个节点作为根：

```text
根取第 1 个：左 0 个，右 i-1 个
根取第 2 个：左 1 个，右 i-2 个
...
根取第 i 个：左 i-1 个，右 0 个
```

所以：

```text
dp[i] += dp[root - 1] * dp[i - root]
```

完整转移：

```text
dp[i] = Σ dp[root - 1] * dp[i - root]
```

### 第四步：为什么是乘法

这是面试中最值得主动讲的一句。

因为：

```text
左子树的构造方式 和 右子树的构造方式 相互独立
```

如果左边有 2 种，右边有 3 种，那么拼起来总共有：

```text
2 * 3 = 6 种
```

所以这里不是加法，而是乘法。

### 第五步：填表顺序

由于 `dp[i]` 依赖更小的状态：

```text
dp[0], dp[1], ..., dp[i-1]
```

所以我们从小到大填：

```text
dp[2] -> dp[3] -> ... -> dp[n]
```

### 用 `n = 3` 手推一遍

初始：

```text
dp[0] = 1
dp[1] = 1
```

计算 `dp[2]`：

```text
root = 1: dp[0] * dp[1] = 1 * 1 = 1
root = 2: dp[1] * dp[0] = 1 * 1 = 1

dp[2] = 2
```

计算 `dp[3]`：

```text
root = 1: dp[0] * dp[2] = 1 * 2 = 2
root = 2: dp[1] * dp[1] = 1 * 1 = 1
root = 3: dp[2] * dp[0] = 2 * 1 = 2

dp[3] = 2 + 1 + 2 = 5
```

所以答案是：

```text
5
```

### 代码

```python
class Solution:
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1

        for nodes in range(2, n + 1):
            for root in range(1, nodes + 1):
                dp[nodes] += dp[root - 1] * dp[nodes - root]

        return dp[n]
```

### 复杂度

```text
时间复杂度：O(n^2)
空间复杂度：O(n)
```

### 面试怎么说最稳

你可以按这个顺序表达：

```text
1. 这题本质是计数 DP
2. 设 dp[i] 表示 i 个节点能组成多少种 BST
3. 枚举每个节点作为根
4. 左子树有 dp[root-1] 种，右子树有 dp[i-root] 种
5. 左右独立，因此相乘
6. 对所有根求和
7. 初始值是 dp[0] = dp[1] = 1
```

这套表达非常完整，基本就是标准面试答案。

## 解法四：卡特兰数公式

对应文件：

```text
11_二叉搜索树/08_q96/solution_4_catalan.py
```

### 思路

这题的答案其实就是第 `n` 个卡特兰数。

公式为：

```text
C(n) = (1 / (n + 1)) * 组合数(2n, n)
```

也可以用递推式迭代计算，避免大组合数和浮点数：

```text
C(0) = 1
C(n + 1) = C(n) * 2 * (2n + 1) / (n + 2)
```

### 代码

```python
class Solution:
    def numTrees(self, n: int) -> int:
        catalan = 1
        for i in range(n):
            catalan = catalan * 2 * (2 * i + 1) // (i + 2)
        return catalan
```

### 复杂度

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

### 这个方法适不适合作为面试主答案

看场景。

如果你：

```text
先讲清楚 DP 推导，再补一句“它其实也是卡特兰数”
```

会很加分。

但如果一上来只背公式，而解释不出为什么，面试效果通常不如 DP。

所以更推荐这样回答：

```text
主答案讲 DP
加分项讲卡特兰数
```

## 四种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 是否推荐做面试主答案 |
| --- | --- | --- | --- |
| 暴力递归 | 指数级 | O(n) | 不推荐 |
| 记忆化搜索 | O(n^2) | O(n) | 可以 |
| 动态规划 | O(n^2) | O(n) | **最推荐** |
| 卡特兰数公式 | O(n) | O(1) | 适合作为加分项 |

## 这题和第 95 题的关系

第 95 题是：

```text
把所有不同的 BST 真正构造出来
```

第 96 题是：

```text
只问一共有多少种
```

所以可以把它们联系起来理解：

```text
95 是“生成”
96 是“计数”
```

而这题的递推关系，本质上就是第 95 题生成逻辑的“计数版本”。

## 一句话总结

这题最核心的一句话是：

```text
枚举根节点后，BST 方案数 = 左子树方案数 × 右子树方案数，再对所有根求和。
```

如果是面试：

```text
优先掌握动态规划；
如果还有余力，再补充卡特兰数公式。
```
