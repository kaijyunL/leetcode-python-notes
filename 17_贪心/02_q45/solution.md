# LeetCode 45 - 跳跃游戏 II（Jump Game II）

## 题意

- 站在下标 `0`
- `nums[i]` 表示从 `i` 最多能跳多远
- 题目保证一定能到终点
- 求 **最少跳跃次数**

例如 `nums = [2,3,1,1,4]`，答案是 `2`。

---

## 这题最顺的理解顺序

1. **动态规划**：先把“最少跳数”定义清楚
2. **区间推进**：最直觉的线性解法
3. **压缩贪心**：把区间推进写短

先记一句话：

> **这题不是在当前点贪心，而是在当前起跳区间里，决定下一次整体最远能扩到哪。**

---

## 方法一：动态规划

对应文件：

```text
17_贪心/02_q45/solution_1_dp.py
```

定义：

```text
dp[i] = 到达下标 i 的最少跳跃次数
```

转移：如果 `j + nums[j] >= i`，说明可以从 `j` 一步跳到 `i`，那么：

```text
dp[i] = min(dp[i], dp[j] + 1)
```

答案是 `dp[n - 1]`。

复杂度：

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(n)`

这版的作用主要是帮你先理解“最少跳数”是什么，真正好用的是后面的区间贪心。

---

## 方法二：按区间推进

对应文件：

```text
17_贪心/02_q45/solution_2_interval_jump.py
```

### 核心想法

一次跳完之后，下一次可选的起跳点不是一个点，而是一段区间。

所以做法很直接：

1. 先拿到当前起跳区间 `[start, end]`
2. 把这段区间全部扫完
3. 算出下一次最远能到的位置 `max_pos`
4. 跳数加一，再进入下一段区间

这里的 `end` 就是它原本的意思：

> **当前这次跳跃最远能到的下标。**

### 变量含义

- `start`：当前起跳区间左边界
- `end`：当前这次跳跃最远能到的下标
- `max_pos`：当前区间里，下一次最远能到哪
- `steps`：已经跳了几次

### 更新方式

初始：

```text
start = 0
end = 0
```

表示一开始只能从下标 `0` 起跳。

每轮扫描完 `[start, end]` 后，更新：

```text
steps += 1
start = end + 1
end = max_pos
```

### 例子

`nums = [2,3,1,1,4]`

第一次区间是 `[0, 0]`，只能看下标 `0`：

```text
0 + nums[0] = 2
```

所以下一次区间变成 `[1, 2]`，也就是下标 `1`、`2`。

再扫描 `[1, 2]`：

- `1 + nums[1] = 4`
- `2 + nums[2] = 3`

最远能到 `4`，终点已经覆盖，所以总共跳 `2` 次。

### 为什么它是对的

因为每次真正要做的决定只有一个：

> **当前这段起跳区间扫完后，下一次最远能扩到哪里。**

当前区间里到底落在哪个点，不重要；重要的是下一次可选范围能不能尽量往右扩。

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

虽然写的是 `while + for`，但每个下标只会被扫一次。

### 面试评价

这是最适合面试解释的版本：直观、稳定、不容易把自己绕进去。

## 方法三：压缩成 `current_end / farthest`

对应文件：

```text
17_贪心/02_q45/solution_3_greedy.py
```

### 本质

> **方法三就是方法二的压缩写法。**

方法二显式维护当前区间 `[start, end]`；方法三把“扫区间”这件事揉进一个 `for` 里。

### 两个变量

- `current_end`：当前这一步覆盖的右边界
- `farthest`：当前区间里，下一步能抵达的右边界

你可以直接把它们对应起来：

- 方法二里的 `end`
- 就是方法三里的 `current_end`

### `if i == current_end` 到底什么意思

不是“我决定从 `i` 起跳”。
而是：

```text
当前区间已经扫完，可以结算这一次跳跃了
```

所以这里才会：

```text
steps += 1
current_end = farthest
```

### 为什么它和方法二一样

方法二：

- 扫完整个 `[start, end]`
- 再更新下一段区间

方法三：

- 连续扫描
- 扫到 `current_end` 就说明当前区间结束
- 再更新跳数和右边界

本质完全一样，只是写得更短。

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 面试评价

熟了以后很好写，但第一次看通常不如区间版直观。

---

## 面试怎么选

- **想讲清楚**：写方法二
- **想写得短**：写方法三

但就算你写方法三，解释时最好也先按“区间推进”去讲。

---

## 总结

这题最重要的结论就一句：

> **每次先看完当前起跳区间，再把下一次可达范围尽量往右扩。**

三种方法的关系：

1. **动态规划**：先定义最少跳数
2. **区间推进**：最直觉的线性解法
3. **压缩贪心**：把区间推进写短

所以正确顺序就是：

> **先把区间版想明白，再看 `current_end / farthest`。**
