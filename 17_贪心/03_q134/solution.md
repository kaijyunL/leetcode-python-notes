# LeetCode 134 - 加油站（Gas Station）

## 题意

给定两个长度相同的数组：

- `gas[i]`：在第 `i` 个加油站能加到多少油
- `cost[i]`：从第 `i` 个加油站开到下一个加油站要消耗多少油

车一开始油箱为空。整个路线是一个环。

要求：

- 如果存在某个起点，可以绕环路一圈，返回这个起点下标
- 如果不存在，返回 `-1`
- 题目保证：**如果有解，答案唯一**

---

## 样例先理解

例如：

```text
下标:   0  1  2  3  4
gas:    1  2  3  4  5
cost:   3  4  5  1  2
```

这里“下标”就是加油站编号。

所以“从下标 `3` 出发”，意思就是：

- 从编号为 `3` 的加油站出发
- 这个位置对应 `gas[3] = 4`
- 从这里开到下一站要花 `cost[3] = 1`

整个经过顺序是：

```text
3 -> 4 -> 0 -> 1 -> 2 -> 回到 3
```

逐步模拟：

- 在编号 `3` 的站加 `4` 升，开到编号 `4` 花 `1` 升，还剩 `3`
- 在编号 `4` 的站加 `5` 升，开到编号 `0` 花 `2` 升，还剩 `6`
- 在编号 `0` 的站加 `1` 升，开到编号 `1` 花 `3` 升，还剩 `4`
- 在编号 `1` 的站加 `2` 升，开到编号 `2` 花 `4` 升，还剩 `2`
- 在编号 `2` 的站加 `3` 升，开回编号 `3` 花 `5` 升，还剩 `0`

可以刚好绕一圈，所以答案是 `3`。

这题真正关心的不是某一站单独有多少油，而是这一站经过之后，油量是变多还是变少。

所以先做一个化简：

```text
diff[i] = gas[i] - cost[i]
```

含义：

- `diff[i] > 0`：经过这一站后，净赚油
- `diff[i] < 0`：经过这一站后，净亏油

于是题目就变成了：

> **能不能找到一个起点，使得从这里出发按顺序累加 `diff`，绕一圈的过程中都不会掉成负数。**

---

## 方法一：暴力枚举起点

对应文件：

```text
17_贪心/03_q134/solution_1_brute_force.py
```

### 思路

最直接的想法就是：

1. 枚举每个位置 `start` 作为起点
2. 从这个起点出发，模拟走 `n` 步
3. 途中维护当前油量 `tank`
4. 只要某一步 `tank < 0`，说明这个起点失败
5. 如果能完整走一圈，就返回这个起点

### 为什么可行

因为题目本来就是在问“哪个起点能走通一圈”。

那最朴素的方法就是把每个起点都试一遍。

### 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(1)`

### 问题在哪里

它会重复做很多没必要的模拟。

比如你从 `0` 出发，已经走到 `2` 才失败，那你后面又从 `1`、`2` 再各试一遍，里面有很多重复路径。

所以关键不是暴力法错，而是它太笨。

---

## 从暴力法里提炼一个关键观察

这一步是整题最重要的地方。

假设：

- 你当前尝试的起点是 `start`
- 从 `start` 出发一路往前开
- 走到某个位置 `i` 时，发现油量变成负数了

也就是说：

```text
从 start 出发，撑不到 i + 1
```

这时最关键的问题是：

> **`start` 后面到 `i` 之间这些点，还要不要再一个个试？**

结论：**完全不用。**

### 为什么这整段都可以排除

因为：

1. 你是从 `start` 出发一路走到 `i` 才第一次失败的
2. 这说明在 `start ~ i - 1` 这段路里，前面攒下来的油已经都用上了
3. 即便带着这些前面积累下来的油，走到 `i` 这里还是不够
4. 那如果你改成从 `start + 1`、`start + 2`、...、`i` 中间某个位置出发，相当于把前面那部分积累直接丢掉了
5. 少了这些积累，只会更早失败，不可能更晚成功

所以：

> **如果从 `start` 出发在 `i` 失败，那么 `start ~ i` 这一整段都不可能成为合法起点。**

这个结论一出来，暴力法就能一下子优化成贪心。

## 方法二：单次遍历贪心

对应文件：

```text
17_贪心/03_q134/solution_2_greedy.py
```

### 这是本题最适合面试的方法

代码里用到三个变量：

- `total`：全局总净收益，也就是整圈 `diff` 的总和
- `tank`：从当前候选起点出发，走到当前位置时，车里还剩多少油
- `start`：当前候选起点

### 先看 `total` 为什么重要

如果：

```text
total < 0
```

说明整圈加的油还没有花的油多。

那不管从哪里出发，最后都不可能绕完一圈。

所以：

> **`total < 0` 时，答案一定是 `-1`。**

这一步是在判断“有没有解”。

### 再看 `tank` 和 `start` 在干什么

遍历每个位置 `i` 时，先算：

```text
diff = gas[i] - cost[i]
```

然后：

```text
total += diff
tank += diff
```

含义分别是：

- `total`：把这一站对整圈总油量的贡献加进去
- `tank`：把这一站对“当前候选起点这条路线”的贡献加进去

### 为什么一旦 `tank < 0`，就可以直接换起点

如果某一时刻：

```text
tank < 0
```

说明：

- 从当前 `start` 出发，走到这里已经撑不住了
- 那么根据上面刚证明过的结论，`start ~ i` 整段都不可能是起点

所以我们直接做两件事：

```text
start = i + 1
tank = 0
```

含义是：

- `start = i + 1`：下一次从后一个位置重新试
- `tank = 0`：因为新的起点还没真正开始累计，所以油量重新记

这一步就是整道题的贪心核心。

### 整个流程

遍历一遍数组：

1. 累加 `total`
2. 累加 `tank`
3. 如果 `tank < 0`
   - 说明当前候选起点失败
   - 直接把起点改成 `i + 1`
   - `tank` 清零

最后：

- 如果 `total < 0`，返回 `-1`
- 否则返回 `start`

### 用样例走一遍

还是这个例子：

```text
gas  = [1, 2, 3, 4, 5]
cost = [3, 4, 5, 1, 2]
diff = [-2, -2, -2, 3, 3]
```

初始：

```text
total = 0
tank = 0
start = 0
```

#### `i = 0`

```text
diff = -2
total = -2
tank = -2
```

这时 `tank < 0`，说明从 `0` 出发失败。

所以：

```text
start = 1
tank = 0
```

#### `i = 1`

```text
diff = -2
total = -4
tank = -2
```

又失败。

所以：

```text
start = 2
tank = 0
```

#### `i = 2`

```text
diff = -2
total = -6
tank = -2
```

继续失败。

所以：

```text
start = 3
tank = 0
```

#### `i = 3`

```text
diff = 3
total = -3
tank = 3
```

能继续走。

#### `i = 4`

```text
diff = 3
total = 0
tank = 6
```

遍历结束。

此时：

```text
total = 0 >= 0
```

说明有解，返回 `start = 3`。

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 为什么它最适合面试

因为它同时满足三点：

1. **代码短**：一趟遍历即可
2. **逻辑硬**：失败区间可以整段排除
3. **好解释**：`total` 管有没有解，`tank` 管当前起点行不行，`start` 管候选答案是谁

### 面试里怎么讲最顺

你可以直接这样说：

> 我先看每个站点的净收益 `gas[i] - cost[i]`。如果总净收益小于 `0`，那一定无解。否则我从一个候选起点开始往前走，用 `tank` 表示当前剩余油量；一旦 `tank < 0`，说明当前起点失败，而且这段区间都不可能是起点，所以我直接把起点跳到 `i + 1`，并把 `tank` 清零重新开始。最后如果总和不小于 `0`，返回这个起点即可。

## 方法三：前缀和找最低点

对应文件：

```text
17_贪心/03_q134/solution_3_prefix_sum.py
```

### 这是一个更“整体视角”的解释

还是看：

```text
diff[i] = gas[i] - cost[i]
```

再定义前缀和：

```text
prefix[i] = diff[0] + diff[1] + ... + diff[i]
```

如果整圈总和小于 `0`，那仍然无解。

如果整圈总和大于等于 `0`，那么答案就是：

> **前缀和最小值的下一个位置。**

### 为什么

因为前缀和最低的位置，代表“走到这里时最缺油”。

那你从它后一个位置重新出发，相当于把最亏的那一段放到了最后再走。这样从新起点开始一路累加时，就不会跌到比这个最低点更低的位置。

所以这个位置可以作为合法起点。

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 评价

这个方法也很漂亮，但它更像是对答案的另一种解释。

第一次做题时，大多数人更容易先从“暴力失败区间可以整段排除”推到方法二。

所以这版更适合复盘时加深理解，不是最优先的面试写法。

---

## 哪个方法最适合面试

### 结论

**方法二：单次遍历贪心。**

### 原因

- 它是从暴力法自然推出来的，不是硬记模板
- 代码短，边界少，容易一次写对
- 变量含义清楚：`total`、`tank`、`start`
- 解释时有明确主线：
  - `total` 看有没有解
  - `tank` 看当前候选起点能不能撑住
  - `start` 记录当前候选起点

---

## 总结

这题最重要的不是记住“贪心”两个字，而是记住下面两个结论：

1. **如果总净收益小于 `0`，一定无解**
2. **如果从某个起点走到一半失败，那么这段区间都可以直接排除**

三种方法的递进关系：

1. **暴力枚举**：每个起点都试一遍
2. **单次遍历贪心**：利用“失败区间整段排除”把暴力优化到 `O(n)`
3. **前缀和最低点**：从整体视角解释为什么答案会落在某个位置
