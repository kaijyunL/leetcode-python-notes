# LeetCode 452 - 用最少数量的箭引爆气球（Minimum Number of Arrows to Burst Balloons）

## 题意

给定若干气球，每个气球用一个区间 `points[i] = [x_start, x_end]` 表示。

意思是：

- 这个气球在 `x_start` 到 `x_end` 之间展开
- 你可以在 x 轴任意位置射一支箭
- 如果某支箭的位置 `x` 满足：

```text
x_start <= x <= x_end
```

那么这个气球就会被引爆。

要求：

> **用最少数量的箭，引爆所有气球。**

### 这题最容易搞混的一点

这里区间两端都是 **包含** 的。

所以：

```text
[1, 2] 和 [2, 3]
```

可以共用一支箭。

因为你把箭射在 `2`，这两个气球都会被打爆。

这点和第 `435` 题不一样。

- 第 `435` 题里，`[1, 2]` 和 `[2, 3]` 不算重叠
- 第 `452` 题里，它们却可以共用一支箭

---

## 样例先理解

例如：

```text
points = [[10, 16], [2, 8], [1, 6], [7, 12]]
```

按左端点排序后是：

```text
[1, 6], [2, 8], [7, 12], [10, 16]
```

先看前两个：

```text
[1, 6]
[2, 8]
```

它们有公共部分：

```text
[2, 6]
```

这说明：

> **只要把箭射在 `2 ~ 6` 之间，前两个气球都能一起打爆。**

再看第三个 `[7, 12]`：

- 它的左端点 `7`
- 已经大于前一组公共部分的右端点 `6`

说明它和前一组已经没有公共射击位置了。

所以必须再开一支新箭。

接着看第四个 `[10, 16]`：

- 它和 `[7, 12]` 还有公共部分 `[10, 12]`
- 所以这两个还可以共用第二支箭

最终：

- 第一支箭负责 `[1, 6]` 和 `[2, 8]`
- 第二支箭负责 `[7, 12]` 和 `[10, 16]`

答案是 `2`。

---

## 先把题目换个说法

这题不是在问“每个气球单独怎么射”，而是在问：

> **哪些气球可以共用同一支箭。**

只要一组气球有公共交集，就可以用一支箭一起解决。

所以核心就变成：

> **尽量把能重叠的气球放进同一组。**

---

## 方法一：按起点排序，维护当前公共射击区间

对应文件：

```text
17_贪心/05_q452/solution_1_greedy_by_start.py
```

### 思路

先按左端点排序。

然后从左到右扫描，维护当前这组气球还能共用的射击区间。

代码里我们只记录一个量：

- `overlap_end`：当前这组气球公共部分的右边界

因为已经按左端点排好序了，所以新的气球一进来：

- 如果它还能和当前组重叠，就把公共部分继续缩小
- 如果它已经和当前组没有公共部分了，就必须新开一支箭

### 整个流程

先排序：

```text
按 start 从小到大排序
```

然后：

1. 先把第一组气球记下来，初始需要 `1` 支箭
2. `overlap_end = 第一个气球的右端点`
3. 继续遍历后面的气球 `[start, end]`
   - 如果 `start > overlap_end`
     - 说明和当前组没有交集了
     - 必须多开一支箭
     - 并把当前组重置成这个新区间
   - 否则
     - 说明还有交集
     - 就把公共右边界缩成更小的那个

也就是：

```text
overlap_end = min(overlap_end, end)
```

### 为什么这样是对的

因为只要几个气球还能共用一支箭，我们就应该尽量把它们放进同一组。

而“能不能继续共用一支箭”，取决于它们的公共交集还在不在。

一旦新的气球让公共交集消失了，就说明：

> **当前组不可能再和它共用同一支箭了。**

那就只能新开一支箭。

### 复杂度

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(1)`

### 评价

这个写法很直觉，因为它直接在维护“这一组还能往哪里射”。

但它有个地方第一次容易想一下：

```text
overlap_end = min(overlap_end, end)
```

也就是：

> **重叠时，不是把区间变大，而是把公共可射范围变小。**

## 方法二：按右端点排序，箭尽量射在更靠左的结束位置

对应文件：

```text
17_贪心/05_q452/solution_2_greedy_by_end.py
```

### 这是本题最适合面试的方法

这版更像第 `435` 题的自然延续。

核心想法是：

> **如果当前这支箭还能继续用，那就尽量把它射在更靠左、但又能命中的位置。**

为什么？

因为射得越靠左，后面越容易继续覆盖更多气球。

而一个气球最靠左还能射中的“安全位置”，其实就是它的右端点。

所以最自然的贪心就是：

> **按右端点排序，然后优先把箭放在当前最早结束的气球右端点上。**

### 代码里两个核心变量

- `arrows`：当前已经用了多少支箭
- `arrow_pos`：当前这支箭射在什么位置

### 整个流程

先排序：

```text
按 end 从小到大排序
```

然后：

1. 先用一支箭，射在第一个气球的右端点
2. 继续看后面的气球 `[start, end]`
3. 如果：

```text
start > arrow_pos
```

说明当前这支箭已经打不到这个气球了。

那就必须：

- 新开一支箭
- 把新箭射在这个气球的右端点 `end`

4. 否则：

```text
start <= arrow_pos
```

说明当前这支箭还能打到它。

那就直接继续用，不需要加箭。

### 为什么条件是 `>`，不是 `>=`

这是这题最容易写错的地方。

因为区间两端都算命中。

所以如果：

```text
start == arrow_pos
```

箭仍然能打到这个气球。

比如：

```text
[1, 2] 和 [2, 3]
```

箭射在 `2`，两个都能爆。

所以只有：

```text
start > arrow_pos
```

才说明真的接不上了。

### 用样例走一遍

样例：

```text
points = [[10, 16], [2, 8], [1, 6], [7, 12]]
```

按右端点排序：

```text
[1, 6], [2, 8], [7, 12], [10, 16]
```

初始：

```text
arrows = 1
arrow_pos = 6
```

继续看：

- `[2, 8]`：`2 <= 6`，当前箭还能打到，继续用
- `[7, 12]`：`7 > 6`，接不上，必须新开一支箭
  - `arrows = 2`
  - `arrow_pos = 12`
- `[10, 16]`：`10 <= 12`，第二支箭还能打到

最后答案就是 `2`。

### 复杂度

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(1)`

### 为什么它最适合面试

因为它有 3 个优点：

1. **变量少**：只要 `arrows` 和 `arrow_pos`
2. **逻辑硬**：总是优先占住最早结束的位置
3. **边界清楚**：只要记住条件是 `start > arrow_pos`

### 面试里怎么讲最顺

你可以直接这样说：

> 这题的关键是尽量让一支箭覆盖更多气球。为了给后面留更多空间，我会让箭尽量射在靠左的位置，而对当前气球来说，最靠左但还能命中的安全位置就是它的右端点。所以我先按右端点排序，先把箭射在第一个气球的右端点；后面如果某个气球的左端点大于当前箭的位置，说明这支箭已经打不到它了，就必须新开一支箭。否则就继续复用当前这支箭。

## 哪个方法最适合面试

### 结论

**方法二：按右端点排序的贪心。**

### 原因

- 它是最经典的区间贪心写法
- 和第 `435` 题思路一脉相承
- 代码最短，最稳
- 最容易讲清楚“为什么要按右端点排序”

---

## 总结

这题最关键的不是记住“贪心”两个字，而是记住下面两句：

1. **只要一组气球还有公共交集，就可以共用一支箭**
2. **为了让一支箭尽量多打几个气球，应该尽量把箭放在更早结束的位置**

两种方法的递进关系：

1. **按起点排序维护公共射击区间**：先从“这一组还能射哪里”来理解
2. **按右端点排序贪心**：直接把箭射在最早结束的位置，这是最适合面试的方法
