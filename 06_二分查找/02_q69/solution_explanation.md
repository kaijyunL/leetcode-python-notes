# LeetCode 69. x 的平方根解析

## 题目描述

给定一个非负整数 `x`，返回它的算术平方根的整数部分。

也就是说，要求返回最大的整数 `ans`，满足：

```text
ans * ans <= x
```

例如：

```text
x = 8
```

真实平方根是：

```text
2.828...
```

但题目只要求整数部分，所以答案是：

```text
2
```

---

## 先理解题意

这题不是让你求精确的小数平方根，而是让你找：

```text
最大的整数 ans，使得 ans^2 不超过 x
```

所以它本质上是在找一个“边界位置”。

例如：

```text
x = 15
```

有：

- `3 * 3 = 9 <= 15`
- `4 * 4 = 16 > 15`

所以答案就是：

```text
3
```

也就是说，真正要找的是：

```text
最后一个满足 mid * mid <= x 的整数
```

---

## 方法一：线性扫描

### 思路

最直接的做法就是从小到大试。

从 `0` 开始不断递增，直到第一次遇到：

```text
i * i > x
```

这时说明：

```text
i 太大了
```

所以答案就是前一个数：

```text
i - 1
```

---

### 为什么可行

因为平方值会随着 `i` 变大而不断增大。

所以一旦某个 `i` 的平方第一次超过 `x`，前一个数一定就是最大的合法答案。

---

### 复杂度

- 时间复杂度：`O(sqrt(x))`
- 空间复杂度：`O(1)`

---

### 这个方法差在哪里

它当然正确，但没有利用单调性来加速。

这题最关键的性质其实是：

```text
随着数字增大，平方值也单调增大
```

既然是单调的，就可以二分。

---

## 方法二：二分查找（面试主推）

这是最适合面试的写法。

---

### 核心想法

这题可以直接转化成：

```text
在区间 [0, x] 中，找最后一个满足 mid * mid <= x 的位置
```

为什么这样想自然？

因为题目要的恰好就是：

```text
平方不超过 x 的最大整数
```

这和“找最后一个满足条件的位置”完全一致。

---

### 二分过程怎么推进

设：

```text
left = 0
right = x
```

每次取中点：

```text
mid = (left + right) // 2
```

如果：

```text
mid * mid <= x
```

说明 `mid` 是一个合法答案，但还不一定是最大的。

所以继续向右找：

```python
left = mid + 1
```

如果：

```text
mid * mid > x
```

说明 `mid` 太大了，答案只能在左边：

```python
right = mid - 1
```

---

### 为什么最后返回 `right`

这是整题最关键的一步。

循环结束时：

```text
left > right
```

而 `right` 会停在：

```text
最后一个满足 mid * mid <= x 的位置
```

所以答案直接就是：

```python
right
```

这和 `35` 题里“找第一个大于等于 target 的位置，最后返回 left”是互补关系：

- `35` 题找第一个满足条件的位置
- `69` 题找最后一个满足条件的位置

---

### 用例子走一遍

输入：

```text
x = 8
```

开始：

```text
left = 0
right = 8
```

---

### 第一次

```text
mid = 4
4 * 4 = 16
```

因为：

```text
16 > 8
```

说明 `4` 太大，所以：

```text
right = 3
```

---

### 第二次

```text
left = 0
right = 3
mid = 1
1 * 1 = 1
```

因为：

```text
1 <= 8
```

说明 `1` 合法，但不一定最大，所以：

```text
left = 2
```

---

### 第三次

```text
left = 2
right = 3
mid = 2
2 * 2 = 4
```

仍然合法，所以：

```text
left = 3
```

---

### 第四次

```text
left = 3
right = 3
mid = 3
3 * 3 = 9
```

因为：

```text
9 > 8
```

所以：

```text
right = 2
```

此时：

```text
left = 3
right = 2
```

循环结束，返回 `right = 2`。

这正是正确答案。

---

### 为什么有些语言会写成 `mid <= x // mid`

在 Python 里，直接写：

```python
mid * mid <= x
```

没有溢出问题。

但在 C++ / Java 这类定长整数语言里，`mid * mid` 可能溢出，所以常见写法是：

```python
mid <= x // mid
```

这两种逻辑是等价的。

如果面试官问到整数溢出，这是一个可以顺手补充的点。

---

## 为什么这是最适合面试的方法

原因很明确：

1. 它把复杂度从 `O(sqrt(x))` 降到了 `O(log x)`。
2. 它完整体现了“找最后一个满足条件的位置”这种二分思维。
3. 代码短，边界清晰，适合现场稳定写出来。

如果面试官问“你怎么想到的”，可以按这条线讲：

```text
先从线性试探出发
-> 发现平方值对整数是单调递增的
-> 所以问题可以转成二分找边界
-> 具体就是找最后一个平方不超过 x 的整数
```

---

## 方法对比

| 方法 | 思路 | 时间复杂度 | 空间复杂度 | 面试建议 |
|---|---|---:|---:|---|
| 方法一 | 从小到大试到平方超过 `x` | `O(sqrt(x))` | `O(1)` | 只适合理解 |
| 方法二 | 二分查找最后一个满足 `mid * mid <= x` 的位置 | `O(log x)` | `O(1)` | **面试主推** |

---

## 总结

这题最值得记住的不是“求平方根”这几个字，而是下面这句话：

```text
本质上是在找最后一个满足 mid * mid <= x 的整数
```

真正理解了这一点，这题就会自然落成：

```text
合法就向右找更大值，不合法就向左收缩，最后返回 right
```

这就是本题的核心解法。
