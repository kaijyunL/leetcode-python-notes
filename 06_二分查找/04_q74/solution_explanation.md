# LeetCode 74. 搜索二维矩阵解析

## 题目描述

给定一个 `m x n` 的整数矩阵 `matrix` 和一个目标值 `target`，判断 `target` 是否存在于矩阵中。

题目给了两个关键条件：

1. 每一行都按升序排列
2. 每一行的第一个元素都大于上一行的最后一个元素

例如：

```text
matrix = [
  [1, 3, 5, 7],
  [10, 11, 16, 20],
  [23, 30, 34, 60]
]
target = 3
```

答案是：

```text
True
```

---

## 先理解题意

这题虽然给的是二维矩阵，但它不是普通的“每行有序、每列有序”。

它多了一条更强的条件：

```text
下一行的第一个数，比上一行的最后一个数还大
```

这意味着如果把整个矩阵按行展开，会得到一个完整的一维升序数组。

例如：

```text
[
  [1, 3, 5, 7],
  [10, 11, 16, 20],
  [23, 30, 34, 60]
]
```

按行展开后就是：

```text
[1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]
```

既然整体有序，那么最自然的优化方向就是二分查找。

---

## 方法一：线性扫描

### 思路

最直接的做法就是逐行逐列去找。

只要某个位置的值等于 `target`，就返回 `True`。

如果所有元素都检查完还没找到，返回 `False`。

---

### 为什么可行

因为这个方法会把矩阵里的每个元素都看一遍，所以不会漏掉目标值。

只要 `target` 存在，就一定会被扫描到。

---

### 复杂度

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(1)`

---

### 这个方法差在哪里

它正确，但没有利用题目给出的“整体有序”这个条件。

既然整个矩阵拉平后是升序的，就没必要把所有元素都看一遍，可以直接二分。

---

## 方法二：二分查找（面试主推）

这是最适合面试的方法。

---

### 核心想法

把矩阵看成一个长度为 `rows * cols` 的一维升序数组。

然后在这个虚拟的一维数组上做普通二分查找。

关键问题只剩一个：

```text
一维下标 mid，怎么映射回二维坐标？
```

答案是：

```python
row = mid // cols
col = mid % cols
```

所以当前位置的值就是：

```python
matrix[row][col]
```

---

### 为什么这个映射成立

假设每一行有 `cols` 个元素。

那么：

- 前 `cols` 个元素在第 `0` 行
- 再往后 `cols` 个元素在第 `1` 行
- 以此类推

所以：

```text
mid // cols
```

表示它落在哪一行，

而：

```text
mid % cols
```

表示它在这一行里的第几个位置。

---

### 二分过程怎么写

设：

```text
left = 0
right = rows * cols - 1
```

每次取中点：

```text
mid = (left + right) // 2
```

然后把 `mid` 转成二维坐标，得到当前位置的值 `num`。

如果：

```text
num == target
```

说明已经找到，直接返回 `True`。

如果：

```text
num < target
```

说明目标只可能在右半边：

```python
left = mid + 1
```

如果：

```text
num > target
```

说明目标只可能在左半边：

```python
right = mid - 1
```

循环结束还没找到，就返回 `False`。

---

### 用例推演

以：

```text
matrix = [
  [1, 3, 5, 7],
  [10, 11, 16, 20],
  [23, 30, 34, 60]
]
target = 16
```

为例。

矩阵一共 `3 * 4 = 12` 个元素，所以二分范围是：

```text
[0, 11]
```

某次如果：

```text
mid = 6
```

那么：

```text
row = 6 // 4 = 1
col = 6 % 4 = 2
```

对应位置就是：

```text
matrix[1][2] = 16
```

这时就直接找到答案，返回 `True`。

---

### 边界处理

LeetCode 这题通常给的矩阵不会为空，但代码里加上：

```python
if not matrix or not matrix[0]:
    return False
```

会更稳。

这样即使传入空矩阵，也不会访问 `matrix[0]` 报错。

---

### 复杂度

- 时间复杂度：`O(log(m * n))`
- 空间复杂度：`O(1)`

---

## 为什么这是最适合面试的写法

因为它有几个明显优点：

1. 完整利用了题目给出的有序条件
2. 写法就是标准二分，不需要额外绕边界
3. 下标映射公式很固定，容易记
4. 代码短，出错点少

面试里可以直接这样解释：

```text
这个矩阵按行展开后其实是一个整体升序数组，
所以我在下标区间 [0, rows * cols - 1] 上做普通二分。
每次用 row = mid // cols、col = mid % cols 把一维下标映射回二维坐标。
```

---

## 最终建议

这题建议这样记：

1. 先看到“下一行第一个数大于上一行最后一个数”
2. 立刻意识到整个矩阵可以视为一维升序数组
3. 然后直接写标准二分

最核心的一句就是：

```text
把二维矩阵当成一维有序数组，二分时用 mid // cols 和 mid % cols 还原坐标。
```
