# LeetCode 2. 两数相加（Add Two Numbers）解析

## 题目描述

给你两个**非空**链表 `l1` 和 `l2`，它们分别表示两个非负整数。

注意这题最关键的条件有两个：

- 每个节点只存一位数字
- 数字是**逆序**存储的

也就是说：

```text
2 -> 4 -> 3
```

表示的其实不是 `243`，而是：

```text
342
```

题目要求把这两个数相加，然后仍然用**同样的逆序链表形式**返回结果。

例如：

```text
l1 = 2 -> 4 -> 3
l2 = 5 -> 6 -> 4
```

表示：

```text
342 + 465 = 807
```

所以返回：

```text
7 -> 0 -> 8
```

---

## 先理解这题在考什么

这题表面上是在“链表求和”，但核心其实是：

```text
如何在链表上模拟小学竖式加法
```

因为链表是逆序存储的，所以：

- 头节点就是个位
- 下一个节点就是十位
- 再下一个节点就是百位

这恰好和我们做加法时从低位往高位算的顺序完全一致。

所以这题最关键的突破口就是：

```text
不用先反转链表，也不用先转成正常顺序，直接从头开始逐位相加
```

而每一位都要处理的核心只有三件事：

- 当前位的两个数字
- 上一位传来的进位 `carry`
- 当前位留下的结果 digit

---

## 方法一：转成整数相加后再转回链表

### 思路

最直观的想法是：

1. 先把链表还原成整数
2. 直接做整数加法
3. 再把和重新拆成逆序链表

例如：

```text
2 -> 4 -> 3  ->  342
5 -> 6 -> 4  ->  465
342 + 465 = 807
807 -> 7 -> 0 -> 8
```

这个思路在 Python 里可以做，因为 Python 整数没有固定上限。

---

### 代码

```python
class Solution:
    def addTwoNumbers(
        self,
        l1: Optional[ListNode],
        l2: Optional[ListNode],
    ) -> Optional[ListNode]:
        def to_number(node: Optional[ListNode]) -> int:
            place = 1
            number = 0

            while node:
                number += node.val * place
                place *= 10
                node = node.next

            return number

        total = to_number(l1) + to_number(l2)
        dummy = ListNode(0)
        cur = dummy

        if total == 0:
            return ListNode(0)

        while total:
            digit = total % 10
            cur.next = ListNode(digit)
            cur = cur.next
            total //= 10

        return dummy.next
```

---

### 为什么可行

因为逆序链表本质上只是整数的另一种表示形式。

只要你能正确完成：

- 链表 -> 整数
- 整数 -> 逆序链表

那最终答案自然就是对的。

---

### 复杂度

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(1)`

---

### 不足在哪里

这个方法虽然在 Python 里能通过，但它最大的问题是：

```text
几乎没有真正练到链表逐位处理和进位控制
```

而且如果换成整数有范围限制的语言，就可能溢出。

所以这题真正该掌握的，还是方法二。

---

## 方法二：哑节点 + 逐位模拟竖式加法（面试主推）

### 核心思路

因为链表就是按个位、十位、百位……逆序排好的，所以我们完全可以像竖式加法那样：

```text
一位一位算，同时把进位带到下一位
```

为了让代码稳定好写，我们引入三个角色：

- `dummy`：结果链表的虚拟头节点
- `cur`：始终指向结果链表当前尾部
- `carry`：上一位传来的进位

每一轮做的事情都固定：

1. 取出 `l1` 当前位，没有就当 `0`
2. 取出 `l2` 当前位，没有就当 `0`
3. 再加上 `carry`
4. 当前位留下 `total % 10`
5. 下一位进位变成 `total // 10`
6. 把新节点接到结果链表尾部

而循环条件最关键的一点是：

```text
只要 l1、l2、carry 三者里还有一个没处理完，就继续
```

也就是：

```python
while l1 or l2 or carry:
```

---

## 为什么这个思路能想到

这题的关键条件是：

```text
数字已经按低位到高位排好了
```

这意味着你根本不需要像正常数字那样先走到末尾再倒着算。

你从头开始走，天然就是在按：

```text
个位 -> 十位 -> 百位
```

的顺序处理。

所以这题最本质的转化就是：

```text
把“链表求和”看成“链表上的竖式加法模拟”
```

一旦这个点想通，`carry` 就会非常自然地出现。

---

## 为什么要用哑节点 `dummy`

如果不用 `dummy`，你第一轮就要额外判断：

```text
结果链表的头节点该怎么初始化？
```

而有了 `dummy` 以后：

- 第一个结果节点和后面的结果节点写法完全一致
- 不用特判头节点
- 最后直接返回 `dummy.next`

这就是链表题里非常经典的简化技巧。

---

## 用例子走一遍

假设：

```text
l1 = 2 -> 4 -> 3
l2 = 5 -> 6 -> 4
```

开始时：

```text
dummy -> None
cur = dummy
carry = 0
```

### 第 1 轮

取当前位：

```text
2 + 5 + 0 = 7
```

所以：

- 当前位写 `7`
- 新进位 `0`

结果链表变成：

```text
dummy -> 7
```

### 第 2 轮

```text
4 + 6 + 0 = 10
```

所以：

- 当前位写 `0`
- 新进位 `1`

结果链表变成：

```text
7 -> 0
```

### 第 3 轮

```text
3 + 4 + 1 = 8
```

所以：

- 当前位写 `8`
- 新进位 `0`

结果链表变成：

```text
7 -> 0 -> 8
```

循环结束，返回 `dummy.next`。

---

### 面试代码

```python
class Solution:
    def addTwoNumbers(
        self,
        l1: Optional[ListNode],
        l2: Optional[ListNode],
    ) -> Optional[ListNode]:
        dummy = ListNode(0)
        cur = dummy
        carry = 0

        while l1 or l2 or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0
            total = val1 + val2 + carry

            carry = total // 10
            cur.next = ListNode(total % 10)
            cur = cur.next

            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next

        return dummy.next
```

---

### 为什么这个方法最适合面试

如果这题你只记一种写法，就记这一种。

### 1. 最贴题目条件

它把“逆序存储”这个条件用满了：

```text
从头开始就是从低位开始，天然适合逐位相加
```

### 2. 写法最稳

`dummy + cur + carry` 这个结构非常清晰，现场不容易乱。

### 3. 边界处理统一

不管是链表长度不同，还是最后多出一个进位，都能被：

```text
while l1 or l2 or carry
```

这一个循环统一处理掉。

### 4. 复杂度最好

- 时间复杂度：`O(max(m, n))`
- 空间复杂度：`O(1)`（不算返回结果链表本身）

这是这题最标准、最推荐现场手写的版本。

---

### 容易出错的地方

### 1. 忘了把 `carry` 放进循环条件

比如：

```text
5 + 5 = 10
```

如果只写：

```python
while l1 or l2:
```

那最后那个最高位 `1` 就会丢掉。

所以一定要写：

```python
while l1 or l2 or carry:
```

### 2. 链表走完后没有把值当 `0`

长度不同的时候，某一边可能已经空了。

这时要记得：

```text
空链表当前位按 0 处理
```

### 3. 把进位和当前位写反

当前位应该是：

```text
total % 10
```

进位应该是：

```text
total // 10
```

这两个很容易在紧张时写反。

---

### 面试里怎么讲

你可以这样解释：

```text
因为两个链表本来就是逆序存储的，所以我可以直接从头开始模拟竖式加法。
每一位把 l1 当前值、l2 当前值和 carry 相加，当前位写 total % 10，新的进位写 total // 10。
我用 dummy 简化结果链表的构造，用 cur 维护结果尾部。
只要 l1、l2、carry 里还有一个没处理完，就继续循环。
这样只需要遍历一次，时间复杂度是 O(max(m,n))，额外空间复杂度是 O(1)。
```

这就是这题最标准的讲法。

---

## 方法三：递归逐位相加（补充理解）

### 思路

既然每一位的处理逻辑都一样，那么也可以把它写成递归：

```text
当前层负责生成当前位节点，下一层递归继续处理下一位和进位
```

递归函数需要接收三样东西：

- 当前的 `l1`
- 当前的 `l2`
- 当前的 `carry`

终止条件也很自然：

```text
l1、l2 都空了，并且 carry 也为 0
```

这时就返回 `None`。

---

### 代码

```python
class Solution:
    def addTwoNumbers(
        self,
        l1: Optional[ListNode],
        l2: Optional[ListNode],
    ) -> Optional[ListNode]:
        def dfs(
            n1: Optional[ListNode],
            n2: Optional[ListNode],
            carry: int,
        ) -> Optional[ListNode]:
            if not n1 and not n2 and carry == 0:
                return None

            val1 = n1.val if n1 else 0
            val2 = n2.val if n2 else 0
            total = val1 + val2 + carry

            node = ListNode(total % 10)
            node.next = dfs(
                n1.next if n1 else None,
                n2.next if n2 else None,
                total // 10,
            )
            return node

        return dfs(l1, l2, 0)
```

---

### 为什么可行

因为每一层递归都在做完全相同的事：

```text
处理当前位，生成当前节点，然后把下一位和进位交给下一层
```

问题结构完全一致，所以可以自然递归下去。

---

### 复杂度

- 时间复杂度：`O(max(m, n))`
- 空间复杂度：`O(max(m, n))`

这里的额外空间来自递归调用栈。

---

### 它适合什么时候学

它适合作为：

- 帮你理解“逐位处理”其实是一个重复子问题
- 练习把迭代逻辑改写成递归
- 看懂别人题解里的递归版本

但如果你现在是二刷，或者面试只准备记一个版本：

```text
还是优先记方法二
```

---

## 三种方法的关系

这题三种做法的递进关系很清楚：

- **方法一**：利用 Python 整数能力，先转数再转回链表
- **方法二**：真正按题目结构做逐位进位相加，这是面试主推
- **方法三**：把方法二的逐位处理写成递归表达

这题最值得抓住的一句话是：

```text
链表已经按低位到高位排好，所以可以直接从头开始模拟竖式加法
```

只要这句话真正想通，方法二就会非常自然。

---

## 复杂度总结

| 方法 | 时间复杂度 | 空间复杂度 | 评价 |
| --- | --- | --- | --- |
| 方法一：转成整数再转回链表 | `O(m + n)` | `O(1)` | Python 可做，但不是真正考点 |
| 方法二：哑节点 + 逐位模拟竖式加法 | `O(max(m, n))` | `O(1)` | 面试主推 |
| 方法三：递归逐位相加 | `O(max(m, n))` | `O(max(m, n))` | 有助于理解，但现场不如迭代稳 |

---

## 总结

这题最重要的不是背模板，而是想清楚：

```text
逆序链表其实已经把最低位放在最前面了，所以你完全可以直接从头开始做加法，并用 carry 把进位一路往后传。
```

如果你现在只准备记一个版本：

```text
就记方法二：哑节点 + 逐位模拟竖式加法
```
