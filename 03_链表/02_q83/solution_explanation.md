# LeetCode 83. 删除排序链表中的重复元素（Remove Duplicates from Sorted List）解析

## 题目描述

给定一个 **已排序** 的链表头节点 `head`，删除所有重复元素，使每个元素只出现一次，并返回仍然保持有序的链表。

例如：

```text
输入：1 -> 1 -> 2
输出：1 -> 2
```

再比如：

```text
输入：1 -> 1 -> 2 -> 3 -> 3
输出：1 -> 2 -> 3
```

---

## 先抓住这题最关键的条件

这题最重要的不是“删除重复”，而是：

```text
链表已经有序
```

这句话会直接改变做法。

因为一旦链表有序，所有重复值一定会挨在一起。

例如：

```text
1 -> 1 -> 1 -> 2 -> 3 -> 3
```

重复元素不会散落在链表各处，而是会形成一段一段的连续块。

所以这题真正考的是：

```text
遍历链表时，如何利用“相邻重复”这个性质，把多余节点跳过去
```

这也是为什么它会被当成链表入门题。

---

## 方法一：哈希集合去重

### 思路

最直接的想法是不管链表有没排序，先用一个集合记录“我见过哪些值”。

遍历时：

- 如果 `curr.next.val` 没见过，就保留它
- 如果 `curr.next.val` 已经见过，就把这个节点跳过

这个方法的好处是思路简单：

```text
见过就删，没见过就留
```

它甚至适用于“链表未排序”的场景。

---

### 代码

```python
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return None

        seen = {head.val}
        curr = head

        while curr.next:
            if curr.next.val in seen:
                curr.next = curr.next.next
            else:
                seen.add(curr.next.val)
                curr = curr.next

        return head
```

---

### 为什么可行

因为集合里始终保存的是：

```text
前面已经出现过的值
```

所以当你看到一个新节点时，只要它的值已经在集合里，就说明它是重复节点，可以删掉。

---

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

---

### 不足在哪里

这个方法虽然能做出来，但它没有利用题目最宝贵的信息：

```text
链表有序
```

既然重复值一定相邻，我们其实根本不需要额外集合。

于是更自然的想法就是：

```text
只比较当前节点和下一个节点
```

这就来到方法二。

---

## 方法二：一次遍历跳过相邻重复（面试主推）

### 核心思路

因为链表已经有序，所以：

```text
如果某个值重复，那么这些重复节点一定连在一起
```

那我们遍历时只需要看一件事：

```text
当前节点 current 和 current.next 的值是不是一样
```

- 如果一样，说明 `current.next` 是重复节点，直接跳过它
- 如果不一样，说明当前节点已经处理干净，可以继续往后走

整个过程完全不需要额外空间。

---

## 为什么这个思路能想到

因为排序链表给了我们一个很强的局部性质：

```text
重复问题被压缩成了“相邻元素比较”问题
```

数组里你可能会想双指针，链表里其实也是一样的感觉，只不过这里不需要左右指针，只需要一个遍历指针：

```text
current
```

它一直负责检查：

```text
当前值和下一个值是否相同
```

一旦相同，就把下一个节点删掉。

这题最关键的转换就是这一步。

---

## 用例子走一遍

假设链表是：

```text
1 -> 1 -> 2 -> 3 -> 3
```

开始时：

```text
current = 第一个 1
```

### 第 1 步

比较：

```text
current.val == current.next.val
1 == 1
```

说明后面的 `1` 是重复节点，所以执行：

```text
current.next = current.next.next
```

链表变成：

```text
1 -> 2 -> 3 -> 3
```

注意这时：

```text
current 先不要往后走
```

因为还要继续确认当前位置后面还有没有重复。

### 第 2 步

现在比较：

```text
1 和 2
```

不相等，说明值 `1` 这一段已经处理完了，`current` 才能后移到 `2`。

### 第 3 步

继续比较：

```text
2 和 3
```

不相等，`current` 后移到第一个 `3`。

### 第 4 步

比较：

```text
3 和 3
```

相等，删掉后一个 `3`，最终得到：

```text
1 -> 2 -> 3
```

这就是这题最完整的过程。

---

### 面试代码

```python
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        cur = head

        while cur and cur.next:
            if cur.val == cur.next.val:
                cur.next = cur.next.next
            else:
                cur = cur.next

        return head
```

---

### 为什么这个方法最适合面试

如果这题你只记一种写法，就记这一种。

### 1. 最贴题目条件

题目已经告诉你链表有序，这个方法正好把这个条件用满：

```text
利用相邻重复，原地删除
```

### 2. 代码很短，但逻辑很稳

你只需要记住两件事：

- 相同：删掉下一个节点
- 不同：当前指针后移

### 3. 复杂度最好

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

这是这题最标准、最适合现场手写的版本。

---

### 容易出错的地方

最容易错的点是：

```text
删掉重复节点之后，不要立刻 current = current.next
```

因为你删掉一个重复节点以后，新的 `current.next` 还有可能继续重复。

比如：

```text
1 -> 1 -> 1 -> 2
```

删掉第二个 `1` 之后，链表会变成：

```text
1 -> 1 -> 2
```

这时还要继续比较当前这个 `1` 和新的下一个 `1`，所以当前位置不能急着往后走。

---

### 面试里怎么讲

你可以这样解释：

```text
因为链表已经有序，所以重复元素一定相邻。
我用一个指针从头往后遍历。
如果当前节点和下一个节点值相同，就说明下一个节点是重复的，直接把它跳过；
如果不同，就说明当前值已经处理完，可以把指针往后移动。
这样每个节点最多被访问一次，所以时间复杂度是 O(n)，空间复杂度是 O(1)。
```

这就是这题最标准的讲法。

---

## 方法三：递归去重（补充理解）

### 思路

递归的想法是：

```text
先把 head.next 开头的子链表去重好，再回来处理 head
```

具体来说：

1. 先递归处理后半段：`head.next = deleteDuplicates(head.next)`
2. 递归回来后，比较 `head` 和 `head.next`
3. 如果相等，就舍弃 `head`
4. 如果不相等，就保留 `head`

---

### 代码

```python
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        head.next = self.deleteDuplicates(head.next)

        if head.val == head.next.val:
            return head.next
        return head
```

---

### 为什么可行

因为递归返回时，`head.next` 后面的部分已经是“去重后的正确链表”了。

这时当前层只需要做一件事：

```text
决定 head 自己留不留
```

如果 `head.val == head.next.val`，那就说明当前这个 `head` 是重复的，直接跳过它即可。

---

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

空间复杂度来自递归栈。

---

### 它适合什么时候学

它适合作为：

- 递归思维练习
- 理解“当前节点的命运由后面子问题结果决定”这种写法

但如果你现在是二刷、或者面试只准备记一种：

```text
还是优先记方法二
```

---

## 三种方法的关系

这题三种做法的递进关系很清楚：

- **方法一**：不利用排序，先用集合完成“删除重复”这件事
- **方法二**：真正利用排序，把问题变成“相邻比较 + 原地跳过”
- **方法三**：把方法二的逻辑换成递归表达

所以你复习时最应该抓住的是：

```text
排序链表里的重复值一定相邻，因此直接比较 cur 和 cur.next
```

这句话就是这题的核心。

---

## 复杂度总结

| 方法 | 时间复杂度 | 空间复杂度 | 评价 |
| --- | --- | --- | --- |
| 方法一：哈希集合去重 | `O(n)` | `O(n)` | 能做，但没利用有序条件 |
| 方法二：一次遍历跳过相邻重复 | `O(n)` | `O(1)` | 面试主推 |
| 方法三：递归去重 | `O(n)` | `O(n)` | 有助于理解，但现场不如迭代稳 |

---

## 总结

这题最重要的不是“会不会删节点”，而是要先想到：

```text
因为链表有序，所以重复值一定相邻
```

一旦这句话通了，方法二就会非常自然。

如果你现在只记一个版本：

```text
就记方法二：一次遍历跳过相邻重复
```
