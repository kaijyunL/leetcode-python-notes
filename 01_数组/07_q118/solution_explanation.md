# LeetCode 118. 杨辉三角（Pascal's Triangle）解析

## 题目描述

给定一个非负整数 `numRows`，生成杨辉三角的前 `numRows` 行。

例如：

```text
numRows = 5
```

返回：

```text
[
  [1],
  [1, 1],
  [1, 2, 1],
  [1, 3, 3, 1],
  [1, 4, 6, 4, 1]
]
```

---

## 先理解这题最核心的规律

杨辉三角最重要的规律只有一句话：

```text
每一行的首尾都是 1
中间每个数 = 上一行左上角 + 上一行右上角
```

比如第 4 行：

```text
[1, 3, 3, 1]
```

怎么来的？

- 第一个数固定是 `1`
- 最后一个数固定是 `1`
- 中间第一个 `3 = 1 + 2`
- 中间第二个 `3 = 2 + 1`

也就是它来自上一行：

```text
[1, 2, 1]
```

所以这题本质不是在“算组合数”，而是在：

```text
按规则一行一行把三角形构造出来
```

---

## 方法一：递归定义 + 记忆化

### 思路

最直观的想法是直接照着定义写。

如果我们把第 `row` 行第 `col` 列的值记成 `value(row, col)`，那么：

- 如果 `col == 0` 或 `col == row`，说明它在边界上，值一定是 `1`
- 否则：

```text
value(row, col) = value(row - 1, col - 1) + value(row - 1, col)
```

这和杨辉三角的定义完全一致。

---

### 为什么要加记忆化

如果直接递归，会有大量重复计算。

比如你在算：

```text
value(4, 2)
```

它会递归去算：

```text
value(3, 1) 和 value(3, 2)
```

而这两个子问题继续往下展开时，又会重复算一些更小的格子。

所以我们用缓存把已经算过的位置记下来。

这样每个位置最多只会真正计算一次。

---

### 代码

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        @lru_cache(None)
        def value(row, col):
            if col == 0 or col == row:
                return 1
            return value(row - 1, col - 1) + value(row - 1, col)

        triangle = []
        for row in range(numRows):
            current_row = []
            for col in range(row + 1):
                current_row.append(value(row, col))
            triangle.append(current_row)

        return triangle
```

---

### 为什么可行

因为它就是把杨辉三角的数学定义原样翻译成代码。

每个格子的值都来自更上一层的两个格子，而边界格子固定是 `1`。

所以只要递归定义正确，整张三角形就一定能生成出来。

---

### 复杂度

- 时间复杂度：`O(numRows^2)`
- 空间复杂度：`O(numRows^2)`

因为总共就有这么多个位置，每个位置在记忆化之后只会被计算一次。

---

### 这个方法的特点

它的优点是：

```text
非常贴近定义，容易帮助理解杨辉三角是怎么长出来的
```

但它不是最适合面试现场手写的方法。

因为：

- 需要写递归
- 需要写缓存
- 虽然思路直观，但实现不如迭代法自然

---

## 方法二：按行迭代构造（面试主推）

### 核心思路

既然每一行都只依赖上一行，那我们完全可以：

```text
从上到下，一行一行生成
```

做法是：

1. 先生成当前行长度为 `row + 1` 的数组，并全部初始化成 `1`
2. 因为首尾本来就应该是 `1`，所以不用动它们
3. 只去填中间位置
4. 中间位置的值来自上一行：

```text
current_row[col] = triangle[row - 1][col - 1] + triangle[row - 1][col]
```

---

### 为什么初始化成全 1 很自然

因为每一行的第一个和最后一个元素本来就是 `1`。

例如第 5 行长度是 5：

```text
[1, 1, 1, 1, 1]
```

真正需要计算的，其实只有中间那几个位置。

这样写会比先单独处理首尾更顺手。

---

### 用例子走一遍

假设：

```text
numRows = 5
```

我们一行一行构造。

### 第 0 行

长度是 `1`：

```text
[1]
```

### 第 1 行

长度是 `2`：

```text
[1, 1]
```

这一行没有中间位置，不需要计算。

### 第 2 行

先初始化：

```text
[1, 1, 1]
```

中间位置只有一个：

```text
current_row[1] = 1 + 1 = 2
```

得到：

```text
[1, 2, 1]
```

### 第 3 行

先初始化：

```text
[1, 1, 1, 1]
```

中间两个位置：

- `current_row[1] = 1 + 2 = 3`
- `current_row[2] = 2 + 1 = 3`

得到：

```text
[1, 3, 3, 1]
```

后面就完全同理。

---

### 面试代码

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        triangle = []

        for row in range(numRows):
            current_row = [1] * (row + 1)
            for col in range(1, row):
                current_row[col] = triangle[row - 1][col - 1] + triangle[row - 1][col]
            triangle.append(current_row)

        return triangle
```

---

### 这段代码为什么这样写

这里最关键的是两个循环。

### 外层循环 `for row in range(numRows)`

它表示：

```text
我要从第 0 行一直构造到第 numRows - 1 行
```

### 内层循环 `for col in range(1, row)`

它表示：

```text
只填当前行的中间位置
```

为什么是 `1` 到 `row - 1`？

因为：

- `0` 是最左边，固定为 `1`
- `row` 是最右边，固定为 `1`

所以真正需要算的只有中间部分。

这个循环范围如果你在面试里能讲清楚，说明你对这题是真的理解了，不是死记。

---

### 复杂度

- 时间复杂度：`O(numRows^2)`
- 空间复杂度：`O(numRows^2)`

因为最终返回结果本身就包含这么多个数字。

---

## 为什么这个方法最适合面试

这题最适合面试的方法就是：

```text
按行迭代构造
```

原因有三个。

### 1. 思路最顺

题目让你“生成前几行”，那最自然的就是一行一行往下生成。

### 2. 代码最稳

不需要递归，不需要缓存，也没有什么复杂状态。

### 3. 它正好体现了题目的核心规律

每一行依赖上一行，这本质上就是一个非常直接的状态转移过程。

所以面试里既好写，也好讲。

---

## 面试里可以怎么讲

你可以这样解释：

```text
杨辉三角每一行的首尾都是 1，中间每个数等于上一行左上角和右上角两个数之和。
所以我可以从上到下一行一行构造。
对于当前行，我先初始化一个全 1 的数组，因为首尾本来就是 1。
然后只遍历中间位置，把它们用上一行的两个相邻元素之和填出来。
这样最终就能得到前 numRows 行。

总元素个数是 1 + 2 + ... + numRows，所以时间复杂度是 O(numRows^2)。
```

这就是这题最标准的面试表达。

---

## 总结

| 方法 | 时间复杂度 | 空间复杂度 | 评价 |
| --- | --- | --- | --- |
| 方法一：递归定义 + 记忆化 | `O(numRows^2)` | `O(numRows^2)` | 贴近定义，适合理解 |
| 方法二：按行迭代构造 | `O(numRows^2)` | `O(numRows^2)` | 面试主推 |

这题最重要的一句话是：

```text
不要把它当成独立计算每个数的问题，而要把它当成“上一行生成下一行”的构造题。
```
