# 115. 不同的子序列

## 题目理解

给你两个字符串 `s` 和 `t`，你需要返回：

> `s` 的子序列中，有多少种不同方式可以组成 `t`。

这里要特别注意两点：

1. **子序列不要求连续**
2. 题目问的不是“能不能组成”，而是“有多少种组成方式”

例如：

```text
s = "rabbbit"
t = "rabbit"
答案是 3
```

因为 `s` 里有 3 种不同的删法，最后都能得到 `rabbit`。

再看一个经典例子：

```text
s = "babgbag"
t = "bag"
答案是 5
```

这题和：

- [1143. 最长公共子序列](../09_q1143/1143_longest_common_subsequence.md)
- [72. 编辑距离](../08_q72/72_edit_distance.md)

都属于双序列 DP。

但它和前两题最大的不同是：

> 这题不是求“最优值”或“是否可行”，而是求“方案数”。

所以状态转移的思维会不一样。

---

## 为什么这题适合这样学

这题非常适合按下面这条线理解：

```text
暴力递归 -> 记忆化搜索 -> 二维 DP -> 一维压缩 DP
```

你最需要想明白的是：

- 为什么状态要定义成两个前缀
- 当 `s[i - 1] == t[j - 1]` 时，为什么是“加法”而不是 `max` 或 `or`
- 当 `s[i - 1] != t[j - 1]` 时，为什么只能跳过 `s[i - 1]`

这题真正难的地方，不在代码，而在于把“匹配问题”切换成“计数问题”的思维。

---

## 方法一：暴力递归

### 思路

设：

```text
dfs(i, j) = s[i:] 中有多少种方式可以组成 t[j:]
```

如果 `t` 已经匹配完了，也就是：

```text
j == len(t)
```

那说明找到了一种合法方案，返回 `1`。

如果 `s` 已经用完了，但 `t` 还没匹配完，那就不可能再组成，返回 `0`。

接下来分情况：

### 情况 1：当前字符相等

如果：

```text
s[i] == t[j]
```

那有两种选择：

1. 用 `s[i]` 去匹配 `t[j]`
2. 不用 `s[i]`，继续往后找别的位置来匹配 `t[j]`

所以：

```text
dfs(i, j) = dfs(i + 1, j + 1) + dfs(i + 1, j)
```

### 情况 2：当前字符不相等

那 `s[i]` 不可能拿来匹配 `t[j]`，只能跳过它：

```text
dfs(i, j) = dfs(i + 1, j)
```

### 代码

```python
# 方法一：暴力递归
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)

        def dfs(i, j):
            if j == n:
                return 1
            if i == m:
                return 0
            if s[i] == t[j]:
                return dfs(i + 1, j + 1) + dfs(i + 1, j)
            return dfs(i + 1, j)

        return dfs(0, 0)
```

### 复杂度

- 时间复杂度：较高，存在大量重复子问题
- 空间复杂度：递归栈最坏 `O(m + n)`

### 评价

这个方法最适合理解计数逻辑。

但重复计算很多，效率很差。

---

## 方法二：记忆化搜索

### 思路

方法一的问题，不是状态定义不对，而是：

```text
dfs(i, j)
```

会被重复计算很多次。

所以只要加一个 `memo`，把算过的状态记下来，就能把复杂度降下来。

### 代码

```python
# 方法二：记忆化搜索
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        memo = {}

        def dfs(i, j):
            if j == n:
                return 1
            if i == m:
                return 0
            if (i, j) in memo:
                return memo[(i, j)]
            if s[i] == t[j]:
                memo[(i, j)] = dfs(i + 1, j + 1) + dfs(i + 1, j)
                return memo[(i, j)]

            memo[(i, j)] = dfs(i + 1, j)
            return memo[(i, j)]

        return dfs(0, 0)
```

### 复杂度

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(m * n)`

### 评价

这个方法已经很好了，而且很适合把递归定义平滑过渡到 DP。

但面试里通常更推荐直接写迭代 DP，因为更标准。

---

## 方法三：二维动态规划（最适合面试）

### 为什么这个最适合面试

这题如果面试只准备一个版本，我最推荐二维 DP。

原因：

1. 状态定义非常标准
2. 转移逻辑完整，特别适合讲清楚“为什么是加法”
3. 边界初始化很有代表性
4. 是双序列计数 DP 的经典题

所以这题最适合面试的方法，就是二维 DP。

---

### 第一步：定义状态

定义：

```text
dp[i][j] = s 前 i 个字符 中，有多少种方式可以组成 t 前 j 个字符
```

也就是：

```text
s[:i] -> t[:j]
```

注意这题是“多少种方式”，所以 `dp[i][j]` 表示的是**方案数**。

---

### 第二步：边界初始化

如果 `t` 是空串，那不管 `s` 前缀是什么，都有且只有 1 种方式组成它：

```text
什么都不选
```

所以：

```text
dp[i][0] = 1
```

如果 `s` 是空串，但 `t` 不是空串，那一定无法组成：

```text
dp[0][j] = 0  (j > 0)
```

这个初始化是这题最关键的边界之一。

---

### 第三步：状态转移

看当前字符：

```text
s[i - 1] 和 t[j - 1]
```

#### 情况 1：字符相等

如果：

```text
s[i - 1] == t[j - 1]
```

那有两种来源：

1. **用当前这个字符来匹配**
   - 方案数来自 `dp[i - 1][j - 1]`
2. **不用当前这个字符来匹配**
   - 方案数来自 `dp[i - 1][j]`

所以：

```text
dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
```

#### 情况 2：字符不相等

如果：

```text
s[i - 1] != t[j - 1]
```

那当前这个 `s[i - 1]` 根本不能拿来匹配 `t[j - 1]`，只能跳过：

```text
dp[i][j] = dp[i - 1][j]
```

---

### 代码

```python
# 方法三：二维动态规划
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(m + 1):
            dp[i][0] = 1

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s[i - 1] == t[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
                else:
                    dp[i][j] = dp[i - 1][j]

        return dp[m][n]
```

### 复杂度

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(m * n)`

### 面试怎么讲

面试里建议你按这条线讲：

1. `dp[i][j]` 表示前缀到前缀的方案数
2. 空串 `t` 永远有 1 种匹配方式
3. 当前字符相等时，分成“用它”和“不用它”两类方案
4. 当前字符不等时，只能跳过 `s[i - 1]`

这题最适合你展示“计数型 DP”和“最值型 DP”的区别。

## 方法四：一维压缩 DP

### 思路

观察二维 DP：

```text
dp[i][j]
```

只依赖上一行：

- `dp[i - 1][j - 1]`
- `dp[i - 1][j]`

所以可以压成一维数组。

但这题和前面几题不太一样：

- 这里必须 **从右往左更新**
- 因为如果从左往右，会把当前行刚更新出来的值错误地拿去继续用

### 代码

```python
# 方法四：一维压缩动态规划
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        dp = [0] * (n + 1)
        dp[0] = 1

        for i in range(1, m + 1):
            for j in range(n, 0, -1):
                if s[i - 1] == t[j - 1]:
                    dp[j] = dp[j - 1] + dp[j]

        return dp[n]
```

### 复杂度

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(n)`

### 评价

这个方法更省空间，但更新方向很容易写错。

如果是面试现场，我还是更推荐先写二维 DP。

因为二维 DP：

- 更稳
- 更容易讲
- 更不容易在转移方向上出错

---

## 最后总结

这题建议这样记：

- **核心状态**：`s` 前缀组成 `t` 前缀的方案数
- **关键区别**：这题是“计数”，不是“最值”也不是“可行性判断”
- **最适合面试**：二维 DP
- **进阶优化**：一维压缩 DP，且必须从右往左更新

如果你是为了面试准备，这题最值得熟练掌握的是：

> **二维 DP 版本**

因为这题很适合拿来展示你是否真正理解“不同类型 DP 的状态含义和转移差别”。
