# 62. 不同路径

## 题目理解

一个机器人位于一个 `m x n` 网格的左上角。

它每次只能：

- 向下走一格
- 向右走一格

目标是走到右下角。

你需要返回：

> 一共有多少条不同路径。

例如：

```text
m = 3, n = 7
答案是 28
```

```text
m = 3, n = 2
答案是 3
```

因为三条路径分别可以理解为：

```text
右 右 下
右 下 右
下 右 右
```

这题是二维 DP 的门面题，也是网格 DP 最经典的入门题之一。

---

## 为什么这题适合这样学

这题非常适合按下面这条线来理解：

```text
暴力递归 -> 记忆化递归 -> 二维 DP -> 一维压缩 DP -> 组合数学
```

原因是它几乎把二维 DP 的核心思路都展示出来了：

1. 当前状态从哪里转移来
2. 为什么会有重复子问题
3. 为什么二维表可以压缩成一维
4. 为什么这题还能进一步转成数学计数

所以这题不只是会做一道题，而是在学整类网格 DP。

---

## 方法一：暴力递归

### 思路

先从最直观的角度想。

如果当前站在位置：

```text
(row, col)
```

那下一步只有两种可能：

- 向下走到 `(row + 1, col)`
- 向右走到 `(row, col + 1)`

所以可以定义：

```text
dfs(row, col) = 从 (row, col) 走到右下角的路径数
```

那么转移就是：

```text
dfs(row, col) = dfs(row + 1, col) + dfs(row, col + 1)
```

当然，前提是这两个位置没有越界。

### 边界

当走到右下角时：

```text
返回 1
```

因为这表示找到了一条完整路径。

### 代码

```python
# 方法一：暴力递归
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        def dfs(row, col):
            if row == m - 1 and col == n - 1:
                return 1

            ways = 0

            if row + 1 < m:
                ways += dfs(row + 1, col)
            if col + 1 < n:
                ways += dfs(row, col + 1)

            return ways

        return dfs(0, 0)
```

### 复杂度

- 时间复杂度：指数级
- 空间复杂度：`O(m + n)`，递归栈深度

### 评价

这个方法非常适合理解状态来源。

但它会反复计算同一个位置的答案，所以会很慢。

---

## 方法二：记忆化递归

### 思路

暴力递归的问题在于：

```text
dfs(row, col)
```

会被重复计算很多次。

那就很自然：

> 算过的位置结果存下来，下次直接复用。

我们用 `memo[(row, col)]` 保存从这个位置出发的路径数。

### 代码

```python
# 方法二：记忆化递归
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        memo = {}

        def dfs(row, col):
            if row == m - 1 and col == n - 1:
                return 1
            if (row, col) in memo:
                return memo[(row, col)]

            ways = 0

            if row + 1 < m:
                ways += dfs(row + 1, col)
            if col + 1 < n:
                ways += dfs(row, col + 1)

            memo[(row, col)] = ways
            return ways

        return dfs(0, 0)
```

### 复杂度

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(m * n)`

### 评价

这个方法已经很好了。

优点：

- 保留了原始递归思路
- 很容易看出每个位置只算一次

缺点：

- 还是递归写法
- 面试里通常更推荐写迭代 DP

---

## 方法三：二维动态规划（最适合面试）

### 为什么这个最适合面试

这是这题最标准、最稳的写法。

原因：

1. 状态定义非常自然
2. 转移方程非常清楚
3. 边界条件很好处理
4. 完全符合二维 DP 的经典模板

所以这题如果面试只准备一个版本，优先准备这个。

---

### 第一步：定义状态

定义：

```text
dp[row][col] = 从左上角走到 (row, col) 的路径数
```

既然题目要的是走到右下角的路径数，最终答案就是：

```text
dp[m - 1][n - 1]
```

---

### 第二步：转移怎么来

要走到某个格子 `(row, col)`，最后一步只可能来自两个方向：

- 上面 `(row - 1, col)` 向下走一步
- 左边 `(row, col - 1)` 向右走一步

所以：

```text
dp[row][col] = dp[row - 1][col] + dp[row][col - 1]
```

这就是整道题最核心的转移方程。

---

### 第三步：边界怎么定

第一行比较特殊。

因为机器人只能一直向右走，所以第一行的每个位置都只有 1 种走法：

```text
dp[0][col] = 1
```

第一列也一样。

因为只能一直向下走，所以第一列每个位置也都只有 1 种走法：

```text
dp[row][0] = 1
```

这两个边界一旦确定，其他位置就都能靠转移方程推出来。

---

### 第四步：用例子走一遍

以：

```text
m = 3, n = 3
```

为例。

先初始化第一行和第一列：

```text
1 1 1
1 0 0
1 0 0
```

然后从 `(1,1)` 开始推：

- `dp[1][1] = dp[0][1] + dp[1][0] = 1 + 1 = 2`
- `dp[1][2] = dp[0][2] + dp[1][1] = 1 + 2 = 3`
- `dp[2][1] = dp[1][1] + dp[2][0] = 2 + 1 = 3`
- `dp[2][2] = dp[1][2] + dp[2][1] = 3 + 3 = 6`

最后答案就是：

```text
6
```

---

### 代码

```python
# 方法三：二维动态规划
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[0] * n for _ in range(m)]

        for row in range(m):
            dp[row][0] = 1
        for col in range(n):
            dp[0][col] = 1

        for row in range(1, m):
            for col in range(1, n):
                dp[row][col] = dp[row - 1][col] + dp[row][col - 1]

        return dp[m - 1][n - 1]
```

### 复杂度

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(m * n)`

---

### 面试时推荐怎么讲

你可以这样讲：

#### 1. 先定义状态

```text
dp[row][col] 表示走到当前格子的路径数
```

#### 2. 再解释最后一步来源

走到当前格子，只可能从上面来或者从左边来。

#### 3. 写出转移

```text
dp[row][col] = dp[row - 1][col] + dp[row][col - 1]
```

#### 4. 说明边界

- 第一行全是 1
- 第一列全是 1

#### 5. 最后返回

```text
dp[m - 1][n - 1]
```

这套讲法非常完整，而且非常像二维 DP 的标准答案。

## 方法四：一维压缩动态规划

### 思路

观察方法三会发现：

```text
dp[row][col]
```

只依赖：

- 当前行左边的值
- 上一行同列的值

所以我们没有必要保留整张二维表。

可以用一维数组：

```text
dp[col]
```

来表示“当前处理到这一行时，每一列的路径数”。

更新时：

```text
dp[col] = dp[col] + dp[col - 1]
```

其中：

- `dp[col]` 更新前表示上方路径数
- `dp[col - 1]` 表示左边路径数

### 代码

```python
# 方法四：一维压缩动态规划
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [1] * n

        for _ in range(1, m):
            for col in range(1, n):
                dp[col] += dp[col - 1]

        return dp[-1]
```

### 复杂度

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(n)`

### 评价

这个方法是标准 DP 的空间优化版。

如果面试官追问空间优化，可以继续写这个版本。

## 方法五：组合数学（复杂度最优）

### 思路

这题其实还可以不用 DP，直接从数学角度计算。

从左上走到右下，总共一定要走：

- `m - 1` 步向下
- `n - 1` 步向右

所以总步数固定是：

```text
m + n - 2
```

问题就变成：

> 在这 `m + n - 2` 步里，选哪 `m - 1` 步向下。

或者等价地：

> 选哪 `n - 1` 步向右。

所以答案就是组合数：

```text
C(m + n - 2, m - 1)
```

或者：

```text
C(m + n - 2, n - 1)
```

### 代码

```python
# 方法五：组合数学
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        total = m + n - 2
        choose = min(m - 1, n - 1)
        answer = 1

        for i in range(1, choose + 1):
            answer = answer * (total - choose + i) // i

        return answer
```

### 复杂度

- 时间复杂度：`O(min(m, n))`
- 空间复杂度：`O(1)`

### 评价

这是复杂度最优的方法。

优点：

- 时间更优
- 空间最优

缺点：

- 不如 DP 那么直观
- 如果面试场景是在考二维 DP，直接写数学法有时不如先写 DP 稳

---

## 哪个方法最适合面试

### 结论

**最适合面试的是：方法三，二维动态规划。**

### 为什么不是别的方法

#### 方法一：暴力递归

- 适合理解状态
- 但会超时
- 不能作为最终答案

#### 方法二：记忆化递归

- 能通过
- 也很自然
- 但一般没有迭代 DP 稳

#### 方法四：一维压缩 DP

- 很好
- 但本质上是方法三的优化版
- 面试里通常先写二维 DP 更清晰

#### 方法五：组合数学

- 复杂度最优
- 但不如 DP 直观
- 如果题目背景是二维 DP 专题，面试里通常先交 DP 更顺

所以综合来看：

> **方法三最标准，最稳，也最适合作为面试主答案。**

## 最适合面试的方法：详细讲解

### 1. 这题的本质是什么

这题不是在求：

- 最短路径长度
- 具体路径长什么样

而是在求：

```text
到达终点一共有多少种走法
```

所以这是一个典型的：

```text
计数型二维 DP
```

---

### 2. 为什么状态定义成“走到当前格子的路径数”

因为这题每个格子的答案，都只和前面的格子有关。

如果定义：

```text
dp[row][col] = 走到这个格子的路径数
```

那么最终答案就是右下角那个格子的值。

这个定义非常自然，也最容易写出转移方程。

---

### 3. 为什么转移一定是“上面 + 左边”

因为机器人只能向右或向下。

所以想走到 `(row, col)`，最后一步只能来自：

- `(row - 1, col)` 向下走一步
- `(row, col - 1)` 向右走一步

不会有第三种来源。

因此：

```text
dp[row][col] = dp[row - 1][col] + dp[row][col - 1]
```

这是这道题最核心的正确性来源。

---

### 4. 为什么第一行和第一列都是 1

第一行只能一直向右走。

所以无论走到第一行哪个格子，都只有一种方法。

第一列只能一直向下走。

所以第一列每个格子也都只有一种方法。

这两个边界初始化之后，整个表就能顺着推完。

---

### 5. 为什么这题是网格 DP 入门题

因为它把网格 DP 的标准套路展示得非常完整：

- 定义二维状态
- 找转移来源
- 处理边界行和边界列
- 最后返回右下角

后面的很多网格 DP，比如 `63`、`64`、`221`，都能从这题继续延伸。

---

### 6. 面试里怎么说最自然

你可以这样讲：

> 我定义 `dp[row][col]` 表示从左上角走到当前位置的路径数。由于机器人只能向右或向下，所以走到当前格子只可能从上边或者左边过来，因此转移方程是 `dp[row][col] = dp[row - 1][col] + dp[row][col - 1]`。边界是第一行和第一列都只有一种走法，所以初始化为 1。最后返回 `dp[m - 1][n - 1]`。

这套表述就是非常标准的二维 DP 面试答案。

---

### 面试最推荐代码

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[0] * n for _ in range(m)]

        for row in range(m):
            dp[row][0] = 1
        for col in range(n):
            dp[0][col] = 1

        for row in range(1, m):
            for col in range(1, n):
                dp[row][col] = dp[row - 1][col] + dp[row][col - 1]

        return dp[m - 1][n - 1]
```

## 总结

### 递进关系

1. **暴力递归**
   - 最直观
   - 但重复子问题很多

2. **记忆化递归**
   - 消除重复计算
   - 保留递归思路

3. **二维动态规划**
   - 最标准
   - 最适合面试

4. **一维压缩动态规划**
   - 在标准 DP 基础上优化空间

5. **组合数学**
   - 复杂度最优
   - 但面试里通常不是首选表达

### 一句话记忆

> 走到每个格子的路径数，等于走到它上边格子的路径数加上走到它左边格子的路径数。
