# LeetCode 80. 删除有序数组中的重复项 II (Remove Duplicates from Sorted Array II)

## 题目

给定一个 **有序** 数组 `nums`，原地删除重复出现的元素，
使得每个元素 **最多出现两次**，返回删除后数组的新长度。

不要使用额外数组空间，必须原地修改，`O(1)` 额外空间。

比如：

```text
nums = [1, 1, 1, 2, 2, 3]
```

返回 `5`，前 5 个元素变成：

```text
[1, 1, 2, 2, 3]
```

---

## 这题真正考的是什么

表面上看，这题是在问：

```text
把超过 2 次的重复删掉
```

但它其实是 `26` 删除有序数组中的重复项的升级版：

```text
26：每个元素最多保留 1 次
80：每个元素最多保留 2 次
```

核心结构完全一样：

```text
快指针往前扫描，慢指针标记保留区末尾
能保留就覆盖写入，不能保留就跳过
```

区别只在于 **判断条件** 从“和前一个不同”变成了“和前两个不同”。

---

## 这题和 26 的关系

| | 26 删除重复项 I | 80 删除重复项 II |
| --- | --- | --- |
| 保留几次 | 1 次 | 2 次 |
| 比较位置 | `nums[fast] != nums[slow-1]` | `nums[fast] != nums[slow-2]` |
| 起始下标 | `slow = 1` | `slow = 2` |

一句话：

```text
允许保留 K 次，就和 slow-K 比；起始下标就是 K
```

所以这题的模板可以推广到任意 K。

---

## 方法一：暴力 pop 删除

### 核心思路

遍历数组，统计当前数字出现次数。
超过 2 次就 `pop` 掉多余的那个，后续元素前移。

---

### 为什么它可行

它就是直接模拟“删掉多余重复”这个过程。
逻辑正确，但 `pop` 会导致后面所有元素前移，每次 `pop` 是 `O(n)`。

---

### 复杂度

- 时间复杂度：`O(n^2)`，最坏情况每次 `pop` 都要移动一堆元素
- 空间复杂度：`O(1)`

---

### 评价

这是保底做法，能帮你建立“统计次数 + 删除”的直觉。
但 `pop` 太慢，面试里不会主推。

---

## 方法二：快慢指针覆盖写（面试主推）

### 核心思路

用两个指针：

- `fast`：往前扫描每个元素
- `slow`：标记保留区的末尾，下一个要写入的位置

关键判断：

```text
nums[fast] 能不能写到 nums[slow]？
```

判断标准是：**`nums[fast]` 和 `nums[slow - 2]` 是否相等**。

- 不相等：可以写，`nums[slow] = nums[fast]`，`slow += 1`
- 相等：说明 `slow` 前面已经有两个一样的了，不能再写，跳过

---

### 为什么和 slow-2 比

这是这题最关键的问题。

`slow` 是下一个要写入的位置。
写入之前，`nums[slow-1]` 和 `nums[slow-2]` 是已经保留的最后两个元素。

因为数组有序，相同的数一定挨在一起。
所以：

```text
如果 nums[fast] == nums[slow-2]
```

说明 `nums[slow-2]`、`nums[slow-1]`、`nums[fast]` 三个都一样
（有序数组里，相等的一定连续）。

也就是说，这个数已经保留了两个，不能再保留了。

反过来：

```text
如果 nums[fast] != nums[slow-2]
```

说明写入它不会导致连续三个相同，可以保留。

**一句话：和 `slow-2` 比，就是在问“前面是不是已经有两个和我一样的了”。**

---

### 为什么前两个不用处理

数组有序，前两个元素（下标 0 和 1）无论是什么，
都最多出现两次，一定合法。

所以 `slow` 和 `fast` 都从 `2` 开始，直接跳过前两个。

---

### 过程演示

```text
nums = [1, 1, 1, 2, 2, 3]
下标   0  1  2  3  4  5
```

初始化：

```text
slow = 2
```

#### fast = 2，值 1

```text
nums[2]=1 vs nums[slow-2]=nums[0]=1
```

相等，说明 `1` 已经保留了两个（下标 0、1），跳过。

```text
nums = [1, 1, 1, 2, 2, 3]   (没变)
slow = 2
```

#### fast = 3，值 2

```text
nums[3]=2 vs nums[slow-2]=nums[0]=1
```

不相等，可以写入：

```text
nums[2] = 2
nums = [1, 1, 2, 2, 2, 3]
slow = 3
```

#### fast = 4，值 2

```text
nums[4]=2 vs nums[slow-2]=nums[1]=1
```

不相等，可以写入：

```text
nums[3] = 2
nums = [1, 1, 2, 2, 2, 3]
slow = 4
```

#### fast = 5，值 3

```text
nums[5]=3 vs nums[slow-2]=nums[2]=2
```

不相等，可以写入：

```text
nums[4] = 3
nums = [1, 1, 2, 2, 3, 3]
slow = 5
```

遍历结束，返回 `slow = 5`，前 5 个元素是 `[1, 1, 2, 2, 3]`。

---

### 为什么这是面试主推

#### 1. 它是最优解

- 时间 `O(n)`：一次遍历
- 空间 `O(1)`：只用两个变量

#### 2. 它是 26 的直接推广

```text
26：和 slow-1 比，保留 1 次
80：和 slow-2 比，保留 2 次
通用：和 slow-K 比，保留 K 次
```

记住这一个模板，任意 K 都能写。

#### 3. 覆盖写比 pop 优雅得多

不删除、不移动，只往保留区写。
覆盖掉的多余元素不影响结果，因为只看前 `slow` 个。

---

### 面试代码

```python
class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        if len(nums) <= 2:
            return len(nums)

        slow = 2

        for fast in range(2, len(nums)):
            if nums[fast] != nums[slow - 2]:
                nums[slow] = nums[fast]
                slow += 1

        return slow
```

---

### 容易出错的地方

#### 1. 起始位置是 2，不是 1

因为允许保留两次，前两个一定合法。
`26` 题从 `1` 开始，这题从 `2` 开始。

#### 2. 比较的是 slow-2，不是 slow-1

```python
if nums[fast] != nums[slow - 2]:
```

和 `slow-1` 比是 `26` 题的写法（保留 1 次）。
这题保留 2 次，所以要往前多看一位。

#### 3. 要先处理数组长度小于等于 2 的情况

```python
if len(nums) <= 2:
    return len(nums)
```

否则 `slow = 2` 会越界。

#### 4. 返回的是 slow，不是 slow+1

`slow` 是下一个要写入的位置，
所以已经写入的是 `0` 到 `slow-1`，共 `slow` 个。

---

### 复杂度

- 时间复杂度：`O(n)`，一次遍历
- 空间复杂度：`O(1)`，两个变量

---

## 两种方法的关系

- **方法一**：暴力 `pop` 删除，建立“统计次数 + 删除”的直觉，但 `O(n^2)` 太慢
- **方法二**：快慢指针覆盖写，不删不移只覆盖，`O(n)` 且可推广到任意 K

这题最值得记住的一句话是：

```text
允许保留 K 次，就和 slow-K 比；覆盖写入比删除移动优雅得多
```

想通这一点，这题就是 `26` 的直接推广。

---

## 复杂度总结

| 方法 | 时间复杂度 | 空间复杂度 | 评价 |
| --- | --- | --- | --- |
| 方法一：暴力 pop 删除 | `O(n^2)` | `O(1)` | 保底，太慢 |
| 方法二：快慢指针覆盖写 | `O(n)` | `O(1)` | 面试主推，可推广任意 K |

---

## 总结

如果你现在只准备记一个版本：

```text
就记方法二：快慢指针覆盖写
```

因为它同时帮你巩固了三件事：

- 覆盖写思想：不删不移，只往保留区写
- 通用模板：和 `slow-K` 比，保留 K 次
- 和 `26` 的关系：`slow-1` 保留 1 次，`slow-2` 保留 2 次

这题是 `26` 的直接升级版，放在一起记，快慢指针去重的模板就全了。
