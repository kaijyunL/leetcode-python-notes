# LeetCode 3. 无重复字符的最长子串解析

## 题目描述

给定一个字符串 `s`，请你找出其中不含重复字符的最长子串长度。

注意这里说的是：

```text
子串
```

不是子序列。

子串必须连续。

例如：

```text
s = "abcabcbb"
```

最长的不重复子串是：

```text
"abc"
```

长度是：

```text
3
```

---

## 先理解题意

这题最容易混淆的点只有一个：

```text
必须是连续的一段
```

所以：

- `"abc"` 是 `"abcabcbb"` 的子串
- `"acb"` 不是，因为它不连续

这题真正要做的是：

```text
在所有连续子串里，找一个没有重复字符的，且长度最大
```

判断“没有重复字符”的标准很直接：

```text
同一个窗口里，每个字符只能出现一次
```

---

## 方法一：暴力枚举所有子串

### 思路

最直接的方法是枚举所有子串。

一个子串由两个边界决定：

- `left`：起点
- `right`：终点

所以可以先枚举 `left`，再枚举 `right`，得到每个子串 `s[left:right + 1]`。

然后再判断这个子串里有没有重复字符。

如果没有重复，就用它的长度更新答案。

---

### 为什么可行

因为它把所有可能的子串都试了一遍。

只要真正的最长无重复子串存在，枚举到它时就一定会被检查到。

这是最朴素的正确性来源：

```text
全枚举，所以不会漏
```

---

### 复杂度

- 时间复杂度：`O(n^3)`
- 空间复杂度：`O(min(n, m))`

其中 `m` 是字符集大小。

为什么是 `O(n^3)`：

1. 两层循环枚举所有子串
2. 每个子串还要再扫描一遍检查重复

---

### 这个方法慢在哪里

慢在：

```text
很多相邻子串的重复检查是重复劳动
```

比如：

```text
"abc"
"abca"
"abcab"
```

这些子串前面的大部分字符都被反复检查。

所以接下来自然会想：

```text
固定起点后，能不能一边向右扩展，一边复用已经检查过的信息？
```

---

## 方法二：固定起点，向右扩展到重复为止

### 思路

比起“每次重新检查整个子串”，可以换一种方式：

固定一个起点 `left` 后，向右扩展 `right`。

扩展过程中用集合 `seen` 记录当前已经出现过的字符。

如果：

- `s[right]` 没出现过，就继续扩展
- `s[right]` 已经出现过，说明从这个 `left` 出发，再往右也不可能得到无重复子串了，可以直接停止当前起点

---

### 为什么比方法一快

因为它不再对每个子串都“从头重新检查一遍”。

它把“是否重复”的判断，变成了：

```text
当前新加入的这个字符，是否已经在集合里
```

这样固定一个起点后，右边只会一路扩展，遇到重复就停。

---

### 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(min(n, m))`

---

### 这个方法还差在哪里

它虽然避免了很多重复检查，但还是有一个问题：

```text
每换一个 left，右边又要从头开始扩展一遍
```

也就是说，不同起点之间还没有共享信息。

这就引出真正的最优思路：滑动窗口。

---

## 方法三：滑动窗口 + 哈希集合（面试主推）

这是最适合面试讲清楚的一版。

---

### 核心想法

维护一个窗口：

```text
s[left:right + 1]
```

并让这个窗口始终满足：

```text
窗口内没有重复字符
```

这里：

- `right` 负责不断向右扩张窗口
- `left` 负责在出现重复时收缩窗口

再用集合 `seen` 记录当前窗口里有哪些字符。

---

### 为什么这就是滑动窗口

因为窗口不是每次重建，而是在原来的基础上滑动。

当 `right` 看到一个新字符时：

- 如果它不在 `seen` 里，窗口可以直接扩大
- 如果它已经在 `seen` 里，说明窗口不合法了，就让 `left` 向右移动，把重复字符逐步移出窗口

直到窗口重新变成“无重复”状态。

---

### 用例子走一遍

输入：

```text
s = "abcabcbb"
```

开始时：

```text
left = 0
seen = {}
ans = 0
```

---

### `right = 0`，字符是 `"a"`

`"a"` 不在 `seen` 中，可以加入：

```text
窗口 = "a"
seen = {"a"}
ans = 1
```

---

### `right = 1`，字符是 `"b"`

`"b"` 不重复，继续加入：

```text
窗口 = "ab"
seen = {"a", "b"}
ans = 2
```

---

### `right = 2`，字符是 `"c"`

继续加入：

```text
窗口 = "abc"
seen = {"a", "b", "c"}
ans = 3
```

---

### `right = 3`，字符又是 `"a"`

现在 `"a"` 已经在窗口里了，不能直接加入。

所以要移动 `left`，把左边字符逐个移出去：

先移出 `s[left] = "a"`：

```text
left 从 0 变成 1
seen = {"b", "c"}
```

这时窗口里已经没有重复的 `"a"` 了，再把当前 `"a"` 加进去：

```text
窗口 = "bca"
seen = {"b", "c", "a"}
ans 仍然是 3
```

后面继续同样处理，最终答案是 `3`。

---

### 为什么时间复杂度是 `O(n)`

这个地方是理解滑动窗口最关键的一步。

虽然代码里有一个 `for` 和一个 `while`，但整体不是 `O(n^2)`。

原因是：

- 每个字符最多被 `right` 加入窗口一次
- 每个字符最多被 `left` 移出窗口一次

也就是说，`left` 和 `right` 都只会从左到右走一遍，不会回头。

所以总操作次数是线性的。

---

### 为什么这是我推荐的面试版本

这版不一定是代码最短的，但通常是最适合现场稳定写出来的。

原因有三点：

1. 思路最自然，容易从 `O(n^2)` 的方法二推到这里。
2. “窗口里始终无重复”这个不变量很直观，口头解释成本低。
3. 虽然有 `while`，但边界和正确性都不难说清楚。

---

## 方法四：滑动窗口 + 哈希表记录上次出现位置

这是同样 `O(n)` 的进阶写法。

---

### 核心想法

方法三遇到重复字符时，是让 `left` 一步一步右移。

这里可以更直接：

用字典 `last_index` 记录每个字符上一次出现的位置。

当遍历到 `right`、看到字符 `ch` 时：

- 如果 `ch` 没见过，正常处理
- 如果 `ch` 见过，而且它上次出现的位置还在当前窗口里，那么 `left` 可以直接跳到那个位置的下一位

也就是：

```text
left = last_index[ch] + 1
```

但这里有一个关键细节：

```text
left 不能往回退
```

所以真正要写的是：

```python
left = max(left, last_index[ch] + 1)
```

---

### 为什么一定要 `max`

看这个例子：

```text
s = "abba"
```

当遍历到最后一个 `"a"` 时：

- `"a"` 上一次出现的位置是 `0`
- 但当前 `left` 已经因为前面的 `"b"` 重复而移动到 `2`

这时位置 `0` 已经不在当前窗口里了。

如果你直接写：

```python
left = last_index[ch] + 1
```

就会把 `left` 错误地拉回去。

所以必须写：

```python
left = max(left, last_index[ch] + 1)
```

---

### 这个方法和方法三相比怎么样

优点：

- 代码更短
- 不需要在重复时逐个删除字符

缺点：

- 理解门槛更高一点
- 最容易写错的地方就是忘记 `max`

所以如果是刷题学习顺序，我建议先掌握方法三。

如果你已经完全理解窗口不变量，再掌握方法四会更合适。

---

## 方法对比

| 方法 | 思路 | 时间复杂度 | 空间复杂度 | 面试建议 |
|---|---|---:|---:|---|
| 方法一 | 枚举所有子串，再检查重复 | `O(n^3)` | `O(min(n, m))` | 只适合理解 |
| 方法二 | 固定起点，向右扩展到重复为止 | `O(n^2)` | `O(min(n, m))` | 过渡思路 |
| 方法三 | 滑动窗口 + 哈希集合 | `O(n)` | `O(min(n, m))` | **面试主推** |
| 方法四 | 滑动窗口 + 上次出现位置 | `O(n)` | `O(min(n, m))` | 进阶写法 |

---

## 面试该怎么讲

如果面试官让你从头推导，可以按这个顺序说：

```text
先从枚举所有子串开始
-> 发现很多重复检查
-> 改成固定 left，向右扩展到重复为止
-> 再进一步，不同 left 之间也不要重来
-> 用滑动窗口维护“当前窗口无重复”这个不变量
-> right 扩张，left 在重复时收缩
```

如果面试官继续追问能不能再优化表达方式，再补充方法四：

```text
可以用哈希表记录字符上次出现位置，让 left 直接跳
```

---

## 总结

这题最值得记住的不是“滑动窗口”四个字，而是这句话：

```text
窗口里始终保持没有重复字符，right 负责扩张，left 负责在重复时恢复这个性质
```

只要真正理解了这句话，这题就不需要死记模板，自己也能推出来。
