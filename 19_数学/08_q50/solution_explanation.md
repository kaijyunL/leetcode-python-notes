# LeetCode 50. Pow(x, n) 解析

## 题目描述

实现 `pow(x, n)`，也就是计算：

```text
x^n
```

其中：

- `x` 是浮点数
- `n` 是整数，可能为正数、0、负数

例子：

```text
x = 2.00000, n = 10   -> 1024.00000
x = 2.10000, n = 3    -> 9.26100
x = 2.00000, n = -2   -> 0.25000
```

第三个例子里：

```text
2^-2 = 1 / 2^2 = 1 / 4 = 0.25
```

约束里 `n` 是 32 位整数范围：

```text
-2^31 <= n <= 2^31 - 1
```

所以不能只想着把 `x` 乘 `n` 次，因为 `n` 最大可能接近 21 亿。

---

## 先理解题意

这题表面是在写幂函数，真正要处理的是两个问题：

1. **指数很大时，不能线性乘法**
2. **指数可能是负数**

先看负指数：

```text
x^-n = 1 / x^n
```

所以我们可以先把问题统一成计算正指数：

```text
如果 n < 0：
    先计算 x^(-n)
    最后取倒数
```

例如：

```text
2^-10 = 1 / 2^10
```

再看大指数。最直接的乘法是：

```text
2^10 = 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2
```

这要乘 10 次。那如果 `n = 2^31 - 1`，就完全不可接受。

这题的核心优化是：

```text
不要每次只乘一个 x，而是反复利用已经算出来的平方。
```

比如：

```text
2^10
= (2^5)^2
= (2^2 * 2)^2
```

每次都把指数减半，复杂度就能从 `O(n)` 降到 `O(log n)`。

---

## 方法一：暴力连乘

### 思路

按幂的定义直接做：

```text
x^n = x * x * x * ... * x
```

如果 `n` 是负数，先按正指数算出 `x^abs(n)`，最后取倒数。

### 代码

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        exp = abs(n)
        ans = 1.0

        for _ in range(exp):
            ans *= x

        if n < 0:
            return 1.0 / ans
        return ans
```

### 评价

这个方法的优点是完全符合定义，几乎不用推导。

但它会超时：

```text
n = 2147483647
```

意味着要乘 20 多亿次。

复杂度：

- 时间复杂度：`O(|n|)`
- 空间复杂度：`O(1)`

这个方法只适合理解题意，不适合提交，也不适合面试。

下一步要优化的是：**能不能少乘一些？**

---

## 方法二：递归快速幂

### 核心思路

暴力方法慢，是因为每次只把答案多乘一个 `x`。

幂运算有一个很重要的性质：

```text
如果 n 是偶数：
    x^n = (x^(n/2)) * (x^(n/2))

如果 n 是奇数：
    x^n = (x^(n//2)) * (x^(n//2)) * x
```

例如：

```text
2^10 = 2^5 * 2^5
2^5  = 2^2 * 2^2 * 2
2^2  = 2^1 * 2^1
2^1  = 2^0 * 2^0 * 2
```

这样每次都把指数砍半。

### 用 `2^10` 走一遍

```text
pow(2, 10)
  先算 pow(2, 5)

pow(2, 5)
  先算 pow(2, 2)

pow(2, 2)
  先算 pow(2, 1)

pow(2, 1)
  先算 pow(2, 0) = 1
  1 是奇数，所以返回 1 * 1 * 2 = 2

pow(2, 2)
  2 是偶数，所以返回 2 * 2 = 4

pow(2, 5)
  5 是奇数，所以返回 4 * 4 * 2 = 32

pow(2, 10)
  10 是偶数，所以返回 32 * 32 = 1024
```

### 代码

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        def fast_power(exp: int) -> float:
            if exp == 0:
                return 1.0

            half = fast_power(exp // 2)
            ans = half * half

            if exp % 2 == 1:
                ans *= x

            return ans

        ans = fast_power(abs(n))
        if n < 0:
            return 1.0 / ans
        return ans
```

### 变量说明

```python
half = fast_power(exp // 2)
```

表示已经算好的：

```text
x^(exp // 2)
```

接着：

```python
ans = half * half
```

就得到：

```text
x^(2 * (exp // 2))
```

如果 `exp` 是偶数，刚好等于 `x^exp`。

如果 `exp` 是奇数，还差一个 `x`，所以补上：

```python
if exp % 2 == 1:
    ans *= x
```

复杂度：

- 时间复杂度：`O(log |n|)`
- 空间复杂度：`O(log |n|)`，来自递归调用栈

这个方法思路清楚，很适合用来理解快速幂。

但面试现场我更推荐写方法三：迭代快速幂。它不依赖递归栈，边界也更集中。

---

## 方法三：迭代快速幂 / 二进制拆指数（面试主推）

### 核心思路

递归快速幂是从公式角度折半：

```text
x^n = x^(n//2) * x^(n//2) * 是否多乘一个 x
```

迭代快速幂换一个角度：把指数 `n` 写成二进制。

比如：

```text
10 的二进制是 1010
10 = 8 + 2
```

所以：

```text
x^10 = x^8 * x^2
```

我们只需要不断维护：

```text
当前 base = x^(当前二进制位对应的权重)
```

一开始：

```text
base = x      对应 x^1
```

每往下一位，`base` 自己平方：

```text
x       -> x^2
x^2     -> x^4
x^4     -> x^8
x^8     -> x^16
...
```

如果当前二进制位是 1，就把当前 `base` 乘进答案。

### 用 `x^10` 走一遍

```text
10 的二进制：1010
从低位到高位看：0, 1, 0, 1
```

过程如下：

```text
初始：
ans = 1
base = x
exp = 10

exp = 10，二进制最低位是 0：
    不乘 ans
    base = x^2
    exp = 5

exp = 5，二进制最低位是 1：
    ans = 1 * x^2 = x^2
    base = x^4
    exp = 2

exp = 2，二进制最低位是 0：
    不乘 ans
    base = x^8
    exp = 1

exp = 1，二进制最低位是 1：
    ans = x^2 * x^8 = x^10
    base = x^16
    exp = 0，结束
```

最终 `ans = x^10`。

### 面试代码

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0:
            x = 1.0 / x
            n = -n

        ans = 1.0
        base = x

        while n > 0:
            if n & 1:
                ans *= base

            base *= base
            n >>= 1

        return ans
```

### 关键变量

```python
ans
```

表示已经选中的那些二进制位对应的幂的乘积。

```python
base
```

表示当前二进制位对应的幂：

```text
第 0 位：x
第 1 位：x^2
第 2 位：x^4
第 3 位：x^8
...
```

```python
if n & 1:
    ans *= base
```

表示当前最低位是 1，这一位对应的 `base` 要计入答案。

```python
base *= base
n >>= 1
```

表示准备处理下一位：

- `base *= base`：从 `x^1` 到 `x^2`，从 `x^2` 到 `x^4`
- `n >>= 1`：把当前最低位丢掉，继续看下一位

### 为什么负指数可以先处理

如果 `n < 0`：

```python
x = 1.0 / x
n = -n
```

原问题：

```text
x^n
```

比如：

```text
2^-3
```

等价改写为：

```text
(1/2)^3
```

所以后面的循环只需要处理非负指数。

### 容易出错的地方

1. `n == 0` 时应该返回 `1`

   迭代写法里 `ans` 初始为 `1.0`，循环不会进入，天然返回 `1.0`。

2. 负指数不能直接循环

   需要先把底数取倒数，再把指数变成正数。

3. 奇数指数要额外乘一次当前底数

   在递归写法里是：

   ```python
   if exp % 2 == 1:
       ans *= x
   ```

   在迭代写法里是：

   ```python
   if n & 1:
       ans *= base
   ```

4. 不要用 Python 内置 `pow` 或 `x ** n`

   这题考的是自己实现快速幂。

5. 注意 `n = -2^31`

   Python 的整数不会溢出，所以：

   ```python
   n = -n
   ```

   可以直接把 `-2147483648` 变成 `2147483648`。

   但如果是在 Java / C++ 里，`int` 的正数上限是 `2147483647`，直接对 `-2147483648` 取相反数会溢出。那时应该先把 `n` 转成更大的整数类型，比如 `long` / `long long`。

6. `0` 的负指数

   数学上 `0^-1` 没有定义。LeetCode 这题的有效测试不会要求你计算这种情况，所以代码里按快速幂主逻辑处理即可。

### 复杂度

- 时间复杂度：`O(log |n|)`
- 空间复杂度：`O(1)`

### 面试里怎么讲

可以这样说：

```text
暴力做法是乘 |n| 次，但指数最大可能到 2^31 级别，所以会超时。

幂运算可以利用平方加速：
x^10 不需要乘 10 次，可以看成 x^8 * x^2。

也就是说，我把指数拆成二进制。每一轮看当前最低位：
- 如果最低位是 1，就把当前 base 乘进答案
- 然后 base 自己平方，代表下一位的权重
- 指数右移一位

负指数先转成倒数：x^-n = (1/x)^n。

这样每一轮指数都减半，所以时间复杂度是 O(log |n|)，空间是 O(1)。
```

---

## 总结

| 方法 | 思路 | 时间复杂度 | 空间复杂度 | 评价 |
| --- | --- | --- | --- | --- |
| 方法一 | 暴力连乘 | `O(|n|)` | `O(1)` | 最直观，但会超时 |
| 方法二 | 递归快速幂 | `O(log |n|)` | `O(log |n|)` | 推导清楚，适合理解 |
| 方法三 | 迭代快速幂 | `O(log |n|)` | `O(1)` | 面试主推 |

最适合面试的是 **方法三：迭代快速幂**。

它的优势是：

- 复杂度最优：`O(log |n|)`
- 不使用递归栈：空间 `O(1)`
- 代码短，变量少，边界集中
- 对负指数、`n == 0` 都能自然处理

真正要记住的不是代码形状，而是这个核心：

```text
指数可以按二进制拆开；
base 每轮平方，指数每轮右移；
当前位是 1，才把 base 乘进答案。
```
