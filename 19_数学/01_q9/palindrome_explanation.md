# 深入理解：回文整数（Palindrome Number）算法

回文数是指正序和倒序读都一样的整数。理解这个算法最好的方式是**循序渐进**，从最直观的想法到最高效的实现。

---

## 阶段一：最直观的想法 —— 字符串转换

如果我们不限制方法，最简单的做法就是把整数转换成字符串，然后利用字符串的切片或反转来判断。

```python
def isPalindrome(x: int) -> bool:
    s = str(x)
    return s == s[::-1]
```

**缺点：**
- 需要额外的内存空间来存储字符串。
- 在很多算法面试中，面试官会明确要求：**“不能将整数转换为字符串”**。

---

## 阶段二：数学方法 —— 反转整个整数

既然不能用字符串，我们可以用数学逻辑反转这个整数。
公式如下：
1. `digit = x % 10` (获取最后一位)
2. `reversed_x = reversed_x * 10 + digit` (拼接到反转结果中)
3. `x = x // 10` (去掉最后一位)

```python
def isPalindrome(x: int) -> bool:
    if x < 0: return False # 负数一定不是回文
    original = x
    reverted = 0
    while x > 0:
        reverted = reverted * 10 + x % 10
        x //= 10
    return original == reverted
```

**潜在问题：**
- **数值溢出**：在 32 位环境（如 C++, Java）中，如果原数很大但反转后超出了 `2^31 - 1`，程序会报错。虽然 Python 会自动处理大整数，但在算法设计上这是一种不够严谨的做法。

---

## 阶段三：终极优化 —— 只反转“一半”

为了解决溢出问题并提高效率，我们可以只反转整数的**后半部分**。

### 1. 核心逻辑
当反转后的数字 `reverted` 大于或等于剩下的数字 `x` 时，说明我们已经到达了数字的中点。

### 2. 特殊情况判断
在开始循环前，我们可以排除一些明显的非法案例：
- **负数**：`-121` 倒过来是 `121-`，不是回文。
- **以 0 结尾（非 0 本身）**：如 `10`, `100`。回文要求第一位也是 0，但整数不会以 0 开头（除了 0 ）。

### 3. 动态模拟 (以 1221 为例)
| 步骤 | x (剩余部分) | revertedNumber (反转部分) | 说明 |
| :--- | :--- | :--- | :--- |
| 初始 | 1221 | 0 | |
| 循环 1 | 122 | 1 | (取最后一位 1) |
| 循环 2 | 12 | 12 | (取倒数第二位 2，此时 x == reverted) |
| **结束** | **12** | **12** | **x == reverted，返回 True** |

### 4. 奇数长度处理 (以 12321 为例)
| 步骤 | x | revertedNumber |
| :--- | :--- | :--- |
| 初始 | 12321 | 0 |
| 循环 1 | 1232 | 1 |
| 循环 2 | 123 | 12 |
| 循环 3 | 12 | 123 |
| **结束** | **12** | **123** |
此时 `x < reverted` 循环停止。对于奇数回文，中间那位（3）在 `reverted` 的个位上。我们可以通过 `reverted // 10` 去掉中间位，再进行比较：`12 == 123 // 10` 结果为 `True`。

---

## 最终代码实现

```python
class Solution:
    def isPalindrome(self, x: int) -> bool:
        # 边界处理：负数和以 0 结尾的非零数
        if x < 0 or (x % 10 == 0 and x != 0):
            return False

        revertedNumber = 0
        # 只处理数字的一半
        while x > revertedNumber:
            revertedNumber = revertedNumber * 10 + x % 10
            x //= 10

        # 情况 1 (偶数长度): x == revertedNumber
        # 情况 2 (奇数长度): x == revertedNumber // 10
        return x == revertedNumber or x == revertedNumber // 10
```

### 总结
这个算法的精妙之处在于：
1. **零内存消耗**：不需要额外空间存字符串。
2. **防溢出**：只处理一半，由于反转后的数不会超过原数的范围，安全可靠。
3. **数学之美**：利用 `%` 和 `//` 优雅地完成了空间和时间的双重优化。
