# LeetCode 171. Excel 表列序号（Excel Sheet Column Number）解析

## 题目描述

给你一个字符串 `columnTitle`，它表示 Excel 表格中的列标题。返回该列标题对应的列序号。

字母和列号的对应关系：

```text
A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28
...
AZ -> 52
BA -> 53
...
ZY -> 701
```

例子：

```text
"A"   -> 1
"AB"  -> 28
"ZY"  -> 701
"FXSHRXW" -> 2147483647
```

约束：

- `1 <= columnTitle.length <= 7`
- `columnTitle` 仅由大写英文字母组成
- 答案保证在 32 位整数范围内

---

## 先理解题意

这是一个**把字母串解释成数字**的问题。

它的形态非常像“26 进制”，但有一个关键区别：

```text
普通 10 进制：每一位是 0~9，共 10 个数字
普通 26 进制：每一位是 0~25，共 26 个数字
Excel 列号 ：每一位是 1~26，没有“0”
```

也就是说，Excel 列号是一种**没有 0 的 26 进制**（也叫 bijective base-26）。

但是！具体到“怎么把字符串转成数字”的算法上，**它和普通 26 进制完全一样**。
原因是：A 对应的不是 0，而是 1。我们直接把每个字母映射成 1~26，再按照 26 进制的公式累加，结果就是正确的列号。

举个最小的例子：

```text
"AB"
A 看作 1，B 看作 2
当成 26 进制：1 * 26 + 2 = 28 ✓
```

再来一个：

```text
"ZY"
Z = 26, Y = 25
26 * 26 + 25 = 676 + 25 = 701 ✓
```

所以只要解决一件事：

```text
把字符串按 26 进制还原成整数，每位的值 = ord(ch) - ord('A') + 1
```

---

## 方法一：从右往左累加，显式计算 26 的幂

### 思路

按位权展开公式，最右一位是 `26^0`，往左每多一位 `26` 的次方加一。

例如 `"ZY"`：

```text
Z Y
位权：26^1 26^0
=  26 * 26^1 + 25 * 26^0
=  676 + 25
=  701
```

直接把这个公式写出来即可：

```text
从右往左遍历，每一位的值 * 当前 26 的幂，累加到答案
每处理一位，幂 *= 26
```

### 代码

```python
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        ans = 0
        power = 1

        for ch in reversed(columnTitle):
            digit = ord(ch) - ord("A") + 1
            ans += digit * power
            power *= 26

        return ans
```

### 评价

- 思路最朴素：完全照着“26 进制位权”的定义来写
- 代码也不复杂
- 缺点是要额外维护一个 `power` 变量，写起来比方法二多一行

复杂度：

- 时间：`O(n)`，`n` 是字符串长度
- 空间：`O(1)`

## 方法二：从左到右秦九韶式累乘（面试主推）

### 核心思路

方法一是“从最低位累加”，那能不能反过来，从**最高位**开始一位一位接进来？

回顾普通十进制是怎么读数的：

```text
读 "123"
result = 0
读到 '1'：result = 0 * 10 + 1 = 1
读到 '2'：result = 1 * 10 + 2 = 12
读到 '3'：result = 12 * 10 + 3 = 123
```

每读一个新字符，把已有的结果**乘以进制**再加上新位的数字，这就是秦九韶 / Horner 法。

Q171 完全一样，只是把 10 换成 26、把 `int(ch)` 换成 `ord(ch) - ord('A') + 1`：

```text
result = 0
对每个字符 ch：
    result = result * 26 + (ord(ch) - ord('A') + 1)
```

### 面试代码

```python
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        ans = 0
        for ch in columnTitle:
            ans = ans * 26 + (ord(ch) - ord("A") + 1)
        return ans
```

### 用 `"ZY"` 走一遍

```text
初始 ans = 0

读 'Z'：digit = 26
    ans = 0 * 26 + 26 = 26

读 'Y'：digit = 25
    ans = 26 * 26 + 25 = 676 + 25 = 701
```

最终答案 701 ✓。

再用 `"AB"` 验证一次：

```text
初始 ans = 0

读 'A'：digit = 1
    ans = 0 * 26 + 1 = 1

读 'B'：digit = 2
    ans = 1 * 26 + 2 = 28
```

✓。

### 关键点

```python
ans = ans * 26 + (ord(ch) - ord("A") + 1)
```

要讲清楚两件事：

1. **为什么要先 `* 26`**
   - 已经读过的字符代表的是“更高位”
   - 多读一个字符，相当于已有的所有位都要整体往左移一格
   - 在 26 进制里，左移一格 = 乘 26

2. **为什么 `+1`，不是 `+0`**
   - Excel 列号里 A 代表 1 而不是 0
   - 所以 `ord(ch) - ord('A')` 得到的是 0~25，要再 `+1` 才能得到 1~26
   - 这是和普通 26 进制唯一的差别

### 边界

- 字符串最长 7 位，远在 64 位整数范围内，Python 还不限大小，不需要担心溢出
- 题目保证只有大写字母，不用做合法性校验

### 复杂度

- 时间：`O(n)`
- 空间：`O(1)`

## 哪个方法最适合面试

最适合面试的是 **方法二：从左到右秦九韶式累乘**。

原因：

- 代码最短，循环里只有一行核心表达式
- 不需要维护 `power` 变量，思路统一为“读一位、扩一位、加进来”
- 解释起来非常自然：和读十进制数字 `"123"` 的过程完全一样，只是把 10 换成 26
- 把 Excel 列号理解成“没有 0 的 26 进制”，能展示出对题目的洞察

面试里可以这样说：

```text
Excel 列号本质上就是 26 进制，只是 A 代表 1 而不是 0。
所以我把每个字符映射成 1 到 26，
然后用秦九韶（Horner）方式从左到右扫一遍：
每读一个字符，先把当前结果乘 26 表示已有位整体左移一格，
再加上当前字符对应的 1 到 26。
时间 O(n)，空间 O(1)。
```

---

## 总结

- 方法一：从右往左累加，显式计算 26 的幂
  - 按位权定义照搬
  - 多一个 `power` 变量

- 方法二：从左到右秦九韶式累乘（面试主推）
  - 代码最简洁
  - 和读十进制数字的过程完全类比
  - 一句话点透核心：Excel 列号 = 没有 0 的 26 进制
