# LeetCode 13. 罗马数字转整数（Roman to Integer）解析

## 题目描述

给你一个罗马数字字符串 `s`，把它转换成整数。

罗马数字的基本符号：

```text
I -> 1
V -> 5
X -> 10
L -> 50
C -> 100
D -> 500
M -> 1000
```

通常是大的数在左边，小的数在右边，直接相加。

例如：

```text
VIII = 5 + 1 + 1 + 1 = 8
```

但有 6 个特殊减法组合：

```text
IV = 4
IX = 9
XL = 40
XC = 90
CD = 400
CM = 900
```

例子：

```text
III -> 3
LVIII -> 58
MCMXCIV -> 1994
```

---

## 先理解题意

罗马数字大多数时候是直接相加。

比如：

```text
LVIII
= L + V + I + I + I
= 50 + 5 + 1 + 1 + 1
= 58
```

真正需要处理的是减法情况。

减法情况的共同特点是：

```text
当前字符的值 < 右边字符的值
```

比如：

```text
IV
I = 1
V = 5
I < V，所以 I 要减掉
IV = -1 + 5 = 4
```

所以核心规则就是：

```text
如果当前值小于右边值，就减当前值；否则加当前值。
```

---

## 方法一：显式处理特殊组合

### 思路

从左到右扫描字符串。

每次先看当前位置和下一个位置能不能组成特殊组合：

```text
IV, IX, XL, XC, CD, CM
```

如果能，就一次处理两个字符。

否则只处理当前一个字符。

### 代码

```python
class Solution:
    def romanToInt(self, s: str) -> int:
        single = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}
        pair = {"IV": 4, "IX": 9, "XL": 40, "XC": 90, "CD": 400, "CM": 900}

        ans = 0
        i = 0

        while i < len(s):
            if i + 1 < len(s) and s[i:i + 2] in pair:
                ans += pair[s[i:i + 2]]
                i += 2
            else:
                ans += single[s[i]]
                i += 1

        return ans
```

### 评价

这个方法好理解，但需要记住 6 个特殊组合。

更好的面试写法是方法二：不硬编码组合，只用“左小右大则减”的规律。

---

## 方法二：正序遍历，和右边一位比较

### 核心思路

从左到右遍历每个字符。

对当前位置 `i`：

- 如果 `s[i]` 的值小于 `s[i + 1]` 的值，说明它参与减法，减掉当前值
- 否则加上当前值

### 面试代码

```python
class Solution:
    def romanToInt(self, s: str) -> int:
        value = {
            "I": 1,
            "V": 5,
            "X": 10,
            "L": 50,
            "C": 100,
            "D": 500,
            "M": 1000,
        }

        ans = 0

        for i, ch in enumerate(s):
            if i + 1 < len(s) and value[ch] < value[s[i + 1]]:
                ans -= value[ch]
            else:
                ans += value[ch]

        return ans
```

### 用 `MCMXCIV` 走一遍

```text
M C M X C I V
```

逐位看：

```text
M = 1000，右边 C = 100，M > C，加 1000
C = 100，右边 M = 1000，C < M，减 100
M = 1000，右边 X = 10，M > X，加 1000
X = 10，右边 C = 100，X < C，减 10
C = 100，右边 I = 1，C > I，加 100
I = 1，右边 V = 5，I < V，减 1
V = 5，右边没有字符，加 5
```

总和：

```text
1000 - 100 + 1000 - 10 + 100 - 1 + 5 = 1994
```

### 代码关键点

```python
i + 1 < len(s)
```

这是防止访问右边字符时越界。

最后一个字符右边没有字符，一定直接加。

```python
value[ch] < value[s[i + 1]]
```

这是减法判断。

只要当前值小于右边值，当前值就应该减掉。

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，映射表固定 7 个字符

## 方法三：倒序遍历

### 思路

也可以从右往左遍历。

维护一个 `prev`，表示右边刚处理过的值。

对当前字符：

- 如果当前值小于右边值 `prev`，就减
- 否则就加，并更新 `prev`

### 代码

```python
class Solution:
    def romanToInt(self, s: str) -> int:
        value = {
            "I": 1,
            "V": 5,
            "X": 10,
            "L": 50,
            "C": 100,
            "D": 500,
            "M": 1000,
        }

        ans = 0
        prev = 0

        for ch in reversed(s):
            cur = value[ch]
            if cur < prev:
                ans -= cur
            else:
                ans += cur
                prev = cur

        return ans
```

### 评价

这个写法不用判断 `i + 1 < len(s)`，但对新手不如方法二直观。

面试中优先写方法二即可。

---

## 哪个方法最适合面试

最适合面试的是 **方法二：正序遍历，和右边一位比较**。

原因：

- 不需要硬背 6 个特殊组合
- 规律简单：左小右大则减，否则加
- 代码短，边界只有 `i + 1 < len(s)`
- 和题意解释最直接

面试里可以这样说：

```text
罗马数字通常是从左到右相加。
唯一的减法情况是当前字符比右边字符小，比如 IV、IX。
所以我遍历每个字符，如果当前值小于右边值，就减当前值；否则加当前值。
最后一个字符没有右边字符，直接加。
```

---

## 总结

- 方法一：显式处理特殊组合
  - 好理解
  - 但要列出 6 个组合

- 方法二：正序遍历，和右边一位比较
  - 面试主推
  - 代码短，逻辑自然

- 方法三：倒序遍历
  - 也很简洁
  - 但解释上不如方法二直观
