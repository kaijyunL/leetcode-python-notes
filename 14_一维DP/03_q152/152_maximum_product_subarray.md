# 152. Maximum Product Subarray

## 题目理解

给你一个整数数组 `nums`，请你找出一个**乘积最大**的非空连续子数组，并返回这个乘积。

例如：

- `nums = [2,3,-2,4]`，答案是 `6`
  - 最大乘积子数组是 `[2,3]`
- `nums = [-2,0,-1]`，答案是 `0`
  - 不能选 `[-2,-1]`，因为它们不连续
- `nums = [-2,3,-4]`，答案是 `24`
  - 最大乘积子数组是 `[-2,3,-4]`

这道题和第 53 题“最大子数组和”很像，但难点明显更高。

因为“和”只会越来越大或越来越小，而“乘积”会受到两件事影响：

1. **负数会翻转大小关系**
2. **0 会把连续乘积直接截断**

这道题真正的核心是：

> 以 `nums[i]` 结尾的最大乘积，不一定只和前一个“最大值”有关，它还可能来自前一个“最小值”。

---

## 为什么这题我只讲 3 种方法

这题如果硬拆成 `O(n^3)` 三重循环，再写一个 `O(n^2)` 暴力优化，其实教学价值不高。

因为对乘积来说，只要固定起点、向右扩终点，乘积就可以直接滚动更新。

所以这里保留 3 种真正有价值的方法：

1. **暴力枚举 + 滚动乘积**
2. **动态规划数组版**
3. **状态压缩最优解**

---

## 方法一：暴力枚举 + 滚动乘积

### 思路

最直接的想法仍然是枚举所有连续子数组。

不过这里不需要像求和那样再额外开一层循环重算区间乘积。

如果固定起点 `i`，让终点 `j` 从 `i` 一直向右扩：

- 初始乘积是 `1`
- 每向右扩一格，就把当前数乘进去
- 每次都尝试更新答案

这样就能用两层循环把所有连续子数组试一遍。

### 代码

```python
class Solution:
    def maxProduct(self, nums: list[int]) -> int:
        n = len(nums)
        best = nums[0]

        for i in range(n):
            prod = 1
            for j in range(i, n):
                prod *= nums[j]
                best = max(best, prod)

        return best
```

### 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(1)`

### 评价

这个方法的优点是：

- 非常直观
- 容易验证题意
- 能帮助你建立“连续子数组”的基本感觉

缺点也很明显：

- 还是把所有起点和终点都枚举了一遍
- 数据规模一大就不够快

所以它适合作为起点思路，不适合作为最终答案。

## 方法二：动态规划

### 思路

这题最关键的难点就在于：

```text
负数 × 负数 = 正数
```

这意味着：

- 前一个很大的正数，乘上负数，可能变成很小的负数
- 前一个很小的负数，乘上负数，反而可能变成很大的正数

所以和第 53 题不一样，这里不能只维护“最大值”，还必须同时维护“最小值”。

定义：

```text
max_dp[i] = 以 nums[i] 结尾的最大乘积
min_dp[i] = 以 nums[i] 结尾的最小乘积
```

为什么要有 `min_dp[i]`？

因为它可能在后面遇到负数时，突然翻成最大值。

转移时，当前位置 `nums[i]` 有三种选择：

1. 单独从自己开始
2. 接在前一个最大乘积后面
3. 接在前一个最小乘积后面

所以：

```text
max_dp[i] = max(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
min_dp[i] = min(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
```

最后答案是所有 `max_dp[i]` 里的最大值。

### 代码

```python
class Solution:
    def maxProduct(self, nums: list[int]) -> int:
        n = len(nums)
        max_dp = [0] * n
        min_dp = [0] * n

        max_dp[0] = nums[0]
        min_dp[0] = nums[0]
        best = nums[0]

        for i in range(1, n):
            num = nums[i]
            max_dp[i] = max(num, max_dp[i - 1] * num, min_dp[i - 1] * num)
            min_dp[i] = min(num, max_dp[i - 1] * num, min_dp[i - 1] * num)
            best = max(best, max_dp[i])

        return best
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 评价

这是这道题最标准的 DP 写法。

优点：

- 状态定义很清楚
- 能把“为什么要同时维护最大值和最小值”讲透
- 非常适合建立正确理解

缺点：

- 额外用了两个数组
- 实际上每一步只依赖前一项，还能继续压缩

## 方法三：状态压缩（最优解）

### 思路

观察方法二会发现：

- `max_dp[i]` 只依赖 `max_dp[i-1]` 和 `min_dp[i-1]`
- `min_dp[i]` 也只依赖 `max_dp[i-1]` 和 `min_dp[i-1]`

所以整张表没必要保留。

我们只需要三个变量：

- `curr_max`：当前“以当前位置结尾”的最大乘积
- `curr_min`：当前“以当前位置结尾”的最小乘积
- `best`：遍历到当前为止的全局最大乘积

遍历到当前数 `num` 时：

```text
新的最大值 = max(num, 旧最大值 × num, 旧最小值 × num)
新的最小值 = min(num, 旧最大值 × num, 旧最小值 × num)
```

注意这里一定要先保存旧值，再更新新值。

### 代码

```python
class Solution:
    def maxProduct(self, nums: list[int]) -> int:
        curr_max = nums[0]
        curr_min = nums[0]
        best = nums[0]

        for num in nums[1:]:
            prev_max = curr_max
            prev_min = curr_min
            curr_max = max(num, prev_max * num, prev_min * num)
            curr_min = min(num, prev_max * num, prev_min * num)
            best = max(best, curr_max)

        return best
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 评价

这是这道题最常见、最推荐的最优写法。

优点：

- 只遍历一次
- 空间是常数级
- 代码不长
- 很适合面试手写

## 哪个方法最适合面试

### 结论

**最适合面试的是：方法三，状态压缩版动态规划。**

但面试里最好的表达方式不是一上来就直接背代码，而是：

> 先讲清楚为什么要同时维护最大值和最小值，再自然压缩成常数空间。

---

## 最适合面试的方法：详细讲解

### 第一步：先明确这题为什么比第 53 题难

第 53 题是“最大和”，只需要关心前面的和是否有贡献。

但第 152 题是“最大乘积”，乘积有符号翻转问题：

- 一个大的正数乘上负数，可能变成很小的负数
- 一个很小的负数乘上负数，可能变成很大的正数

所以：

```text
当前最大乘积，不只可能来自前一个最大乘积，也可能来自前一个最小乘积
```

这是整道题最核心的区别。

---

### 第二步：定义状态

令：

```text
max_dp[i] = 以 nums[i] 结尾的最大乘积
min_dp[i] = 以 nums[i] 结尾的最小乘积
```

这里“最小乘积”不是多余状态，反而非常关键。

因为今天看起来最差的那个负数乘积，明天遇到另一个负数时，可能一下变成最大值。

---

### 第三步：为什么必须同时维护最大和最小

看这个例子：

```text
nums = [-2, 3, -4]
```

我们来一步一步看：

初始：

```text
curr_max = -2
curr_min = -2
best = -2
```

走到 `3`：

```text
curr_max = max(3, -2×3, -2×3) = 3
curr_min = min(3, -2×3, -2×3) = -6
best = 3
```

走到 `-4`：

```text
curr_max = max(-4, 3×-4, -6×-4) = 24
curr_min = min(-4, 3×-4, -6×-4) = -12
best = 24
```

关键就在这里：

```text
24 不是来自前一个最大值 3，而是来自前一个最小值 -6
```

所以如果你只维护一个“最大乘积”，这题就会做错。

---

### 第四步：为什么 0 不需要单独特殊处理

很多人会担心 `0`。

其实这套转移天然就能处理：

如果 `num = 0`，那么：

```text
max(num, prev_max * 0, prev_min * 0) = 0
min(num, prev_max * 0, prev_min * 0) = 0
```

也就是说：

- 连续乘积会在这里被截断
- 下一段子数组会自然从后面重新开始

所以这题不需要额外手动写“遇到 0 就重置”的特殊逻辑。

---

### 第五步：为什么可以状态压缩

因为当前状态只依赖前一个位置：

```text
max_dp[i] 只依赖 max_dp[i-1] 和 min_dp[i-1]
min_dp[i] 只依赖 max_dp[i-1] 和 min_dp[i-1]
```

所以：

- 更早的位置都不需要保留
- 只保留前一对状态就够了

于是数组版 DP 可以压缩成三个变量：

- `curr_max`
- `curr_min`
- `best`

这就是最优解。

---

### 面试时推荐怎么讲

你可以按这个顺序讲：

#### 1. 先说暴力思路

- 枚举所有连续子数组
- 用滚动乘积把复杂度做到 `O(n^2)`
- 但还不够好

#### 2. 再指出这题的核心难点

- 负数会翻转大小关系
- 所以不能只维护最大值，还必须维护最小值

#### 3. 定义状态

```text
max_dp[i] = 以 i 结尾的最大乘积
min_dp[i] = 以 i 结尾的最小乘积
```

#### 4. 写出转移

```text
max_dp[i] = max(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
min_dp[i] = min(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
```

#### 5. 再补充空间优化

- 因为只依赖前一个位置
- 所以可以压缩成常数空间

这样的表达会很完整，面试官通常会觉得你是真正理解了这题的本质。

---

### 面试最推荐代码

```python

            best = max(best, curr_max)

```

---

## 总结

### 递进关系

1. **暴力枚举 + 滚动乘积**
   - 直观
   - 但还是 `O(n^2)`

2. **动态规划**
   - 同时维护“以当前位置结尾的最大乘积”和最小乘积
   - 真正抓住了这题的核心

3. **状态压缩**
   - 保留核心状态
   - 得到 `O(n)` 时间、`O(1)` 空间的最优解

### 一句话记忆

> 乘积题和求和题最大的不同在于：负数会翻转大小关系，所以要同时维护最大乘积和最小乘积。
