# 213. House Robber II

## 题目理解

这题是第 198 题 `House Robber` 的环形版本。

第 198 题里，房子排成一条直线：

```text
不能偷相邻两间房子
```

第 213 题里，房子排成一个环：

```text
第 0 间房子 和 最后一间房子 也相邻
```

所以多出来的限制是：

```text
第 0 间 和 最后一间 不能同时偷
```

例如：

```text
nums = [2, 3, 2]
```

不能偷第 0 间和第 2 间，因为它们在环里相邻。答案是偷中间的 `3`。

---

## 核心拆解

环形问题看起来比线性问题复杂，但这题的关键是：

> 第 0 间和最后一间不能同时偷，所以最优答案一定落在两种情况之一。

两种情况：

```text
情况 1：不偷最后一间，只考虑 nums[0 : n - 1]
情况 2：不偷第一间，只考虑 nums[1 : n]
```

这两段都变回了第 198 题的线性打家劫舍问题。

所以：

```text
answer = max(
    rob_line(nums[0 : n - 1]),
    rob_line(nums[1 : n])
)
```

注意 `n == 1` 时没有“环”的问题，直接返回 `nums[0]`。

---

## 方法一：暴力递归

### 思路

先不考虑优化，只解决线性区间 `[left, right]`。

站在第 `i` 间房子，有两个选择：

1. 不偷第 `i` 间，去看 `i + 1`
2. 偷第 `i` 间，下一间不能偷，去看 `i + 2`

递归定义：

```text
dfs(i) = 从 i 到 right 这段房子里，最多能偷多少钱
```

转移：

```text
dfs(i) = max(
    dfs(i + 1),
    nums[i] + dfs(i + 2)
)
```

环形问题仍然拆成两段：

```text
max(dfs(0 到 n-2), dfs(1 到 n-1))
```

### 代码

见 [solution_1_brute_force.py](./solution_1_brute_force.py)

### 复杂度

- 时间复杂度：`O(2^n)`
- 空间复杂度：`O(n)`，递归栈深度

### 评价

这个方法适合理解问题，不适合作为面试最终答案。

它的问题是重复计算太多。比如 `dfs(i + 2)` 会从多条路径反复进入。

## 方法二：普通 DP

### 思路

暴力递归的选择关系已经很清楚：

```text
偷当前：nums[i] + 前前一个位置的最优值
不偷当前：前一个位置的最优值
```

在线性数组 `arr` 上定义：

```text
dp[i] = 偷到 arr[i] 这一间时，最多能偷多少钱
```

转移：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + arr[i])
```

边界：

```text
dp[0] = arr[0]
dp[1] = max(arr[0], arr[1])
```

环形问题还是拆成两段：

```text
rob_line(nums[:-1])
rob_line(nums[1:])
```

取最大值。

### 代码

见 [solution_2_dp.py](./solution_2_dp.py)

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 评价

这个方法已经可以通过面试，但不是最推荐的最终写法。

它的优点是状态清晰，适合从第 198 题迁移过来；缺点是 `dp` 数组其实只用到了前两个状态，可以继续压缩空间。

## 方法三：状态压缩 DP（最适合面试）

### 为什么这个最适合面试

这是本题最推荐的面试写法。

原因：

1. 时间复杂度已经最优：必须至少看一遍数组，所以 `O(n)` 无法再降
2. 空间复杂度是 `O(1)`
3. 代码短，但不是投机写法，能清楚表达“环拆两段 + 线性 DP”
4. 和第 198 题形成稳定模板，面试里容易解释

### 线性子问题怎么压缩

普通 DP 里：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

计算 `dp[i]` 只需要：

```text
dp[i - 1]
dp[i - 2]
```

所以用两个变量：

```text
prev2 = dp[i - 2]
prev1 = dp[i - 1]
```

遍历当前房子 `money` 时：

```text
curr = max(prev1, prev2 + money)
```

含义是：

- `prev1`：不偷当前房子，收益就是前一间的最优值
- `prev2 + money`：偷当前房子，就不能偷前一间，只能接上前前一间的最优值

更新：

```text
prev2 = prev1
prev1 = curr
```

### 为什么拆两段不会漏答案

因为第 0 间和最后一间不能同时偷。

任意合法方案一定满足下面至少一个条件：

1. 不偷最后一间
2. 不偷第一间

如果一个方案第一间和最后一间都不偷，它会同时出现在两种情况里；这不影响答案，因为我们只是取最大值。

所以两段覆盖了全部合法解：

```text
nums[0 : n - 1]  覆盖所有“不偷最后一间”的方案
nums[1 : n]      覆盖所有“不偷第一间”的方案
```

### 代码

见 [solution_3_optimized_dp.py](./solution_3_optimized_dp.py)

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 面试表达模板

可以这样说：

> 这题比 House Robber I 多了首尾相邻的限制。因为首尾不能同时选，所以最优解一定在两种线性情况里：不选最后一间，或者不选第一间。对每个线性区间，用 House Robber I 的状态压缩 DP：当前最优值等于“不偷当前”和“偷当前”两者取最大。最后返回两段结果的最大值。

---

## 易错点

1. `n == 1` 必须单独处理，否则拆成两段会变成空区间
2. 拆分时是 `nums[0:n-1]` 和 `nums[1:n]`
3. 状态压缩更新顺序不能写反，要先算 `curr`，再移动 `prev2` 和 `prev1`
4. 本题不是简单地把第 198 题跑一遍，因为首尾相邻会让 `[2,3,2]` 这种例子出错
