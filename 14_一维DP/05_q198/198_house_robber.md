# 198. House Robber

## 题目理解

你是一个小偷，准备偷一排房子。

每间房子里都有一定金额，但**相邻的两间房子不能在同一晚偷**，否则会触发报警。

给你一个数组 `nums`，其中：

- `nums[i]` 表示第 `i` 间房子的钱

请你返回：

> 在不触发报警的前提下，今晚最多能偷到多少钱。

例如：

- `nums = [1,2,3,1]`，答案是 `4`
  - 偷第 1 间和第 3 间：`1 + 3 = 4`
- `nums = [2,7,9,3,1]`，答案是 `12`
  - 偷第 1、3、5 间：`2 + 9 + 1 = 12`

这道题最核心的矛盾是：

```text
偷当前房子，就不能偷前一间
不偷当前房子，就可以看前一间的最优结果
```

所以它本质上是一个：

> 每个位置都要在“偷”与“不偷”之间做选择的动态规划问题。

---

## 为什么这题我写 4 种方法

这题非常适合完整走一遍这条思路链：

```text
暴力递归 -> 记忆化递归 -> DP -> 状态压缩
```

因为它的递推关系特别清楚，中间每一步都有独立教学价值。

所以这题保留 4 种方法是合理的，不是为了凑数。

---

## 方法一：暴力递归

### 思路

对于第 `i` 间房子，有两个选择：

1. **偷第 `i` 间**
   - 那前一间就不能偷
   - 剩下问题变成：去求前 `i-2` 间房子的最大收益
2. **不偷第 `i` 间**
   - 那就看前 `i-1` 间房子的最大收益

所以如果定义：

```text
f(i) = 偷前 i+1 间房子（下标 0 到 i）时能得到的最大金额
```

那么有：

```text
f(i) = max(f(i - 1), f(i - 2) + nums[i])
```

边界：

```text
f(0) = nums[0]
f(1) = max(nums[0], nums[1])
```

### 代码

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        def dfs(i: int) -> int:
            if i == 0:
                return nums[0]
            if i == 1:
                return max(nums[0], nums[1])
            return max(dfs(i - 1), dfs(i - 2) + nums[i])

        n = len(nums)
        if n == 1:
            return nums[0]
        return dfs(n - 1)
```

### 为什么会慢

因为很多状态会被重复计算。

比如为了算 `dfs(4)`，会去算 `dfs(3)` 和 `dfs(2)`；
而算 `dfs(3)` 时又会再次去算 `dfs(2)`。

这就是经典的重复子问题。

### 复杂度

- 时间复杂度：`O(2^n)`
- 空间复杂度：`O(n)`（递归栈）

### 评价

这个方法适合理解状态转移是怎么来的，但不适合作为最终答案。

## 方法二：记忆化递归

### 思路

既然暴力递归慢，是因为同一个状态被反复计算，那就把已经算过的结果存起来。

定义：

```text
memo[i] = 前 i+1 间房子能偷到的最大金额
```

每次递归到 `dfs(i)` 时：

- 如果已经算过，直接返回
- 如果没算过，再递归计算并存下来

### 代码

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]

        memo = {}

        def dfs(i: int) -> int:
            if i == 0:
                return nums[0]
            if i == 1:
                return max(nums[0], nums[1])
            if i in memo:
                return memo[i]
            memo[i] = max(dfs(i - 1), dfs(i - 2) + nums[i])
            return memo[i]

        return dfs(n - 1)
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 评价

这个方法已经很优秀了。

优点：

- 保留了递归思路
- 很直观地消除了重复子问题

缺点：

- 仍然有递归栈
- 仍然用了额外存储

如果面试官允许递归写法，这个答案通常是完全可以接受的。

## 方法三：动态规划

### 思路

既然递推关系已经很明确：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

那我们就可以直接从小到大推表。

定义：

```text
dp[i] = 偷前 i+1 间房子时能得到的最大金额
```

转移时：

- `dp[i - 1]`：不偷当前房子
- `dp[i - 2] + nums[i]`：偷当前房子

取两者最大值。

边界：

```text
dp[0] = nums[0]
dp[1] = max(nums[0], nums[1])
```

### 代码

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]

        dp = [0] * n
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        for i in range(2, n):
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])

        return dp[-1]
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 为什么这就是 DP

因为它满足非常典型的 DP 结构：

1. 当前状态依赖更小状态
2. 存在重复子问题
3. 每个位置都在做最优选择

这是这类“打家劫舍型”题目的标准模型。

### 评价

这是这道题最标准、最稳妥的 DP 写法。

如果你在系统练一维 DP，这一步一定要会。

## 方法四：状态压缩（最优解）

### 思路

观察方法三：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

可以发现，计算 `dp[i]` 时只会用到：

- `dp[i - 1]`
- `dp[i - 2]`

更早的状态都用不到。

所以没必要保留整张 `dp` 表，只需要两个变量：

- `dp_i_1`：表示 `dp[i - 1]`
- `dp_i_2`：表示 `dp[i - 2]`

每次更新：

```text
curr = max(dp_i_1, dp_i_2 + nums[i])
dp_i_2 = dp_i_1
dp_i_1 = curr
```

最后返回 `dp_i_1` 即可。

### 代码

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]

        dp_i_2 = nums[0]
        dp_i_1 = max(nums[0], nums[1])

        for i in range(2, n):
            curr = max(dp_i_1, dp_i_2 + nums[i])
            dp_i_2 = dp_i_1
            dp_i_1 = curr

        return dp_i_1
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 评价

这是这道题最实用、最常见、最推荐面试写的版本。

优点：

- 只遍历一次
- 空间最优
- 代码简洁
- 白板手写压力小

## 哪个方法最适合面试

### 结论

**最适合面试的是：方法四，状态压缩版动态规划。**

但最好的表达方式是：

> 先从“偷或不偷当前房子”的选择推出 DP 转移，再自然优化到状态压缩。

这样会比直接背公式更有说服力。

---

## 最适合面试的方法：详细讲解

### 第一步：先明确每个位置在做什么选择

对于第 `i` 间房子，只有两种情况：

1. **不偷它**
   - 那最大收益就是前 `i-1` 间房子的最优解
2. **偷它**
   - 那前一间不能偷
   - 收益就是前 `i-2` 间房子的最优解加上当前房子的钱

所以：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

这就是整道题的核心。

---

### 第二步：为什么这个转移一定正确

因为相邻房子不能同时偷，所以“偷当前房子”时，前一个位置一定不能选。

而“不偷当前房子”时，就可以直接沿用前一个位置的最优结果。

也就是说：

- 当前房子选不选
- 已经完整覆盖了所有合法情况
- 两种情况互斥且完备

因此取最大值就是最优答案。

---

### 第三步：边界怎么处理

如果只有一间房：

```text
dp[0] = nums[0]
```

如果有两间房：

```text
dp[1] = max(nums[0], nums[1])
```

这两个边界一定要先定清楚，后面的递推才成立。

---

### 第四步：为什么可以状态压缩

因为每一步只依赖前两个状态：

```text
dp[i - 1]
dp[i - 2]
```

所以没有必要存整个数组。

只保留：

- `dp_i_1`
- `dp_i_2`

就足够了。

这是非常典型的一维 DP 状态压缩。

---

### 第五步：用例子走一遍

以：

```text
nums = [2, 7, 9, 3, 1]
```

为例。

初始：

```text
dp_i_2 = 2
dp_i_1 = 7
```

继续：

- 到 `9`：`curr = max(7, 2 + 9) = 11`
- 更新后：`dp_i_2 = 7, dp_i_1 = 11`

- 到 `3`：`curr = max(11, 7 + 3) = 11`
- 更新后：`dp_i_2 = 11, dp_i_1 = 11`

- 到 `1`：`curr = max(11, 11 + 1) = 12`
- 更新后：`dp_i_2 = 11, dp_i_1 = 12`

最后答案就是 `12`。

---

### 面试时推荐怎么讲

你可以这样讲：

#### 1. 明确状态

```text
dp[i] = 偷前 i+1 间房子时能得到的最大金额
```

#### 2. 明确选择

- 不偷当前房子：`dp[i - 1]`
- 偷当前房子：`dp[i - 2] + nums[i]`

#### 3. 写出转移

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

#### 4. 说明边界

```text
dp[0] = nums[0]
dp[1] = max(nums[0], nums[1])
```

#### 5. 再补一句空间优化

- 因为只依赖前两个状态
- 所以可以把数组压缩成两个变量

这套表达会很完整，也很像你是真的现场推出来的。

---

### 面试最推荐代码

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]

        dp_i_2 = nums[0]
        dp_i_1 = max(nums[0], nums[1])

        for i in range(2, n):
            curr = max(dp_i_1, dp_i_2 + nums[i])
            dp_i_2 = dp_i_1
            dp_i_1 = curr

        return dp_i_1
```

---

## 总结

### 递进关系

1. **暴力递归**
   - 最直观
   - 但有大量重复子问题

2. **记忆化递归**
   - 消除重复计算
   - 时间降到 `O(n)`

3. **动态规划**
   - 从底向上推表
   - 是标准写法

4. **状态压缩**
   - 只保留前两个状态
   - 是最优写法，也是面试最推荐写法

### 一句话记忆

> 每间房子只有偷或不偷两种选择，所以当前最优解就是“不偷当前”与“偷当前并跳过前一间”这两种方案的最大值。
