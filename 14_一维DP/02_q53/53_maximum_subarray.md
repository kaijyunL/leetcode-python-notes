# 53. Maximum Subarray

## 题目理解

给你一个整数数组 `nums`，请你找出一个**具有最大和的连续子数组**，返回它的最大和。

例如：

- `nums = [-2,1,-3,4,-1,2,1,-5,4]`，答案是 `6`
  - 最大连续子数组是 `[4,-1,2,1]`
  - 和为 `6`
- `nums = [1]`，答案是 `1`
- `nums = [5,4,-1,7,8]`，答案是 `23`

这道题最关键的点有两个：

1. **必须是连续子数组**
2. **要求的是最大和，不是子数组本身**

很多人一开始会想“是不是把所有正数加起来就行”，但这不对，因为题目要求的是**连续**。

这道题真正的核心是：

> 当我们考虑“以当前位置结尾”的最大子数组和时，它和前一个位置之间有什么关系？

---

## 方法一：暴力枚举所有子数组

### 思路

最直接的办法是：

- 枚举所有起点 `i`
- 枚举所有终点 `j`
- 对每个区间 `nums[i:j+1]` 再求和
- 取最大值

这相当于把所有连续子数组都试一遍。

### 代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        n = len(nums)
        best = nums[0]

        for i in range(n):
            for j in range(i, n):
                total = 0
                for k in range(i, j + 1):
                    total += nums[k]
                best = max(best, total)

        return best
```

### 复杂度

- 时间复杂度：`O(n^3)`
- 空间复杂度：`O(1)`

### 评价

这个方法最好理解，因为它完全不需要技巧。

但问题也很明显：

- 子数组个数本来就很多
- 每个子数组还要重新求和
- 重复计算特别严重

所以它只适合作为最初思路，不适合作为最终答案。

---

## 方法二：枚举起点 + 滚动累加

### 思路

方法一慢的原因之一是：

```text
每次换一个终点，都重新把整个子数组再加一遍
```

其实没必要。

如果我们固定起点 `i`，然后让终点从 `i` 一直往右扩：

- 当终点是 `i` 时，子数组和是 `nums[i]`
- 当终点变成 `i+1` 时，只需要在前面的基础上加上 `nums[i+1]`
- 当终点变成 `i+2` 时，再继续加上 `nums[i+2]`

这样就能把三重循环优化成两重循环。

### 代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        n = len(nums)
        best = nums[0]

        for i in range(n):
            total = 0
            for j in range(i, n):
                total += nums[j]
                best = max(best, total)

        return best
```

### 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(1)`

### 评价

这是一个很自然的优化。

优点：

- 仍然容易理解
- 比最原始暴力法少了很多重复求和

缺点：

- 本质上还是在枚举所有起点和终点
- 数据规模大时仍然不够快

不过它是一个很好的中间台阶，能帮助你从“纯暴力”过渡到“状态思考”。

## 方法三：动态规划

### 思路

这道题最关键的突破口是：

不要直接想“所有子数组里谁最大”，而是想：

```text
以 nums[i] 结尾的最大子数组和是多少？
```

定义：

```text
dp[i] = 以 nums[i] 结尾的最大子数组和
```

为什么这样定义有用？

因为任何一个“以 `i` 结尾”的连续子数组，只有两种情况：

1. **把 `nums[i]` 接在前面的子数组后面**
2. **从 `nums[i]` 自己重新开始**

所以转移方程就是：

```text
dp[i] = max(dp[i - 1] + nums[i], nums[i])
```

意思是：

- 如果前面的和 `dp[i-1]` 是有价值的，那就接上当前数
- 如果前面的和会拖后腿，那就从当前数重新开始

最后答案不是 `dp[n-1]`，而是：

```text
max(dp[0], dp[1], ..., dp[n-1])
```

因为题目要的是“整个数组里最大的连续子数组和”，不要求它一定以最后一个位置结尾。

### 代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        n = len(nums)
        dp = [0] * n
        dp[0] = nums[0]
        best = dp[0]

        for i in range(1, n):
            dp[i] = max(dp[i - 1] + nums[i], nums[i])
            best = max(best, dp[i])

        return best
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 为什么这题特别适合练 DP

因为它非常经典地体现了 DP 的两个点：

1. **状态定义很重要**
   - 如果你直接定义“前 i 个数里的最大和”，会不太好转移
   - 但定义成“以 i 结尾的最大和”，转移会非常自然

2. **每一步只依赖前一步**
   - `dp[i]` 只依赖 `dp[i-1]`
   - 这为后面的状态压缩做好了铺垫

### 评价

这是这道题非常标准的 DP 写法。

如果你在系统刷一维 DP，这一步一定要理解透。

## 方法四：状态压缩（最优解）

### 思路

观察方法三：

```text
dp[i] = max(dp[i - 1] + nums[i], nums[i])
```

其实在计算 `dp[i]` 时，我们只会用到一个东西：

```text
dp[i - 1]
```

也就是说，整张 `dp` 数组根本没必要保存。

我们只需要两个变量：

- `curr`：当前“以当前位置结尾”的最大子数组和
- `best`：遍历到当前为止的全局最大和

遍历每个数 `num` 时：

```text
curr = max(curr + num, num)
best = max(best, curr)
```

这就是这道题最经典的最优写法，也常被叫做 **Kadane 算法**。

### 代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        curr = nums[0]
        best = nums[0]

        for num in nums[1:]:
            curr = max(curr + num, num)
            best = max(best, curr)

        return best
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 评价

这是最常见、最实用、最推荐面试写的版本。

优点：

- 只遍历一次
- 不需要额外数组
- 代码短
- 边界处理清楚
- 很适合白板手写

## 哪个方法最适合面试

### 结论

**最适合面试的是：方法四，状态压缩版动态规划（Kadane 算法）。**

但更准确地说：

> 面试里最好的表达方式是：先讲清楚方法三的 DP 状态定义，再自然压缩成方法四。

这样会比你一上来直接背一个 `curr = max(curr + num, num)` 更有说服力。

---

## 最适合面试的方法：详细讲解

### 第一步：先想“以当前位置结尾”

很多人一开始会卡在这里：

```text
整个数组里最大的连续子数组和是多少？
```

这个问题直接想，不太好下手。

所以要换一个更容易递推的问法：

```text
以 nums[i] 结尾的最大连续子数组和是多少？
```

一旦这样问，问题就变简单了。

因为“以 `i` 结尾”的连续子数组，最后一个数一定是 `nums[i]`，那它前面的部分只有两种可能：

1. 前面的子数组值得保留，就接上它
2. 前面的子数组不值得保留，就从当前数重新开始

于是得到：

```text
dp[i] = max(dp[i - 1] + nums[i], nums[i])
```

这就是整道题最核心的一步。

---

### 第二步：为什么只有这两种情况

这是面试里非常值得讲的一点。

因为题目要求的是**连续子数组**。

如果一个最大子数组以 `i` 结尾，那么它要么：

- 包含 `i-1`，那它前面那一段一定就是“以 `i-1` 结尾的某个子数组”
- 不包含 `i-1`，那就只能从 `nums[i]` 自己开始

不会有第三种情况。

所以我们不需要回头枚举很多历史位置，只需要看前一个状态。

这就是为什么这题可以从 `O(n^2)` / `O(n^3)` 直接降到 `O(n)`。

---

### 第三步：全局最大值为什么要单独维护

`dp[i]` 只是：

```text
以 i 结尾的最大子数组和
```

但题目要的是：

```text
整个数组中的最大子数组和
```

所以在遍历过程中，还要顺手维护：

```text
best = max(best, dp[i])
```

这样最后得到的才是全局答案。

---

### 第四步：为什么可以压缩成两个变量

因为 `dp[i]` 只依赖 `dp[i-1]`。

也就是说：

- 算完 `dp[i]` 之后
- 更早的 `dp[i-2]`、`dp[i-3]`...
- 就再也用不到了

所以没必要保留整个数组，只保留前一个状态就够了。

于是把：

- `dp[i-1]` 压缩成 `curr`
- 全局答案压缩成 `best`

最终得到：

```text
curr = max(curr + num, num)
best = max(best, curr)
```

---

### 第五步：用一个例子走一遍

以：

```text
nums = [-2,1,-3,4,-1,2,1,-5,4]
```

为例。

初始：

```text
curr = -2
best = -2
```

继续遍历：

| 当前数 | curr 的更新 | best 的更新 |
|---|---|---|
| 1 | max(-2 + 1, 1) = 1 | 1 |
| -3 | max(1 - 3, -3) = -2 | 1 |
| 4 | max(-2 + 4, 4) = 4 | 4 |
| -1 | max(4 - 1, -1) = 3 | 4 |
| 2 | max(3 + 2, 2) = 5 | 5 |
| 1 | max(5 + 1, 1) = 6 | 6 |
| -5 | max(6 - 5, -5) = 1 | 6 |
| 4 | max(1 + 4, 4) = 5 | 6 |

最后答案是 `6`。

最大连续子数组就是：

```text
[4, -1, 2, 1]
```

---

### 面试时推荐怎么讲

你可以按下面这个顺序讲：

#### 1. 先说暴力法

- 枚举所有子数组
- 时间复杂度高，最坏 `O(n^3)`

#### 2. 再说优化方向

- 关键不是枚举所有区间，而是思考“以当前位置结尾”的最优值

#### 3. 定义状态

```text
dp[i] = 以 nums[i] 结尾的最大子数组和
```

#### 4. 推导转移

```text
dp[i] = max(dp[i - 1] + nums[i], nums[i])
```

#### 5. 说明答案维护

- 用 `best` 维护全局最大值

#### 6. 再补一句空间优化

- 因为只依赖前一个状态，所以可以把 `dp` 数组压缩成一个变量 `curr`

这样的表达很完整，面试官通常会觉得你是真理解了，而不是只背了模板。

---

### 面试最推荐代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        curr = nums[0]
        best = nums[0]

        for num in nums[1:]:
            curr = max(curr + num, num)
            best = max(best, curr)

        return best
```

---

## 总结

### 递进关系

1. **暴力枚举所有子数组**
   - 最直观
   - 但重复求和很多，太慢

2. **枚举起点 + 滚动累加**
   - 去掉重复求和
   - 但仍然是 `O(n^2)`

3. **动态规划**
   - 定义 `dp[i]` 为“以 i 结尾的最大子数组和”
   - 时间降到 `O(n)`

4. **状态压缩**
   - 把 DP 数组压缩成一个变量
   - 得到最优解 `O(n)` 时间、`O(1)` 空间

### 一句话记忆

> 以当前位置结尾的最大子数组和，要么接上前面的最佳连续和，要么从当前数重新开始。
