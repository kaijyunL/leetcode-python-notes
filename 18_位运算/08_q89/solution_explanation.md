# LeetCode 89. 格雷编码（Gray Code）解析

## 题目描述

给你一个整数 `n`，返回一个长度为 `2^n` 的格雷码序列。

要求：

- 第一个数是 `0`
- 每个数都在 `0 ~ 2^n - 1`
- 每个数只出现一次
- 相邻两个数的二进制表示只差一位

例子：

```text
n = 2
输出：[0, 1, 3, 2]
```

对应二进制：

```text
00
01
11
10
```

相邻两个数都只差一位。

---

## 先理解题意

`n` 表示二进制位数。

如果 `n = 2`，合法数字范围是：

```text
0 ~ 2^2 - 1
= 0 ~ 3
```

也就是：

```text
00, 01, 10, 11
```

但不能随便排列，要求相邻两个数只变一位。

普通递增顺序是：

```text
00 -> 01 -> 10 -> 11
```

其中：

```text
01 -> 10
```

变了两位，所以不行。

这题的核心是：**怎么构造一个每一步只变一位的完整序列。**

---

## 方法一：回溯翻转一位

### 思路

把每个数字看成一个状态。

从 `0` 开始，每一步尝试翻转某一位：

```python
nxt = cur ^ (1 << bit)
```

如果 `nxt` 没出现过，就加入路径。

路径长度达到 `2^n` 时，就是一个合法序列。

### 评价

这个方法直观，但本质是在搜索路径，不是面试最推荐写法。

复杂度：

- 时间复杂度：最坏指数级
- 空间复杂度：`O(2^n)`

---

## 方法二：镜像构造

### 核心思路

这是最适合面试的方法。

先从：

```text
[0]
```

开始。

每次扩展一位时：

1. 保留当前序列作为前半段
2. 倒序遍历当前序列
3. 给倒序出来的每个数加上当前新增的最高位 `head`
4. 追加到结果后面

### 用 `n = 2` 走一遍

初始：

```text
res = [0]
head = 1
```

第一轮：

```text
当前 res = [0]
倒序遍历 res，取到的数是 0
计算 head + 0 = 1
把 1 追加到 res 末尾
```

得到：

```text
res = [0, 1]
head = 2
```

第二轮：

```text
当前 res = [0, 1]
倒序遍历：1, 0

先取 1，计算 head + 1 = 2 + 1 = 3，把 3 追加到 res 末尾
再取 0，计算 head + 0 = 2 + 0 = 2，把 2 追加到 res 末尾
```

得到：

```text
res = [0, 1, 3, 2]
```

二进制：

```text
00
01
11
10
```

合法。

### 为什么必须倒序

当前已经有：

```text
00
01
```

如果正序补最高位 `1`，后半段是：

```text
10
11
```

中间连接是：

```text
01 -> 10
```

变了两位，不合法。

倒序后，后半段是：

```text
11
10
```

中间连接变成：

```text
01 -> 11
```

只变新增的最高位，合法。

### 面试代码

```python
class Solution:
    def grayCode(self, n: int) -> list[int]:
        res = [0]
        head = 1

        for _ in range(n):
            for j in range(len(res) - 1, -1, -1):
                res.append(head + res[j])
            head <<= 1

        return res
```

### 变量说明

- `res`：当前已经构造好的格雷码序列
- `head`：当前新增的最高位，依次是 `1, 2, 4, 8...`

### `n = 3` 的完整处理流程

初始：

```text
res = [0]
二进制：[000]
head = 1
```

第 1 轮，`head = 1`：

```text
当前 res：
[0]
[000]

倒序遍历当前 res：
[0]

每个数加 head 后追加到 res 末尾：
0 + 1 = 1
```

第 1 轮结束：

```text
res = [0, 1]
二进制：
000
001

head 左移，变成 2
```

第 2 轮，`head = 2`：

```text
当前 res：
[0, 1]

二进制：
000
001

倒序遍历当前 res：
[1, 0]

每个数加 head 后追加到 res 末尾：
1 + 2 = 3
0 + 2 = 2
```

第 2 轮结束：

```text
res = [0, 1, 3, 2]

二进制：
000
001
011
010

head 左移，变成 4
```

第 3 轮，`head = 4`：

```text
当前 res：
[0, 1, 3, 2]

二进制：
000
001
011
010

倒序遍历当前 res：
[2, 3, 1, 0]

每个数加 head 后追加到 res 末尾：
2 + 4 = 6
3 + 4 = 7
1 + 4 = 5
0 + 4 = 4
```

第 3 轮结束：

```text
res = [0, 1, 3, 2, 6, 7, 5, 4]

二进制：
000
001
011
010
110
111
101
100
```

为什么可以写：

```python
head + res[j]
```

因为 `head` 是新增高位，`res[j]` 只占低位，二进制位不重叠。

比如：

```text
head = 4 = 100
res[j] = 3 = 011
head + res[j] = 111
```

这里写 `head | res[j]` 也可以，但 `head + res[j]` 更常见、更简洁。

复杂度：

- 时间复杂度：`O(2^n)`
- 空间复杂度：`O(2^n)`，返回数组本身

## 方法三：公式生成

### 思路

格雷码有一个直接公式：

```python
gray = i ^ (i >> 1)
```

所以可以写：

```python
class Solution:
    def grayCode(self, n: int) -> list[int]:
        return [i ^ (i >> 1) for i in range(1 << n)]
```

这个方法最短，但面试中不如镜像构造好解释。

复杂度：

- 时间复杂度：`O(2^n)`
- 空间复杂度：`O(2^n)`

---

## 哪个方法最适合面试

最适合面试的是 **方法二：镜像构造**。

原因：

- 代码短，现场容易写出来
- 不需要硬背公式
- 倒序的原因可以讲清楚
- `res` 和 `head` 两个变量含义明确

面试里可以这样说：

```text
我用镜像构造。
res 保存当前已经构造好的格雷码序列。
每扩展一位，就倒序遍历当前 res，给每个数加上当前最高位 head，再追加到 res 后面。
必须倒序，因为这样前半段最后一个数和后半段第一个数只差新增的最高位。
每轮结束后 head 左移一位。
```

---

## 总结

- 方法一：回溯翻转一位
  - 好理解，但不适合面试主写

- 方法二：镜像构造
  - 最适合面试
  - 推荐写 `res/head` 版本

- 方法三：公式生成
  - 代码最短
  - 但需要记公式，解释性不如镜像构造
